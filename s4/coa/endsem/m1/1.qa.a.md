#### **Q1. With a neat block diagram, explain the functional units in the basic structure of a computer.**
*Ref: Sept 2020, Dec 2018 (10 Marks)*

A computer consists of five main functional units. The CPU contains the ALU and Control Unit.

1.  **Input Unit:** Accepts data and programs from the outside world (Keyboard, Mouse) and converts them into digital signals (ADC process).
2.  **Memory Unit:**
    *   **Primary Memory (RAM):** Fast, volatile storage where programs reside during execution.
    *   **Secondary Memory:** Non-volatile storage for permanent data (Hard disks).
3.  **Arithmetic and Logic Unit (ALU):** The "calculator" of the system. It performs addition, subtraction, multiplication, and logic operations (AND, OR, NOT). Operands are brought from memory to registers, processed, and the result is stored back.
4.  **Output Unit:** The reverse of input. It converts processed binary data into human-readable form (Monitors, Printers) using a DAC process.
5.  **Control Unit (CU):** The "manager." It coordinates all units by issuing timing and control signals. It fetches instructions, decodes them, and tells the ALU/Memory how to respond.

#### **Q2. What is meant by an instruction cycle? Describe its two phases.**
*Ref: Sept 2020 (5 Marks)*

The **Instruction Cycle** is the complete process of fetching, decoding, and executing a single machine instruction.

1.  **Fetch Phase:**
    *   The address in the **Program Counter (PC)** is sent to the **MAR**.
    *   A **Read** signal is sent to memory.
    *   The instruction is loaded into the **MDR** and then transferred to the **Instruction Register (IR)**.
    *   The **PC** is incremented (usually by 4) to point to the next instruction.
2.  **Execute Phase:**
    *   The **Instruction Decoder** interprets the opcode in the IR.
    *   Necessary operands are fetched from registers or memory.
    *   The **ALU** performs the operation.
    *   The result is stored in the destination location.

#### **Q3. Differentiate between Big-endian and Little-endian byte ordering assignments with examples.**
*Ref: 2017 Paper, May 2019, Dec 2019, 2026 Assessment (5 Marks)*

These terms describe how multi-byte data (like a 32-bit integer) is stored in byte-addressable memory.

*   **Big-endian:** The **Most Significant Byte (MSB)** is stored at the **lowest** (starting) memory address. (Left-to-right storage).
*   **Little-endian:** The **Least Significant Byte (LSB)** is stored at the **lowest** memory address. (Right-to-left storage).

**Example:** Storing hexadecimal value `0x12345678` at address `1000`.
| Address | Big-endian Content | Little-endian Content |
| :--- | :--- | :--- |
| **1000** | `12` (MSB) | `78` (LSB) |
| **1001** | `34` | `56` |
| **1002** | `56` | `34` |
| **1003** | `78` (LSB) | `12` (MSB) |

#### **Q4. Give the relevance of MAR, PC, and IR in a typical computer system with a neat diagram.**
*Ref: 2026 Assessment (5 Marks)*

These are specialized registers within the CPU required for basic operation:

1.  **Program Counter (PC):** It holds the address of the next instruction to be fetched. It ensures instructions are executed in the correct sequence.
2.  **Memory Address Register (MAR):** It holds the address of the memory location currently being accessed (for either reading an instruction or reading/writing data). It is connected directly to the address lines of the system bus.
3.  **Instruction Register (IR):** Once an instruction is fetched from memory, it is placed here. It holds the current instruction opcode while it is being decoded and executed.

#### **Q5. Differentiate between mono bus (single) and multi bus organization.**
*Ref: 2017 Paper, May 2019 (5 Marks)*

| Feature | Single (Mono) Bus | Multiple (Three) Bus |
| :--- | :--- | :--- |
| **Data Path** | Only one path for all transfers. | Multiple paths (Buses A, B, and C). |
| **Concurrency** | Sequential. Only one transfer per cycle. | Parallel. Two operands can move while a result returns. |
| **Temp Registers** | Requires Y and Z to hold operands/results. | No need for Y and Z; data moves directly. |
| **Hardware** | Simple and low cost. | Complex and higher cost. |
| **Performance** | Slower; instructions take more clock cycles. | Much faster; instructions take fewer cycles. |
