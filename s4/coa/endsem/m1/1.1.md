### 1.1 Basic Structure of Computers - Functional Units

A computer system consists of five distinct functional units: **Input, Memory, Arithmetic and Logic (ALU), Output, and Control**. While the ALU and Control unit are physically combined into the **Central Processing Unit (CPU)**, they perform vastly different functions.

#### 1. Input Unit
The primary function of the input unit is to accept data and programs from external sources and convert them into a digital format (electronic impulses) that the computer can process.
*   **Mechanism:** It acts as an Analog-to-Digital Converter (ADC) for raw data.
*   **Examples:** Keyboard, Mouse, Scanners, and Magnetic Disks.
*   **Operation:** When you type or scan, the input unit translates these actions into binary code (0s and 1s) to be stored in the memory.

#### 2. Memory Unit (MU)
The Memory Unit is a collection of storage cells used to store programs (instructions) and data. It is organized into a hierarchy for efficiency.
*   **Primary Storage (RAM):** This is the "main memory." It holds the data and applications currently in use by the CPU. It is fast but volatile (data is lost when power is turned off).
*   **Secondary Storage:** Used for long-term archiving of data. Examples include Hard Drives (HDD), Solid State Drives (SSD), and Optical Media. It is slower than RAM but provides much higher capacity.
*   **Word Length:** Data is handled in groups of 'n' bits called a **Word**. Modern computers typically use 16, 32, or 64-bit word lengths.

#### 3. Arithmetic and Logic Unit (ALU)
The ALU is where the actual "computation" happens. It performs two types of operations:
*   **Arithmetic Operations:** Addition, subtraction, multiplication, and division.
*   **Logic Operations:** Comparisons ($>$, $<$, $=$) and boolean operations (AND, OR, NOT, XOR).
*   **Data Flow:** Operands are brought from the memory into the ALU registers. After the operation is performed, the result is either stored in a processor register or sent back to the memory.

#### 4. Output Unit
The Output Unit is the reverse of the input unit. It takes processed binary data and converts it back into a human-readable or machine-usable form.
*   **Mechanism:** It acts as a Digital-to-Analog Converter (DAC).
*   **Examples:** Display screens (Monitors), Printers, Plotters, and Synthesizers.
*   **Significance:** It sends processed results to the "outside world."

#### 5. Control Unit (CU)
The Control Unit acts as the "supervisor" or "manager" of the entire system. It does not process data itself; instead, it coordinates the other units.
*   **Coordination:** It issues timing and control signals to the Memory, ALU, and I/O units.
*   **Instruction Handling:** It determines the sequence of execution. It fetches an instruction from memory, interprets (decodes) it, and then tells the relevant unit what to do.
*   **Peripheral Management:** It acts like a switchboard operator when multiple users or devices try to access the computer simultaneously.

---

### Central Processing Unit (CPU)
The **ALU** and the **Control Unit** are jointly known as the CPU. It is considered the **brain** of the computer because it takes all major decisions, performs calculations, and directs every part of the system by activating/deactivating control lines.
