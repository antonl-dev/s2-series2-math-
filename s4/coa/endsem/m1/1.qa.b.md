#### **Q13. Discuss how instructions are classified based on the number of operands or addresses they use, with suitable examples.**
*Ref: Sept 2020, 2026 Assessment (10 Marks)*

Instructions are categorized by the number of memory addresses or registers they can specify in a single instruction word. We evaluate the task $X = (A + B) * (C + D)$ for each:

**1. Three-Address Instructions:**
*   **Format:** `Opcode Source1, Source2, Destination`
*   **Example:**
    *   `ADD R1, A, B` ($R1 \leftarrow [A] + [B]$)
    *   `ADD R2, C, D` ($R2 \leftarrow [C] + [D]$)
    *   `MUL X, R1, R2` ($X \leftarrow [R1] * [R2]$)
*   **Logic:** High information density per instruction, but requires very long instruction words.

**2. Two-Address Instructions:**
*   **Format:** `Opcode Source, Destination`
*   **Example:**
    *   `MOVE R1, A` ($R1 \leftarrow [A]$)
    *   `ADD B, R1` ($R1 \leftarrow [R1] + [B]$)
*   **Note:** One operand acts as both source and destination. It is the most common format in general-purpose register machines.

**3. One-Address Instructions (Accumulator Architecture):**
*   **Mechanism:** Uses an implicit register called the **Accumulator (ACC)**.
*   **Example:**
    *   `LOAD A` ($ACC \leftarrow [A]$)
    *   `ADD B` ($ACC \leftarrow ACC + [B]$)
    *   `STORE T` ($[T] \leftarrow ACC$)
*   **Note:** Requires more instructions to complete the same task compared to multi-address formats.

**4. Zero-Address Instructions (Stack Architecture):**
*   **Mechanism:** Operands are pushed onto a **Stack**. Operations like `ADD` implicitly take the top two elements, add them, and push the result back.
*   **Example:** `PUSH A`, `PUSH B`, `ADD`.

#### **Q14. Describe the different addressing modes and illustrate them with examples.**
*Ref: May 2017, 2026 Assessment (10 Marks)*

Addressing modes determine the **Effective Address (EA)** of an operand.

1.  **Immediate Mode:** Operand is a constant within the instruction.
    *   *Example:* `ADD #10, R1` (Adds 10 to R1).
2.  **Register Mode:** Operand is stored in a register.
    *   *Example:* `ADD R1, R2` (EA = R1).
3.  **Absolute (Direct) Mode:** Address of operand is explicitly in the instruction.
    *   *Example:* `MOVE 1000, R1` (Fetch data from memory address 1000).
4.  **Indirect Mode:** Instruction contains the address of a location that holds the *actual* EA.
    *   *Notation:* `(R1)`
    *   *Example:* `ADD (R1), R0`. If R1 contains 2000, the CPU goes to address 2000 to find the operand.
5.  **Index Mode:** $EA = X + [Ri]$. Constant $X$ is added to register content.
    *   *Example:* `10(R1)` (Useful for array access where $10$ is the start address).
6.  **Relative Mode:** $EA = [PC] + X$.
    *   *Usage:* Used in branch instructions to jump forward/backward relative to current position.
7.  **Autoincrement Mode:** $EA = [Ri]$; then $Ri = Ri + d$.
    *   *Notation:* `(R1)+`
    *   *Example:* `MOVE (R1)+, R0` (Moves data from address in R1 to R0, then increments R1 to point to next data).

#### **Q15. Differentiate the architectural characteristics of RISC and CISC paradigms.**
*Ref: Dec 2018, May 2019, Sept 2020 (5-10 Marks)*

| Feature | RISC (Reduced Instruction Set) | CISC (Complex Instruction Set) |
| :--- | :--- | :--- |
| **Instruction Size** | Fixed length (usually 32-bit). | Variable length. |
| **Memory Access** | Load/Store architecture only. | Most instructions can access memory. |
| **Addressing Modes** | Simple and very few. | Many and complex. |
| **Execution** | Most instructions run in 1 cycle. | Instructions take multiple cycles. |
| **Registers** | Large number of registers. | Fewer registers. |
| **Complexity** | Simple hardware, complex compiler. | Complex hardware, simple compiler. |

#### **Q18. Write notes on different instruction sequencing techniques.**
*Ref: Sept 2020 (5 Marks)*

1.  **Straight-Line Sequencing:**
    *   The CPU fetches and executes instructions from successive memory locations.
    *   The **PC** is automatically incremented by $d$ (word size) after every fetch.
2.  **Branching:**
    *   Used to change the execution flow (loops, if-statements).
    *   **Conditional Branch:** Only jumps if a condition (like Zero flag or Negative flag) is met.
    *   **Unconditional Branch:** Always jumps to the target address.
    *   The **PC** is updated with the **Branch Target Address** instead of just $PC+4$.
