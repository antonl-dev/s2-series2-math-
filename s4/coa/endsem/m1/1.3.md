### 1.3 Introduction to Buses, Single Bus, and Multiple Bus Organization

A **Bus** is a shared communication pathway (a collection of wires) that connects multiple components within a computer system. Only one pair of units can use the bus to transfer data at any given time.

---

### 1.3.1 Bus Structures (The System Level)
The system bus consists of three functional groups of lines:
1.  **Address Lines:** Used by the CPU to specify the memory location or I/O device it wants to access.
2.  **Data Lines:** Provide the path for moving data between the CPU, memory, and I/O.
3.  **Control Lines:** Carry signals that command the timing and specific action (e.g., Read, Write, Interrupt Acknowledge).

### 1.3.2 Single Bus Organization
In this organization, all CPU components (ALU, registers, control circuitry) are interconnected via a **single common internal bus**.

**Key Characteristics:**
*   **Simplicity:** It is the simplest and cheapest architecture to design.
*   **Bottleneck:** Only one data item can be transferred over the bus per clock cycle. This makes control sequences long because steps must happen sequentially.
*   **Registers Y, Z, and TEMP:** Since the ALU has no internal storage and the bus is shared, these temporary registers are essential. 
    *   **Register Y:** Holds one operand before the ALU operation.
    *   **Register Z:** Holds the result of the ALU operation before it is moved to a destination register.

**Operating Logic in Single Bus:**
To add $R1$ and $R2$ and store in $R3$:
1.  $R1_{out}, Y_{in}$ (Move R1 to Y via bus).
2.  $R2_{out}, Select Y, Add, Z_{in}$ (Move R2 to ALU, add with Y, store result in Z).
3.  $Z_{out}, R3_{in}$ (Move result from Z to R3).

### 1.3.3 Multiple Bus Organization
To reduce the number of steps required for instructions, commercial processors use multiple internal paths. The most common is the **Three-Bus Structure**.

**Key Features:**
*   **Parallelism:** Multiple transfers can take place simultaneously in a single clock cycle.
*   **The Three Buses (A, B, and C):**
    *   **Buses A and B:** Used to transfer two operands simultaneously from the register file to the ALU inputs.
    *   **Bus C:** Used to transfer the result from the ALU output back to the destination register.
*   **Register File Ports:** The register file has three ports—two output ports (to Bus A and B) and one input port (from Bus C).
*   **Incrementer Unit:** A separate hardware unit used to increment the Program Counter (PC). This eliminates the need to use the main ALU for `PC + 4`, saving clock cycles.
*   **Efficiency:** Because operands move on A and B while the result moves on C, an "Add" operation can often be completed in a single execution step instead of three.

### 1.3.4 Comparison (Exam Perspective)

| Feature | Single Bus Organization | Multiple Bus Organization |
| :--- | :--- | :--- |
| **Speed** | Slower (Sequential) | Faster (Parallel) |
| **Complexity** | Low | High |
| **Cost** | Cheap | Expensive |
| **Registers** | Requires Y and Z for intermediate storage | Obviates (removes) the need for Y and Z |
| **Performance** | One transfer per clock cycle | Multiple transfers per clock cycle |
