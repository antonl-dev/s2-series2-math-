### 1.5 Addressing Modes

Addressing modes are the different ways a computer specifies the location of an operand (the data) used in an instruction. These modes allow programmers to implement variables, constants, arrays, and pointers efficiently.

The term **Effective Address (EA)** is used to denote the actual memory address of an operand as determined by the addressing mode.

---

#### 1. Immediate Mode
The operand is given **explicitly** within the instruction itself.
*   **Usage:** For constants.
*   **Notation:** Usually indicated by a `#` sign.
*   **Example:** `Add #200, R1` (Adds the value 200 directly to register R1).
*   **Advantage:** No memory access is needed to fetch the operand, making it very fast.

#### 2. Register Mode
The operand is stored in a **processor register**. The name (address) of the register is given in the instruction.
*   **EA:** $EA = Ri$
*   **Example:** `Add R1, R2` (The operand is in R1, and the result is stored in R2).
*   **Advantage:** Register access is significantly faster than memory access.

#### 3. Absolute (Direct) Mode
The operand is in a **memory location**, and the address of this location is given explicitly in the instruction.
*   **EA:** $EA = LOC$
*   **Example:** `Move LOC, R1` (Copies the value stored at memory address `LOC` into register R1).
*   **Usage:** Accessing global variables.

#### 4. Indirect Mode
The instruction contains a register or a memory location that holds the **address** of the operand, rather than the operand itself. This is the concept of a **pointer**.
*   **Notation:** Indicated by parentheses `()`.
*   **EA:** $EA = [Ri]$ or $EA = [LOC]$
*   **Example:** `Add (R1), R0` (Look at register R1, find the address stored there, go to that memory address to fetch the actual operand, and add it to R0).
*   **Advantage:** Useful for implementing pointers and passing parameters to subroutines.

#### 5. Index Mode
The effective address of the operand is generated by adding a constant value (offset/displacement) to the contents of a register (the **Index Register**).
*   **EA:** $EA = X + [Ri]$
*   **Notation:** `X(Ri)`
*   **Example:** `1000(R1)` (If R1 contains 20, the EA is $1000 + 20 = 1020$).
*   **Usage:** Excellent for accessing **arrays**. The register holds the index, and the constant X points to the start of the array.

#### 6. Relative Mode
A variation of index mode where the **Program Counter (PC)** is used instead of a general-purpose register.
*   **EA:** $EA = X + [PC]$
*   **Usage:** Primarily used in **Branch instructions** to specify a target address relative to the current instruction. It allows for "position-independent code."

#### 7. Base with Index (and Offset)
These modes use two registers (Base register $Ri$ and Index register $Rj$) to calculate the address.
*   **Base with Index:** $EA = [Ri] + [Rj]$
*   **Base with Index and Offset:** $EA = X + [Ri] + [Rj]$
*   **Usage:** Accessing multi-dimensional arrays or records within a database.

#### 8. Autoincrement / Autodecrement Modes
Specialized modes used for stepping through items in a list or implementing a stack.
*   **Autoincrement `(Ri)+`:** The EA is the current content of $Ri$. After the operand is accessed, the value of $Ri$ is automatically incremented (by 1 for bytes, 4 for words).
*   **Autodecrement `-(Ri)`:** The value of $Ri$ is first decremented, and then this new value is used as the EA to fetch the operand.

### Summary Table for Exam

| Mode | Syntax | Effective Address (EA) |
| :--- | :--- | :--- |
| **Immediate** | `#Value` | Operand = Value |
| **Register** | `Ri` | $EA = Ri$ |
| **Absolute** | `LOC` | $EA = LOC$ |
| **Indirect** | `(Ri)` | $EA = [Ri]$ |
| **Index** | `X(Ri)` | $EA = [Ri] + X$ |
| **Relative** | `X(PC)` | $EA = [PC] + X$ |
| **Autoincrement** | `(Ri)+` | $EA = [Ri]; Ri \leftarrow Ri + d$ |
| **Autodecrement** | `-(Ri)` | $Ri \leftarrow Ri - d; EA = [Ri]$ |
