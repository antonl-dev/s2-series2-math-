#### **Q16. Give the control sequence (step-by-step signals) for the execution of the instruction `Add (R3), R1` in a single-bus processor.**
*Ref: 2017 Paper, Dec 2019 (10 Marks)*

This instruction adds the contents of a memory location (pointed to by R3) to register R1.

**Phase 1: Instruction Fetch (Common)**
1.  **Step 1:** $PC_{out}, MAR_{in}, Read, Select4, Add, Z_{in}$
    *(Move PC to MAR to start fetch, simultaneously calculate PC+4 in ALU).*
2.  **Step 2:** $Z_{out}, PC_{in}, Y_{in}, WMFC$
    *(Update PC with new value, wait for memory to respond with the instruction).*
3.  **Step 3:** $MDR_{out}, IR_{in}$
    *(Load instruction into Instruction Register).*

**Phase 2: Execution**
4.  **Step 4:** $R3_{out}, MAR_{in}, Read$
    *(Decoding reveals indirect mode. Move the pointer in R3 to MAR to fetch the actual operand).*
5.  **Step 5:** $R1_{out}, Y_{in}, WMFC$
    *(Move first operand from R1 to temporary register Y, wait for memory operand to arrive).*
6.  **Step 6:** $MDR_{out}, SelectY, Add, Z_{in}$
    *(Memory operand is now in MDR. Add MDR to Y, store result in Z).*
7.  **Step 7:** $Z_{out}, R1_{in}, End$
    *(Move sum back to R1 and signal end of cycle).*

#### **Q17. Explain the data path implementation for executing `Add R4, R5, R6` in a 3-bus processor unit.**
*Ref: Sept 2020, 2026 Assessment (5-10 Marks)*

In a **Three-Bus Organization**, the internal structure allows the execution phase to be much shorter because two operands can be sourced and a result stored in the **same clock cycle**.

**The Three-Bus Data Path:**
*   **Bus A & Bus B:** Connected to the two output ports of the register file.
*   **Bus C:** Connected to the input port of the register file.

**Control Steps for `Add R4, R5, R6` ($R6 \leftarrow [R4] + [R5]$):**
1.  **Step 1:** $PC_{out}, R=B, MAR_{in}, Read, IncPC$
    *(PC is passed through ALU to MAR. The separate 'Incrementer' updates PC).*
2.  **Step 2:** $WMFC$
    *(Wait for instruction).*
3.  **Step 3:** $MDR_{outB}, R=B, IR_{in}$
    *(Instruction from MDR moved to IR).*
4.  **Step 4:** $R4_{outA}, R5_{outB}, SelectA, Add, R6_{in}, End$
    *(R4 is put on Bus A, R5 on Bus B. ALU adds them immediately. Result goes to Bus C and into R6).*

**Efficiency Note:** Notice Step 4 performs the entire addition and storage in **one cycle**, whereas the single-bus version (Q16) took three cycles for the execution phase.

#### **Q19. Enumerate the sequence of actions (control signals) involved in executing an unconditional branch instruction.**
*Ref: 2026 Assessment (5 Marks)*

An unconditional branch instruction (e.g., `JMP Target`) forces the CPU to skip to a non-sequential address.

1.  **Step 1–3:** Instruction Fetch (Same as Q16).
2.  **Step 4:** $Offset\_field\_of\_IR_{out}, Add, Z_{in}$
    *(The branch offset stored in the IR is sent to the ALU. Since the updated PC value was already moved to register Y in Step 2, the ALU adds the Offset to the PC).*
3.  **Step 5:** $Z_{out}, PC_{in}, End$
    *(The new calculated address is loaded back into the PC. The next instruction cycle will start from this new address).*

#### **Q20. Explain Load and Store operations in detail.**
*Ref: Dec 2018 (5 Marks)*

These are the primary instructions for moving data between memory and registers.

*   **LOAD Operation:** Transfers data from memory to a register.
    *   *RTN:* $R1 \leftarrow [Memory\_Address]$
    *   *Key Registers:* MAR (holds address), MDR (receives data), R1 (final destination).
*   **STORE Operation:** Transfers data from a register to memory.
    *   *RTN:* $[Memory\_Address] \leftarrow R1$
    *   *Key Registers:* MAR (holds destination address), MDR (holds data to be written), R1 (source).
