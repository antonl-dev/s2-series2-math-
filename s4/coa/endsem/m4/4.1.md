### 4.1 Memory Organization: Memory Cells & Basic Organization

**Memory** is a collection of storage cells, each capable of storing one bit of information (0 or 1). For efficient access, these cells are organized into larger units.

#### 1. Memory Cells
A memory cell is the smallest unit of digital storage. 
*   **SRAM (Static RAM) Cell:** Uses a flip-flop configuration (usually 6 transistors). It retains data as long as power is supplied and does not need refreshing. It is very fast but expensive and less dense.
*   **DRAM (Dynamic RAM) Cell:** Uses a single transistor and a capacitor to store a bit as an electrical charge. Because capacitors leak, the charge must be **refreshed** periodically (thousands of times per second). It is slower than SRAM but much cheaper and denser.

[Click here to see the SRAM vs DRAM cell circuit diagrams](https://www.google.com/search?q=SRAM+vs+DRAM+cell+circuit+diagram+comparison+COA&udm=2)

#### 2. Word and Word Length
*   **Word:** A group of $n$ bits that the CPU can store or retrieve in a single basic operation.
*   **Word Length:** The number of bits in a word (typically 16, 32, or 64 bits). 
*   **Byte:** A unit of 8 bits. Most modern memories are **byte-addressable**, meaning every byte has a unique address.

#### 3. Basic Organization of a Memory Chip
A memory chip is organized as an array of cells arranged in rows and columns.
*   **Address Decoder:** When the CPU provides an address, the decoder activates exactly one row (word line).
*   **Sensing/Writing Circuits:** These circuits read the data from the activated cells or write new data into them.
*   **Organization Example:** A $1K \times 8$ memory chip has 1024 words, and each word is 8 bits (1 byte) long. It would require 10 address lines ($2^{10} = 1024$).

[Click here to see the internal organization of a memory chip (Row/Column decoder)](https://www.google.com/search?q=internal+organization+of+memory+chip+decoder+diagram&udm=2)

#### 4. Memory Address Space
The maximum number of addressable locations is determined by the number of bits in the address bus ($k$).
*   If the address bus is $k$ bits wide, the address space is $2^k$ locations.
*   **MAR and MDR Role:** The **MAR** (Memory Address Register) holds the $k$-bit address, and the **MDR** (Memory Data Register) holds the $n$-bit data being moved.
