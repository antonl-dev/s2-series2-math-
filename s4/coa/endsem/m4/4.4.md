### 4.4 Caches - Cache Performance

**Cache Memory** is a small, high-speed memory placed between the CPU and Main Memory. It stores copies of data from frequently used main memory locations to reduce the average time to access memory.

#### 1. Basic Operation
When the CPU needs to access memory, it first checks the Cache:
*   **Cache Hit:** The requested word is found in the cache. The CPU reads it immediately (very fast).
*   **Cache Miss:** The word is not in the cache. The CPU must access Main Memory. The requested block is then copied into the cache for future use.

#### 2. Performance Measures
The efficiency of a cache is measured by its **Hit Ratio**.
*   **Hit Ratio =** (Number of Hits) / (Total CPU memory references)
*   **Miss Ratio =** 1 - Hit Ratio

#### 3. Mapping Functions
Since the Cache is much smaller than Main Memory, we need a rule to determine where a memory block should be placed in the cache. There are three main techniques:

**A. Direct Mapping**
*   **Logic:** Each block of main memory maps to exactly one specific line in the cache.
*   **Formula:** *Cache line number = (Main memory block number) MOD (Total cache lines)*.
*   **Advantage:** Simple and inexpensive to implement.
*   **Disadvantage:** If a program frequently accesses two different blocks that map to the same cache line, they will constantly kick each other out (**Thrashing**).

**B. Associative Mapping**
*   **Logic:** A main memory block can be placed in **any** available cache line.
*   **Mechanism:** Uses CAM (Content Addressable Memory) to search all "Tags" simultaneously to find the data.
*   **Advantage:** Maximum flexibility; no thrashing.
*   **Disadvantage:** Very expensive hardware due to the complex search logic.

[Click here to see Associative Mapping diagram](https://www.google.com/search?q=associative+mapping+cache+memory+diagram+KTU&udm=2)

**C. Set-Associative Mapping**
*   **Logic:** A compromise between the two. The cache is divided into **sets**. A block can be placed in any line within its designated set.
*   **Example:** In a "2-way set-associative cache," each set contains 2 lines.

#### 4. Replacement Algorithms
When the cache is full and a new block arrives, an existing block must be removed.
*   **LRU (Least Recently Used):** Discards the block that has not been used for the longest time. (Most effective in practice).
*   **FIFO (First-In, First-Out):** Discards the block that arrived first.
*   **Random:** Chooses a block at random.

#### 5. Write Policies
What happens when the CPU performs a **Write** operation?
*   **Write-Through:** Data is written to both the Cache and Main Memory simultaneously.
