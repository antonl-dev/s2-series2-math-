### 3.2 Fixed- and Floating-Point Representations, Character Representation

This section details how different types of data (integers, decimals, and text) are stored in computer memory.

---

#### 1. Fixed-Point Representation
In fixed-point representation, the position of the binary point (the decimal point in binary) is fixed. It is used primarily for integers.

*   **Integer Representation:** The binary point is assumed to be to the right of the least significant bit (LSB).
*   **Fraction Representation:** The binary point is assumed to be to the left of the most significant magnitude bit.
*   **Registers:** In hardware, these numbers are stored in standard registers like the **Accumulator (AC)** or **B register (BR)**.
*   **Limitation:** It cannot represent very large or very small numbers efficiently without using a massive number of bits.

---

#### 2. Floating-Point Representation
Floating-point representation is used to store real numbers (numbers with fractional parts). It is analogous to "Scientific Notation" (e.g., $1.23 \times 10^5$). 

A floating-point number has three parts:
1.  **Sign (s):** 0 for positive, 1 for negative.
2.  **Mantissa (m):** Represents the significant digits of the number.
3.  **Exponent (e):** Represents the power to which the base is raised.

**Formula:** $V = (-1)^s \times m \times r^e$ (where $r$ is the radix/base, usually 2 in computers).

*   **Normalization:** A number is "normalized" if the most significant digit of the mantissa is non-zero. This ensures a unique representation for every number.
*   **Biased Exponent:** To simplify comparisons, exponents are stored as "biased" positive numbers. For example, if the bias is 127, an actual exponent of $-1$ is stored as $126$ ($127 - 1$).

#### 3. IEEE 754 Standard (High Exam Priority)
This is the universal standard for floating-point arithmetic. It defines two main formats:

**A. Single Precision (32 bits):**
*   **Sign:** 1 bit.
*   **Exponent:** 8 bits (Bias = 127).
*   **Mantissa (Fraction):** 23 bits.
*   **Total:** 32 bits.

**B. Double Precision (64 bits):**
*   **Sign:** 1 bit.
*   **Exponent:** 11 bits (Bias = 1023).
*   **Mantissa (Fraction):** 52 bits.
*   **Total:** 64 bits.

#### 4. Character Representation
Since computers only understand bits, characters (letters, symbols) are assigned unique binary codes.

*   **ASCII (American Standard Code for Information Interchange):** 
    *   Uses 7 bits (standard) or 8 bits (extended).
    *   Can represent 128 to 256 characters (English alphabet, numbers, basic symbols).
*   **ISCII (Indian Script Code for Information Interchange):** 
    *   An 8-bit code used specifically to represent various Indian scripts.
*   **Unicode:** 
    *   A modern, universal standard (usually 16 or 32 bits).
    *   It can represent almost every character from every language in the world, including emojis and ancient scripts.
