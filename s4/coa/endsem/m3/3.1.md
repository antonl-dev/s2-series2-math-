### 3.1 Computer Arithmetic: Signed and Unsigned Numbers

In computer architecture, data is processed in binary format. The way this binary data is interpreted depends on whether the numbers are treated as **unsigned** or **signed**. 

#### 1. Unsigned Numbers
Unsigned numbers represent only positive values (and zero). In an $n$-bit unsigned binary number, all $n$ bits are used to represent the magnitude.
*   **Range:** $0$ to $2^n - 1$.
*   **Example:** An 8-bit unsigned number can represent values from $0$ to $255$.

**Subtraction of Unsigned Numbers using Complements:**
While humans subtract using the "borrow" concept, digital hardware is much more efficient if it uses **complements** (specifically the 2's complement in binary or 10's complement in decimal) to perform subtraction via addition. 

To subtract two $n$-digit unsigned numbers $M - N$:
1.  Add the minuend $M$ to the $r$'s complement of the subtrahend $N$. Mathematically: $M + (r^n - N) = M - N + r^n$.
2.  **Case 1 ($M \ge N$):** The sum will produce an end carry ($r^n$). Simply **discard the end carry**, and what is left is the correct positive result ($M - N$).
3.  **Case 2 ($M < N$):** The sum does not produce an end carry. The result is $r^n - (N - M)$, which is the $r$'s complement of the actual magnitude. To get the final answer in familiar form, take the $r$'s complement of the sum and attach a negative sign.

**Binary Example (Unsigned Subtraction):** 
Subtract $Y = 1000011$ from $X = 1010100$ using 2's complement:
*   $X = 1010100$
*   2's complement of $Y = 0111101$
*   Sum = $1010100 + 0111101 = 10010001$
*   Discard the end carry (the 8th bit '1'). The answer is `0010001`.

#### 2. Signed Numbers
Signed numbers can represent both positive and negative values. The Most Significant Bit (MSB) is reserved as the **Sign Bit** (0 for positive, 1 for negative). The remaining $n-1$ bits represent the magnitude.

There are three common ways to represent signed integers:
1.  **Sign-Magnitude Representation:** The MSB is the sign, and the rest is the absolute value. 
    *   *Example:* `+5` is `0101`, `-5` is `1101`.
2.  **1's Complement Representation:** Negative numbers are formed by inverting every bit of the positive number. 
    *   *Example:* `+5` is `0101`, `-5` is `1010`.
3.  **2's Complement Representation:** Negative numbers are formed by taking the 1's complement and adding 1 to the LSB.
    *   *Example:* `+5` is `0101`, `-5` is `1011`.

#### 3. Why 2's Complement is Preferred
Modern computers almost exclusively use **2's complement** for signed arithmetic. 
*   **Unique Zero:** Sign-magnitude and 1's complement have two representations for zero (`+0` and `-0`), which complicates hardware logic. 2's complement has only one representation for zero.
*   **Unified Arithmetic:** Addition and subtraction can be performed using the exact same hardware circuit (an adder), without needing to check the signs of the operands first. 
*   **No End-Around Carry:** Unlike 1's complement, 2's complement addition doesn't require adding an overflow carry back into the LSB.

#### 4. Addition and Subtraction with Sign-Magnitude Data
If a system *does* use Sign-Magnitude representation, the hardware algorithm is more complex. Let the magnitudes be $A$ and $B$, and the signs be $A_s$ and $B_s$. 
There are eight conditions depending on the operation and signs:

| Operation | Add Magnitudes | Subtract Magnitudes |
| :--- | :--- | :--- |
| | | **When A > B** | **When A < B** | **When A = B** |
| $(+A) + (+B)$ | $+(A + B)$ | | | |
| $(+A) + (-B)$ | | $+(A - B)$ | $-(B - A)$ | $+(A - B)$ |
| $(-A) + (+B)$ | | $-(A - B)$ | $+(B - A)$ | $+(A - B)$ |
| $(-A) + (-B)$ | $-(A + B)$ | | | |
| $(+A) - (+B)$ | | $+(A - B)$ | $-(B - A)$ | $+(A - B)$ |
| $(+A) - (-B)$ | $+(A + B)$ | | | |
| $(-A) - (+B)$ | $-(A + B)$ | | | |
| $(-A) - (-B)$ | | $-(A - B)$ | $+(B - A)$ | $+(A - B)$ |

**Rule:** 
*   If signs are the same (for addition), add magnitudes and attach the original sign.
*   If signs differ (for addition), compare magnitudes, subtract the smaller from the larger, and attach the sign of the larger magnitude.
