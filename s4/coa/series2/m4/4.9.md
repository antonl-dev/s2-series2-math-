# 4.9 Instruction and Arithmetic Pipelines

### Overview
Pipelining can be applied at two different levels: for performing complex mathematical operations (Arithmetic) or for executing program instructions (Instruction).

---

### 1. Arithmetic Pipeline
An arithmetic pipeline is used to perform operations on floating-point numbers. Floating-point addition and subtraction are typical examples.

**Mathematical Representation (PDF 2, Page 9):**
*   Assume two numbers: $X = A \times 2^a$ and $Y = B \times 2^b$
*   Where $A, B$ are **Mantissas** and $a, b$ are **Exponents**.

**The 4-Segment Process (PDF 1, Page 14; PDF 2, Page 10):**
1.  **Segment 1: Compare Exponents** – Find the difference between exponents $a$ and $b$.
2.  **Segment 2: Align Mantissa** – The mantissa associated with the smaller exponent is shifted right to make the exponents equal.
3.  **Segment 3: Add or Subtract Mantissas** – Perform the addition/subtraction ($A \pm B$).
4.  **Segment 4: Normalize Result** – Adjust the result so it has a single non-zero digit before the decimal point. This involves shifting the mantissa and incrementing/decrementing the exponent.

**Example:**
*   $X = 0.9504 \times 10^3$
*   $Y = 0.8200 \times 10^2 \rightarrow$ **Shift Right** to match exponent $\rightarrow 0.0820 \times 10^3$
*   **Add:** $(0.9504 + 0.0820) \times 10^3 = 1.0324 \times 10^3$
*   **Normalize:** $0.10324 \times 10^4$

---

### 2. Instruction Pipeline
An instruction pipeline executes multiple instructions by overlapping their execution phases.

**The 4-Segment Instruction Pipeline (PDF 1, Page 15; PDF 2, Page 11):**
1.  **FI (Fetch Instruction):** The instruction is read from memory.
2.  **DA (Decode & Address):** The instruction is decoded, and the Effective Address of the operands is calculated.
3.  **FO (Fetch Operands):** The actual data (operands) required for the instruction are fetched from memory.
4.  **EX (Execute):** The operation is performed by the ALU.

**Timing Diagram (Throughput):**
In a perfect pipeline, while Instruction 1 is being **Executed (EX)**, Instruction 2 is **Fetching Operands (FO)**, Instruction 3 is being **Decoded (DA)**, and Instruction 4 is being **Fetched (FI)**. This allows the processor to finish one instruction per clock cycle once the pipeline is full.
