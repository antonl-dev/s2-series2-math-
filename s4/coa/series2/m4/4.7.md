# 4.7 Introduction to Pipelining - Basic Principles

### Overview
Pipelining is a technique used in computer architecture to improve the performance of a processor by performing multiple operations simultaneously. It is similar to an assembly line in a factory.

### 1. Basic Definition (PDF 1, Page 11; PDF 2, Page 5)
A complex process is divided into several smaller **sub-operations** called **segments** ($S_1, S_2, S_3, \dots$). 
*   Each sub-operation is performed in its own dedicated hardware segment.
*   Each segment is associated with a **register** ($R$) that stores the output of that segment.
*   The output stored in a register is passed as the input to the next sub-operation in the next clock cycle.

### 2. Key Principles
*   **Independent Operation:** All segments work independently and concurrently (at the same time).
*   **Registers as Buffers:** Registers between segments prevent data from mixing and allow each segment to work on a different task during the same clock cycle.
*   **Synchronous Execution:** All segments are controlled by a **common clock pulse** (CLK). On every clock pulse, data moves from one stage to the next.
*   **Why use Pipelining?** To increase the "throughput" (the number of tasks finished per unit of time). 

### 3. Example: Arithmetic Pipeline (PDF 1, Pages 12-13; PDF 2, Pages 6-8)
Consider the operation: **$A_i * B_i + C_i$** for $i = 1$ to $7$.

**The 3-Segment Breakdown:**
1.  **Segment 1 ($S_1$):** Load inputs into registers ($R_1 \leftarrow A_i, R_2 \leftarrow B_i$).
2.  **Segment 2 ($S_2$):** Perform multiplication and load $C_i$ ($R_3 \leftarrow R_1 * R_2, R_4 \leftarrow C_i$).
3.  **Segment 3 ($S_3$):** Perform addition ($R_5 \leftarrow R_3 + R_4$).

**Performance Comparison:**
*   **Normal Sequential Manner:** Each of the 7 tasks takes 3 clock cycles. 
    *   $3 \times 7 = \mathbf{21 \text{ clock cycles}}$.
*   **Pipelining Manner:** After a "warm-up" period (the time it takes to fill the pipe), one result is produced every single clock cycle.
    *   Total time = $\mathbf{9 \text{ clock cycles}}$.

### 4. Throughput and Efficiency
*   **Cycle 1:** Task 1 starts in $S_1$.
*   **Cycle 2:** Task 1 moves to $S_2$; Task 2 starts in $S_1$.
*   **Cycle 3:** Task 1 moves to $S_3$ (Finish); Task 2 moves to $S_2$; Task 3 starts in $S_1$.
*   By the end of Cycle 9, all 7 tasks are completed.
