# 4.1 Memory Organization: Memory Cells & Basic Organization

### Overview
Memory organization refers to how a computer system stores and retrieves data. The fundamental building block of any memory system is the **Memory Cell**, which is an electronic circuit capable of storing one bit of information (binary 0 or 1).

### 1. Memory Cells
According to the notes (PDF 1, Page 4), RAM is divided into two primary types based on the construction of their memory cells:

#### **Static RAM (SRAM)**
*   **Technology:** Uses **flip-flops** to store binary information.
*   **Speed:** Very fast access times.
*   **Cost:** Expensive to manufacture.
*   **Power:** Consumes more power but does not require refreshing.
*   **Usage:** Designed specifically to make **Cache Memory**.
*   **Characteristics:** Information remains as long as power is supplied.

#### **Dynamic RAM (DRAM)**
*   **Technology:** Uses **capacitors** to store bits as an electrical charge.
*   **Speed:** Slower than SRAM because capacitors need time to charge/discharge.
*   **Cost:** Cheaper and allows for higher density.
*   **Capacity:** High storage capacity; used to store large amounts of information.
*   **Maintenance:** Requires periodic **refreshing** because capacitors leak charge over time.
*   **Usage:** Designed to make **Main Memory (RAM)**.

### 2. Basic Organization
Memory is organized into an array of cells. To access a specific piece of data, the system uses:
*   **Address Lines:** To identify the specific location (word) in memory.
*   **Data Lines:** To carry the actual bits being read from or written to memory.
*   **Control Lines:** Signals like **Read** and **Write** that tell the memory unit which operation to perform.
