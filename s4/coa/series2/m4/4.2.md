# 4.2 Memory Hierarchy

### Overview
Memory Hierarchy is a concept in computer architecture that organizes different types of memory into a pyramid structure. The goal is to provide the system with the highest possible access speed while keeping costs low and storage capacity high.

### 1. Types of Memory
Based on the hierarchy (PDF 1, Page 1), memory is categorized into three main levels:

1.  **Cache Memory (Level 3 in diagram):**
    *   The smallest and fastest memory.
    *   Placed directly between the CPU and Main Memory.
    *   Stores frequently used instructions to reduce access time.
2.  **Main Memory (Level 1 / Primary Memory):**
    *   Refers to RAM (Random Access Memory).
    *   The CPU communicates directly with this memory.
    *   It is **volatile** (data is lost when power is off).
3.  **Auxiliary Memory (Level 2 / Secondary Memory):**
    *   Used for permanent storage and backup (e.g., Magnetic Disks, Magnetic Tapes).
    *   The CPU cannot access this directly; data must be moved to Main Memory via I/O processors first.
    *   It is **non-volatile** (data remains when power is off).

### 2. The Hierarchy Triangle (Properties)
The relationship between these levels is defined by three key properties (PDF 1, Page 3):

| Property | Cache Memory | Main Memory | Auxiliary Memory |
| :--- | :--- | :--- | :--- |
| **Access Speed** | Fastest | Fast | Slowest |
| **Storage Capacity** | Small (KB/MB) | Medium (GB) | Large (TB) |
| **Cost per Bit** | Highest | Medium | Lowest |

**Trends in the Hierarchy:**
*   **Moving Down:** Capacity **increases**, but speed **decreases** and cost per bit **decreases**.
*   **Moving Up:** Speed **increases**, but cost per bit **increases** and capacity **decreases**.

### 3. Data Transfer
*   **CPU Access:** The CPU only executes programs present in the **Main Memory**.
*   **Execution Flow:** When a program is saved, it resides in auxiliary memory (hard disk). During execution, the program is transferred from auxiliary memory to main memory.
*   **Cache Role:** Frequently accessed data is copied from Main Memory to Cache for even faster CPU access.
