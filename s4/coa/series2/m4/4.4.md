# 4.4 Caches - Cache Performance

### Overview
Cache memory is a small, high-speed memory placed between the CPU and Main Memory. Its primary purpose is to store **frequently used instructions and data** so that the CPU can access them faster than if it had to go to Main Memory every time.

### 1. Locality of Reference (PDF 1, Page 5)
Cache works because of a property called **Locality of Reference**. Programs tend to reuse data and instructions they have used recently.
*   **Temporal Locality:** If an item is referenced, it will tend to be referenced again soon (e.g., loops like `for(int i=0; i<100; i++)`).
*   **Spatial Locality:** If an item is referenced, items with nearby addresses will tend to be referenced soon.

### 2. Cache Mapping Techniques (PDF 1, Pages 6-7)
Mapping is the process of loading information from Main Memory into Cache Memory. There are three main types:

#### **A. Associative Mapping**
*   The CPU address is placed in an argument register.
*   The entire cache is searched simultaneously for a match.
*   **Pros:** Most flexible. **Cons:** Most expensive hardware.

#### **B. Direct Mapping**
*   The CPU address is divided into two parts: **Tag** and **Index**.
*   Each block of Main Memory maps to exactly one specific line in the Cache.
*   **Problem:** If two frequently used blocks map to the same index (different tags), it causes a "Miss," leading to a lower hit ratio.

#### **C. Set-Associative Mapping**
*   A middle ground between Direct and Associative mapping.
*   A single **Index** can store multiple **[Tag + Data]** pairs.
*   Example: A "2-way set associative" cache can store two different memory blocks at the same index.

### 3. Cache Performance: Hit Ratio (PDF 1, Page 5)
The performance of a cache is measured by the **Hit Ratio**.
*   **Hit:** When the CPU finds the required information in the Cache.
*   **Miss:** When the information is not in the Cache and must be fetched from Main Memory (this causes a **Miss Penalty**).

**Formula:**
$$\text{Hit Ratio} = \frac{\text{No. of Hits}}{\text{No. of Hits} + \text{No. of Misses}}$$

*   A **High Hit Ratio** means the system is performing efficiently.
