# 4.5 Virtual Memory

### Overview
Virtual Memory is a memory management technique that creates the **illusion** of a very large main memory. It allows the computer to execute programs that are much larger than the actual physical RAM available. (PDF 1, Page 8; PDF 2, Page 1)

### 1. Key Concepts
*   **Physical Memory:** The actual RAM installed in the system.
*   **Virtual Memory:** An illusion of physical memory.
*   **Address Space:** The collection of **Virtual Addresses** (used by the program/Auxiliary memory).
*   **Memory Space:** The collection of **Physical Addresses** (actual locations in Main Memory).
*   **Translation:** The process of converting a Virtual Address into a Physical Address so the CPU can access the data.

**Example from notes:**
If Main Memory (MM) = 4GB and a Program = 6GB, the CPU can still execute it by using Virtual Memory to swap parts of the program in and out of the 4GB RAM.

### 2. Paging Mechanism (PDF 2, Page 2-4)
To manage virtual memory, the system divides memory into fixed-size units:
*   **Pages:** The units into which **Auxiliary Memory** (Secondary storage) is divided.
*   **Blocks (or Page Frames):** The units into which **Main Memory** is divided.
*   **Rule:** The size of a Page must equal the size of a Block.

### 3. Address Translation & Mapping Table
The hardware uses a **Memory Mapping Table** to keep track of where pages are stored in RAM.
*   **Virtual Address:** Consists of a **Page Number** and a **Line Number**.
*   **Mapping Table Columns:**
    *   **Page No:** The index.
    *   **Block No:** Where that page is located in RAM.
    *   **Presence Bit:** 
        *   `1`: Page is present in Main Memory.
        *   `0`: Page is not in Main Memory (**Page Fault**).

### 4. Page Fault and Replacement (PDF 1, Page 10; PDF 2, Page 5)
*   **Page Fault:** Occurs when the CPU tries to access a page whose presence bit is `0`. The Operating System (OS) must then transfer the required page from the Hard Disk to Main Memory.
*   **Page Replacement:** If Main Memory is **full**, the OS must remove an existing page to make room for the new one.
*   **Algorithms:**
    1.  **FIFO (First-In, First-Out):** Replaces the oldest page in memory.
    2.  **Optimal Replacement:** Replaces the page that will not be used for the longest period in the future.
    3.  **LRU (Least Recently Used):** Replaces the page that hasn't been used for the longest time.
