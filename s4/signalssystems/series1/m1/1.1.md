# 1.1 Introduction to Signals and Systems

## 1. Definition of a System
A **System** is a physical device or a mathematical abstraction that operates on an input signal to produce an output signal. 

*   **Input Signal:** The excitation or stimulus applied to the system (often denoted as `x(t)` for continuous or `x(n)` for discrete).
*   **Output Signal:** The response produced by the system (often denoted as `y(t)` or `y(n)`).

[Click here for Image: Signals and Systems Block Diagram](https://www.google.com/search?q=signals+and+systems+block+diagram&tbm=isch&udm=2)

### Examples of Systems:
*   **Speaker:** Amplifies the input electrical signal into sound waves.
*   **Filter:** Removes noise and interference from a signal.
*   **ADC (Analog to Digital Converter):** Converts an analog signal into a digital format.
*   **DAC (Digital to Analog Converter):** Converts a digital signal back into an analog format.
*   **Processor:** Processes the signal based on specific algorithms.

---

## 2. What is a Signal?
A **Signal** is a physical quantity that varies with time, space, or any other independent variable. It conveys information.

**Examples:** 
*   Audio signals (voice, music)
*   Images (intensity varies over space)
*   Voltage levels in a circuit

---

## 3. Elementary Test Signals
In the study of systems, we use specific "standard" signals to test how a system behaves. These serve as the basic building blocks for more complex signals.

### A. Unit Impulse Function (Delta Function)
The impulse signal represents a very large force acting for a very short duration (a sudden spike).

*   **Continuous Time `delta(t)`:**
    *   `delta(t) = 1` at `t = 0`
    *   `delta(t) = 0` for `t != 0`
*   **Discrete Time `delta(n)`:**
    *   `delta(n) = 1` for `n = 0`
    *   `delta(n) = 0` for `n != 0`

[Click here for Image: Unit Impulse Function Graph](https://www.google.com/search?q=unit+impulse+signal+graph+CT+DT&tbm=isch&udm=2)

### B. Unit Step Function
The step function represents a signal that turns "ON" at a specific time and stays constant.

*   **Continuous Time `u(t)`:**
    *   `u(t) = 1` for `t >= 0`
    *   `u(t) = 0` for `t < 0`
*   **Discrete Time `u(n)`:**
    *   `u(n) = 1` for `n >= 0`
    *   `u(n) = 0` for `n < 0`

[Click here for Image: Unit Step Function Graph](https://www.google.com/search?q=unit+step+function+CT+DT+graph&tbm=isch&udm=2)

### C. Unit Ramp Function
The ramp function increases linearly with time, starting from zero. It represents a constant rate of change (like constant acceleration).

*   **Continuous Time `r(t)`:**
    *   `r(t) = t` for `t >= 0`
    *   `r(t) = 0` for `t < 0`
    *   Note: The slope is "unity" (1).
*   **Discrete Time `r(n)`:**
    *   `r(n) = n` for `n >= 0`
    *   `r(n) = 0` for `n < 0`

[Click here for Image: Unit Ramp Function Graph](https://www.google.com/search?q=unit+ramp+function+graph&tbm=isch&udm=2)

## 4. Relationship Between Elementary Signals
There is a mathematical link between these three signals:
1.  **Integrating** the Impulse gives the Step.
2.  **Integrating** the Step gives the Ramp.
3.  **Differentiating** the Ramp gives the Step.
4.  **Differentiating** the Step gives the Impulse.

## Practice Problems (from Section 1.1)

**Q1. Define a system and give two examples of its components.**
*Answer:* A system is a device that transforms an input signal into an output signal. Components include Filters (remove noise) and Amplifiers (increase signal strength).

**Q2. Sketch the Unit Step signal `u(n)` for discrete time.**
*Answer:* Draw a horizontal axis `n`. At `n = 0, 1, 2, 3...`, draw vertical lines (stems) with a height of 1. For negative `n`, the value is 0.

**Q3. What is a Unit Ramp signal?**
*Answer:* It is a signal that increases linearly for positive time (`t >= 0`) with a slope of 1. Mathematically: `r(t) = t * u(t)`.
