# 1.8 Concept of System and Properties (Part 1)

## 1. Concept of a System
A system is a mathematical or physical entity that transforms an input signal `x(n)` or `x(t)` into an output signal `y(n)` or `y(t)`. 
*   **Notation:** `y(n) = T{x(n)}` where `T` represents the operation/transformation performed by the system.

## 2. Linearity (Linear vs. Non-Linear)
A system is **linear** if it satisfies the **Superposition Principle**, which consists of two parts:
1.  **Additivity:** The response to a sum of inputs is the sum of the individual responses.
2.  **Homogeneity (Scaling):** Scaling the input results in the same scale for the output.

### Test Procedure:
To check for linearity, we check if:
`T[a * x1(t) + b * x2(t)] = a * T[x1(t)] + b * T[x2(t)]`

### Practice Problems (Linearity):
**Q1. Check if `d^2y/dt^2 + 2t * y(t) = t^2 * x(t)` is linear.**
*   **Step 1:** Apply input `x1(t)` to get output `y1(t)`.
*   **Step 2:** Apply input `x2(t)` to get output `y2(t)`.
*   **Step 3:** Apply weighted sum `a*x1 + b*x2`. 
*   **Result:** The weighted sum of outputs equals the output due to weighted sum of inputs.
*   **Conclusion:** The system is **Linear**.

**Q2. Check if `y(t) = x^2(t)` is linear (HW).**
*   **Step 1:** `y1(t) = x1^2(t)`
*   **Step 2:** `y2(t) = x2^2(t)`
*   **Weighted Sum:** `a * y1 + b * y2 = a*x1^2 + b*x2^2`.
*   **Input Sum:** `T[a*x1 + b*x2] = (a*x1 + b*x2)^2`.
*   Since `(a*x1 + b*x2)^2 != a*x1^2 + b*x2^2`.
*   **Conclusion:** The system is **Non-Linear**.

## 3. Time Invariance (Time-Invariant vs. Time-Variant)
A system is **Time-Invariant (TI)** if a time shift in the input signal causes the exact same time shift in the output signal.

### Test Procedure:
1.  **Find Output due to Delayed Input:** `y(t, T) = T{x(t - T)}`. (Replace `x(t)` with `x(t - T)`).
2.  **Find Delayed Output:** `y(t - T)`. (Replace every `t` in the original equation with `t - T`).
3.  **Compare:** If `y(t, T) = y(t - T)`, it is Time-Invariant.

### Practice Problems (Time Invariance):
**Q1. Check `y(t) = t^2 * x(t)` (HW).**
*   Output due to delayed input: `y(t, T) = t^2 * x(t - T)`.
*   Delayed output: `y(t - T) = (t - T)^2 * x(t - T)`.
*   **Result:** They are not equal. 
*   **Conclusion:** **Time-Variant**.

**Q2. Check `y(n) = x^2(n - 2)` (HW).**
*   Output due to delayed input: `y(n, k) = x^2(n - 2 - k)`.
*   Delayed output: `y(n - k) = x^2((n - k) - 2) = x^2(n - 2 - k)`.
*   **Result:** They are equal.
*   **Conclusion:** **Time-Invariant**.

---

## 4. Causality (Causal vs. Non-Causal)
A system is **Causal** if its output at any time depends only on the **present and past** values of the input, but not on future values.

### Practice Problems (Causality):
**Q1. Check `y(n) = x(-n)` (HW).**
*   Let `n = -1`. `y(-1) = x(1)`.
*   Since `x(1)` is a future input relative to time `-1`, the system is **Non-Causal**.

**Q2. Check `y(n) = x(n^2)` (HW).**
*   Let `n = 2`. `y(2) = x(4)`.
*   `x(4)` is a future value.
*   **Conclusion:** **Non-Causal**.

**Q3. Check `y(n) = x(n) + 1/x(n-1)` (HW).**
*   Output depends on present `x(n)` and past `x(n-1)`.
*   **Conclusion:** **Causal**.

## Summary Table of System Properties

| Property | Rule of Thumb |
| :--- | :--- |
| **Linearity** | No powers (x^2), no transcendental functions (sin(x)), no additions (+4). |
| **Time Invariance** | No time-varying coefficients (like `t` or `n`) outside the brackets. |
| **Causality** | No "look ahead" (cannot have `x(n+1)` or `x(t^2)` for future values). |
