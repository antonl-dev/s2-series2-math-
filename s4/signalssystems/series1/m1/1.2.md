# 1.2 Elementary Signals: Exponentials and Sinusoids

In addition to step and ramp signals, these three types of signals are fundamental in engineering because they describe vibrations, oscillations, and growth/decay patterns in nature.

---

## 1. Sinusoidal Signals
A sinusoidal signal is a periodic signal that follows a sine or cosine wave pattern.

### Continuous-Time Form:
`x(t) = A * sin(w0 * t + phi)` or `x(t) = A * cos(w0 * t + phi)`
*   **A:** Amplitude (Peak value).
*   **w0:** Angular Frequency (radians/second). Calculated as `w0 = 2 * pi * f0`.
*   **phi:** Phase angle (in radians).
*   **T:** Period. `T = 2 * pi / w0`.

### Discrete-Time Form:
`x(n) = A * sin(w0 * n + phi)`
*   Note: For a discrete sinusoid to be periodic, `w0 / (2 * pi)` must be a rational number.

## 2. Real Exponential Signals
These signals describe processes that grow or decay over time, such as radioactive decay or compound interest.

### General Form:
`x(t) = C * e^(a * t)`
*   **If a > 0:** The signal grows exponentially (Diverging).
*   **If a < 0:** The signal decays exponentially (Converging/Stable).
*   **If a = 0:** The signal is a constant DC value `C`.

## 3. Complex Exponential Signals
These are the most important signals in Fourier Analysis. They combine sinusoids and exponentials using **Euler’s Identity**.

### Euler's Identity:
`e^(j * theta) = cos(theta) + j * sin(theta)`

### General Form:
`x(t) = A * e^(s * t)` where `s` is a complex number `s = sigma + j * w0`.
This results in:
`x(t) = A * e^(sigma * t) * [cos(w0 * t) + j * sin(w0 * t)]`

*   If `sigma = 0`, it is a **Purely Imaginary Exponential** (a pure sinusoid).
*   If `sigma != 0`, it is a **Damped Sinusoid** (a wave that gets smaller or larger over time).

## Practice & Homework Problems (from Notes)

These problems focus on identifying and analyzing the properties of the signals mentioned in this section.

### HW Problem 1: Analyze the signal `x(n) = e^(j * (3/5) * (n + 1/2))`
*   **Type:** Complex Exponential (Discrete).
*   **Expansion:** Using Euler’s Identity:
    `x(n) = cos(3/5 * n + 3/10) + j * sin(3/5 * n + 3/10)`
*   **Frequency (w0):** `3/5`
*   **Periodicity Check:** For periodicity, `N = (2 * pi * m) / w0` must be an integer.
    `N = (2 * pi * m) / (3/5) = 10 * pi * m / 3`.
    Since `pi` is irrational, `N` cannot be an integer for any integer `m`.
*   **Conclusion:** This signal is **Non-Periodic**.

### HW Problem 2: Analyze the signal `x(n) = cos((2 * pi / 3) * n)`
*   **Type:** Sinusoidal (Discrete).
*   **Frequency (w0):** `2 * pi / 3`.
*   **Periodicity Check:** `N = (2 * pi * m) / (2 * pi / 3) = 3 * m`.
    If we pick `m = 1`, then `N = 3`.
*   **Conclusion:** This is a **Periodic** signal with a fundamental period of **N = 3**.

### HW Problem 3: Analyze the signal `x(n) = e^(j * 2 * n)`
*   **Type:** Complex Exponential (Discrete).
*   **Expansion:** `x(n) = cos(2n) + j * sin(2n)`.
*   **Frequency (w0):** `2`.
*   **Periodicity Check:** `N = (2 * pi * m) / 2 = pi * m`.
    Because `pi` is present, `N` will never be an integer.
*   **Conclusion:** This signal is **Non-Periodic**.

### HW Problem 4: Composite Signal `x(n) = cos(pi/4 * n) + cos(2n)`
*   **Signal 1:** `cos(pi/4 * n)`. `w1 = pi/4`. `N1 = (2 * pi * m) / (pi/4) = 8m`. Fundamental period `N1 = 8`.
*   **Signal 2:** `cos(2n)`. `w2 = 2`. `N2 = (2 * pi * m) / 2 = pi * m`. (Non-periodic).
*   **Total Signal:** Since one part is non-periodic, the sum is **Non-Periodic**.
