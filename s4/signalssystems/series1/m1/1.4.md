# 1.4 Classification of Signals: Periodic, Aperiodic, Causal, and Non-Causal

## 1. Periodic and Aperiodic Signals

### Continuous-Time (CT) Periodicity
A signal is **periodic** if it repeats itself at regular intervals of time.
*   **Condition:** `x(t + T) = x(t)` for all `t`.
*   **Fundamental Period (T):** The smallest positive value of `T` that satisfies the condition.
*   **Angular Frequency (w0):** `w0 = 2 * pi / T`.

[Click here for Image: Periodic vs Aperiodic Continuous Signal](https://www.google.com/search?q=periodic+and+aperiodic+signals+ct+graph&tbm=isch&udm=2)

### Discrete-Time (DT) Periodicity
A DT signal is periodic if it repeats after a fixed number of samples.
*   **Condition:** `x(n + N) = x(n)` for all `n`.
*   **Important Rule:** For a DT sinusoid `x(n) = sin(w0 * n)` to be periodic, the frequency `w0` must be a **rational multiple of 2*pi**.
*   **Formula for Period (N):** `N = (2 * pi * m) / w0`. 
    *   *Note:* `m` must be the smallest integer that makes `N` an integer.

## 2. Causal, Non-Causal, and Anti-Causal Signals

This classification is based on when the signal exists relative to time `t = 0`.

*   **Causal Signal:** A signal that is zero for all negative time.
    *   `x(t) = 0` for `t < 0`. 
    *   *Real-world signals (that start when you turn a switch on) are causal.*
*   **Non-Causal Signal:** A signal that has non-zero values for some `t < 0`.
*   **Anti-Causal Signal:** A signal that is zero for all positive time.
    *   `x(t) = 0` for `t > 0`.

## Practice & Homework Problems (Detailed Solutions)

### Q1. Examine if `x(t) = sin(12 * pi * t)` is periodic. Find T.
1.  Compare with standard form `sin(w0 * t)`: `w0 = 12 * pi`.
2.  Formula: `T = 2 * pi / w0`.
3.  Calculation: `T = 2 * pi / (12 * pi) = 2 / 12 = 1/6`.
4.  **Result:** Periodic with fundamental period **T = 1/6 seconds**.

### Q2. Examine if `x(n) = sin( (6 * pi / 7) * n + 1 )` is periodic. Find N.
1.  Angular frequency `w0 = 6 * pi / 7`.
2.  Formula: `N = (2 * pi * m) / w0`.
3.  Calculation: `N = (2 * pi * m) / (6 * pi / 7) = (2 * pi * m * 7) / (6 * pi) = 7 * m / 3`.
4.  To make `N` an integer, the smallest `m` is `3`.
5.  `N = (7 * 3) / 3 = 7`.
6.  **Result:** Periodic with fundamental period **N = 7 samples**.

### Q3. Periodicity of a Sum: `x(n) = cos(pi/3 * n) + cos(3*pi/4 * n)`
1.  **Find N1:** `w1 = pi/3`. `N1 = (2 * pi * m) / (pi/3) = 6m`. Smallest `m=1`, so `N1 = 6`.
2.  **Find N2:** `w2 = 3*pi/4`. `N2 = (2 * pi * m) / (3*pi/4) = 8m / 3`. Smallest `m=3`, so `N2 = 8`.
3.  **Check Ratio:** `N1 / N2 = 6 / 8 = 3 / 4`. (Since 3/4 is rational, the sum is periodic).
4.  **Find Total Period (N):** Use LCM of `N1` and `N2`.
    *   `LCM(6, 8) = 24`.
5.  **Result:** Periodic with fundamental period **N = 24**.

### HW Problem: Is `x(t) = t * sin(t)` periodic?
1.  Test condition: `x(t + T) = (t + T) * sin(t + T)`.
2.  This does not equal `t * sin(t)` because the amplitude term `(t + T)` increases as `t` increases.
3.  **Result:** **Aperiodic**.

## Summary of Periodicity Rules

| Signal Type | periodicity Condition | Fundamental Period Formula |
| :--- | :--- | :--- |
| **CT Sinusoid** | Always Periodic | `T = 2 * pi / w0` |
| **DT Sinusoid** | `w0 / (2 * pi)` must be rational | `N = (2 * pi * m) / w0` |
| **Sum of Signals** | Ratio of periods `N1 / N2` must be rational | `N = LCM(N1, N2)` |
