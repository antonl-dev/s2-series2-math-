# 1.6 Basic Operations on Signals

Basic operations are divided into those that affect the **Amplitude** (vertical axis) and those that affect the **Time** (horizontal axis).

## 1. Time Shifting (Translation)
Time shifting moves the signal along the time axis.

*   **Formula:** `y(n) = x(n - k)` or `y(t) = x(t - k)`
*   **Case 1: Delaying (-k):** If `k` is positive, the signal shifts to the **RIGHT**.
    *   Example: `x(n - 2)` moves the signal 2 units to the right.
*   **Case 2: Advancing (+k):** If `k` is positive, `x(n + k)` shifts the signal to the **LEFT**.
    *   Example: `x(n + 1)` moves the signal 1 unit to the left.

## 2. Folding / Reflection / Time Reversal
Folding mirrors the signal about the vertical axis (time = 0).

*   **Formula:** `y(n) = x(-n)` or `y(t) = x(-t)`
*   **Operation:** Replace every index `n` with `-n`.
*   Example: If a signal exists at `n = 1, 2, 3`, after folding, it will exist at `n = -1, -2, -3`.

## 3. Amplitude Scaling
This changes the "height" or strength of the signal. The time axis remains exactly the same.

*   **Formula:** `y(n) = a * x(n)`
*   **Amplification:** If `a > 1`, the signal is stretched vertically.
*   **Attenuation:** If `0 < a < 1`, the signal is compressed vertically.
*   **Inversion:** If `a` is negative, the signal is flipped upside down (across the horizontal axis).

## 4. Time Scaling
This changes the "speed" of the signal, stretching or compressing it along the horizontal axis.

*   **Formula:** `y(n) = x(k * n)`

### A. Down-Sampling (Decimation / Compression)
*   **Condition:** `k > 1` (e.g., `y(n) = x(2n)`)
*   **Effect:** The signal is compressed. You only keep every `k-th` sample.
*   **Result:** Data is lost. For `x(2n)`, you only keep samples at `n=0, 2, 4...`.

### B. Up-Sampling (Interpolation / Expansion)
*   **Condition:** `0 < k < 1` (e.g., `y(n) = x(n/2)`)
*   **Effect:** The signal is stretched. New samples are typically filled with zeros between original samples.
*   **Result:** The "sampling rate" effectively increases.

## Practice & Homework Problems (from Notes)

### Q1. Given signal `x(n)` at indices `[0, 1, 2, 3, 4]`, draw `y(n) = x(n - 2)`.
*   **Solution:** This is a delay by 2 units.
*   Sample at index 0 moves to index 2.
*   Sample at index 4 moves to index 6.
*   **Result:** The entire shape is shifted 2 units to the right.

### Q2. Perform Amplitude Scaling: `y(n) = 2 * x(n)`.
*   **Given:** `x(n)` has heights `[1, 2, 3, 4]`.
*   **Solution:** Multiply every height by 2.
*   **Result:** New heights are `[2, 4, 6, 8]`. The `n` indices stay exactly the same.

### Q3. Perform Time Scaling (Down-sampling): `y(n) = x(2n)`.
*   **Given:** `x(n)` values at `n = [-2, -1, 0, 1, 2]`.
*   **Calculation:**
    *   `y(0) = x(2*0) = x(0)`
    *   `y(1) = x(2*1) = x(2)`
    *   `y(-1) = x(2*-1) = x(-2)`
*   **Result:** Samples at `n = -1` and `n = 1` are discarded. Only samples at even original indices remain.

### Q4. Perform Time Scaling (Up-sampling): `y(n) = x(n / 2)`.
*   **Given:** `x(n)` values at `n = [0, 1, 2]`.
*   **Calculation:**
    *   `y(0) = x(0)`
    *   `y(1) = x(0.5)` -> **0** (no signal at 0.5)
    *   `y(2) = x(1)`
    *   `y(3) = x(1.5)` -> **0**
    *   `y(4) = x(2)`
*   **Result:** The signal is stretched, and zeros are inserted between original samples.
