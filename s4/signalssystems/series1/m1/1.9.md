# 1.9 Properties of Systems: Memory, Stability, and Invertibility

## 1. Memory (Static vs. Dynamic Systems)
This property describes whether a system requires a "storage" component to hold previous values of a signal.

### Static System (Memoryless)
A system is **Static** (or memoryless) if the output at any instant depends **only** on the input sample at that exact same time. It does not look at the past or the future.
*   **Condition:** `y(n)` depends only on `x(n)`.
*   **Example (Page 32):** `y(n) = 5 * x^3(n)`. To find the output at `n=5`, you only need the input value at `n=5`.

### Dynamic System (With Memory)
A system is **Dynamic** if the output at any instant depends on past or future values of the input.
*   **Condition:** `y(n)` depends on `x(n-1)`, `x(n-2)`, `x(n+1)`, etc.
*   **Example (Page 32):** `y(t) = a * dx/dt`. Differentiation involves the difference between the current value and a value slightly in the past/future.
*   **Example (Page 32):** `y(t) = Integral of x(t) dt`. Integration accumulates (sums up) values over a period of time.
*   **Example (Page 33):** `y(n) = a * x(n) + b * x(n-1)`. The term `x(n-1)` represents a "previous sample," requiring memory.

## 2. Stability (BIBO Stability)
A system is considered stable if it does not "blow up." The most common test is **BIBO Stability** (Bounded Input, Bounded Output).

*   **Bounded Input:** An input that stays within a finite range (does not go to infinity).
*   **Rule:** If a bounded input is applied, and the resulting output is also bounded, the system is **Stable**.
*   **Unstable Example:** `y(n) = n * x(n)`. If we apply a constant input `x(n) = 1`, as time `n` grows to infinity, the output `y(n)` also grows to infinity. This is **Unstable**.

## 3. Invertibility
A system is **Invertible** if distinct inputs produce distinct outputs, allowing us to "undo" the system's operation.

*   **Condition:** If you know the output `y(t)`, you can uniquely determine the input `x(t)`.
*   **Inverse System:** If system `H` produces `y(t)`, the inverse system `H_inv` would take `y(t)` and turn it back into `x(t)`.
*   **Non-Invertible Example:** `y(t) = x^2(t)`. If the output is `y(t) = 9`, the input could have been `+3` or `-3`. Because there is ambiguity, the system is **Non-Invertible**.

## Practice & Homework Problems (Synthesis of section)

**Q1. Classify as Static or Dynamic:**
1.  `y(t) = x(t-5)` -> **Dynamic** (depends on the past).
2.  `y(n) = x^2(n)` -> **Static** (depends only on present).
3.  `y(n) = x(2n)` -> **Dynamic** (depends on future values for some `n`, e.g., `y(2) = x(4)`).

**Q2. Is the system `y(t) = cos(x(t))` stable?**
*   *Logic:* The cosine function's output is always between -1 and 1, regardless of how large the input is.
*   *Result:* **Stable** (Output is always bounded).

**Q3. Find the inverse system of `y(n) = 2 * x(n)`.**
*   *Logic:* To get `x(n)` back from `y(n)`, we must divide by 2.
*   *Result:* `x(n) = 0.5 * y(n)`. This system is **Invertible**.
