# Module 2.7: Break-Even Analysis - Problem Solving

## 2.7.1 The Gear Shaft Problem (From Notes, Page 57-58)
**Question:** An engineering company can produce a maximum of 20,000 units of gear shafts per month. These shafts are sold at ₹100 each. Variable costs are ₹20 per unit and total fixed costs are ₹2 Lakhs. Compute the firm’s Break-Even Point (BEP) in units, sales, and percentage.

**Data:**
*   Maximum Capacity ($Q_{max}$) = 20,000 units
*   Selling Price ($P$) = ₹100
*   Variable Cost ($V$ or $AVC$) = ₹20
*   Fixed Cost ($TFC$) = ₹2,00,000 (2 Lakhs)

**Step 1: Break-Even Quantity ($Q_B$)**
$$Q_B = \frac{TFC}{P - V} = \frac{2,00,000}{100 - 20} = \frac{2,00,000}{80} = \mathbf{2,500 \text{ units}}$$

**Step 2: Break-Even Sales ($S_B$)**
$$S_B = Q_B \times P = 2,500 \times 100 = \mathbf{₹2,50,000}$$

**Step 3: Percentage Break-Even (%B)**
This tells us what percentage of the factory's capacity must be used to break even.
$$\%B = \left( \frac{Q_B}{Q_{max}} \right) \times 100 = \left( \frac{2,500}{20,000} \right) \times 100 = \mathbf{12.5\%}$$

## 2.7.2 The Comprehensive Exam Problem (From Question Paper, Q13)
**Question:** A firm pays ₹10,000 as monthly rent and ₹10,000 as interest. Monthly expenditure on raw materials is ₹40,000. Monthly sales revenue is ₹80,000. Price of one unit is ₹40. 
**Find:** (i) P/V Ratio, (ii) BE Sales, (iii) BE Output, (iv) Profit, (v) Margin of Safety.

**Data Extraction:**
*   **Total Fixed Cost (TFC):** Rent + Interest = $10,000 + 10,000 = \mathbf{₹20,000}$
*   **Total Revenue (TR):** ₹80,000
*   **Price (P):** ₹40
*   **Total Variable Cost (TVC):** ₹40,000 (raw materials)

**Hidden Data (Calculate first):**
*   **Actual Quantity Sold ($Q$):** $TR / P = 80,000 / 40 = \mathbf{2,000 \text{ units}}$
*   **Variable Cost per unit ($V$):** $TVC / Q = 40,000 / 2,000 = \mathbf{₹20}$

**Calculations:**
1.  **P/V Ratio:** $\frac{P - V}{P} \times 100 = \frac{40 - 20}{40} \times 100 = \mathbf{50\%}$
2.  **BE Output ($Q_B$):** $\frac{TFC}{P - V} = \frac{20,000}{20} = \mathbf{1,000 \text{ units}}$
3.  **BE Sales ($S_B$):** $Q_B \times P = 1,000 \times 40 = \mathbf{₹40,000}$
4.  **Profit Earned:** $TR - (TFC + TVC) = 80,000 - (20,000 + 40,000) = \mathbf{₹20,000}$
5.  **Margin of Safety (MoS):** $Actual Sales - BE Sales = 80,000 - 40,000 = \mathbf{₹40,000}$

## 2.7.3 Cost Table Completion (From Notes, Page 54)
If you are given a partial table, use these relationships to fill it:

| Formulas to Remember | |
| :--- | :--- |
| **TC** | $TFC + TVC$ |
| **AC** | $TC / \text{Product}$ |
| **AFC** | $TFC / \text{Product}$ |
| **AVC** | $TVC / \text{Product}$ |
| **MC** | $TC_{current} - TC_{previous}$ |

**Crucial Logic for Output 0:**
*   At output 0, **TVC = 0**.
*   Therefore, **TC = TFC**. 
*   *In your notes:* If TC is 300 at output 0, then the TFC is 300 for all rows!

## 2.7.4 Exam Tips for Module 2 Numericals:
1.  **Check Units vs Sales:** If the question asks for "Break-even point" without specifying, give both the **Units** (Output) and the **Value** (Sales).
2.  **The "Lakh" Conversion:** Be careful with zeros. $2 \text{ Lakh} = 2,00,000$. One wrong zero ruins the entire BEP calculation.
3.  **TFC identification:** In problems, "Rent," "Interest," "Insurance," and "Salaries of Management" are always **Fixed**. "Raw materials," "Labor wages," and "Power" are **Variable**.
4.  **Shut Down Check:** If you find that Price is less than Variable Cost ($P < V$), always add a note: *"The firm should shut down immediately as it is not covering its variable costs."*
