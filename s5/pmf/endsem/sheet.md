
## Master Exam Formula Cheat-Sheet

| Topic | Formula |
| :--- | :--- |
| **CPM Forward & Backward Pass** | $EF = ES + D$; $\quad LS = LF - D$ |
| **Floats** | $TF = LS - ES = LF - EF$; $\quad FF = \min(ES_{\text{succ}}) - EF$ |
| **PERT Expected Time & Variance** | $t_e = \dfrac{t_o + 4t_m + t_p}{6}$; $\quad \sigma = \dfrac{t_p - t_o}{6}$; $\quad \sigma^2 = \left(\dfrac{t_p - t_o}{6}\right)^2$ |
| **PERT Completion Probability** | $Z = \dfrac{T_s - T_e}{\sqrt{\sum \sigma_{\text{critical}}^2}}$ |
| **Crashing Cost Slope** | $\text{Cost Slope} = \dfrac{\text{Crash Cost} - \text{Normal Cost}}{\text{Normal Time} - \text{Crash Time}}$ |
| **Earned Value (EVM)** | $SV = EV - PV$; $\;CV = EV - AC$; $\;SPI = \dfrac{EV}{PV}$; $\;CPI = \dfrac{EV}{AC}$ |
| **Payback Period (Uneven)** | $\text{PBP} = E + \dfrac{B}{C}$ *(Uniform: $I_0 / CF$)* |
| **Accounting Rate of Return** | $\text{ARR} = \dfrac{\text{Average Annual PAT}}{\text{Average Investment}} \times 100\%$, $\;\text{Avg Inv} = \dfrac{I_0 + S}{2}$ |
| **Net Present Value** | $\text{NPV} = \sum_{t=1}^{n} \dfrac{CF_t}{(1+r)^t} - I_0$ *(Accept if $\text{NPV} > 0$)* |
| **IRR (Linear Interpolation)** | $\text{IRR} = r_L + \dfrac{\text{NPV}_L}{\text{NPV}_L - \text{NPV}_H}(r_H - r_L)$ *(Accept if $\text{IRR} > k$)* |
| **Benefit–Cost Ratio** | $\text{BCR} = \dfrac{\text{PV of Benefits}}{I_0\text{ (or PV of Costs)}}$; $\quad \text{NBCR} = \text{BCR} - 1 = \dfrac{\text{NPV}}{I_0}$ |
