## 1. Program Evaluation and Review Technique (PERT)

### Concept and Definition
**PERT (Program Evaluation and Review Technique)** was developed in **1958 by the U.S. Navy** (Special Projects Office, with Booz Allen Hamilton) for the Polaris Submarine Missile project. Unlike CPM, PERT is a **probabilistic** and **event-oriented** network scheduling tool designed for projects where activity durations are **uncertain** (such as R&D, software innovation, defense, and first-of-a-kind engineering projects).

[Click here to see the diagram for PERT Beta Distribution and Three Time Estimates](https://www.google.com/search?q=PERT+beta+distribution+three+time+estimates+diagram&udm=2)

### Importance of PERT Chart in Project Scheduling
1. **Handles Uncertainty:** Models unpredictable task durations using three probabilistic time estimates instead of a single fixed number.
2. **Quantifies Schedule Risk:** Enables calculation of **variance**, **standard deviation**, and the **probability of completing the project** on or before a target deadline.
3. **Visualizes Complex Dependencies:** Clearly maps parallel tasks, sequential bottlenecks, and critical events across large R&D or non-repetitive projects.
4. **Supports Proactive Decision-Making:** Helps managers identify high-variance critical tasks early and focus contingency buffers where risk is highest.

## 2. Three Time Estimates and Formulas in PERT

Because future task durations in novel projects are uncertain, PERT assumes activity durations follow a **Beta Probability Distribution** and uses **three time estimates**:

1. **Optimistic Time ($t_o$ or $O$):**  
   The **minimum possible time** required to complete an activity if everything goes exceptionally well with no setbacks.
2. **Most Likely Time ($t_m$ or $M$):**  
   The **normal/realistic time** the activity would take most frequently under standard conditions (mode of the distribution).
3. **Pessimistic Time ($t_p$ or $P$):**  
   The **maximum possible time** required if everything goes wrong (excluding catastrophic disasters like fires or wars).

### Key PERT Activity Formulas

1. **Expected Time ($t_e$):** Weighted average (mean) duration of the activity:
   $$t_e = \frac{t_o + 4t_m + t_p}{6}$$

2. **Standard Deviation ($\sigma$):** Measure of uncertainty/spread of the activity duration:
   $$\sigma = \frac{t_p - t_o}{6}$$

3. **Variance ($\sigma^2$):** Square of standard deviation (used because variances add linearly along a path):
   $$\sigma^2 = \left(\frac{t_p - t_o}{6}\right)^2$$

## 3. Steps Involved in Constructing a PERT Chart / PERT Analysis

1. **Identify Activities & Milestones:** Break the project into discrete tasks and milestone events using a WBS, and determine precedence relationships.
2. **Obtain Three Time Estimates:** Estimate Optimistic ($t_o$), Most Likely ($t_m$), and Pessimistic ($t_p$) durations for each activity.
3. **Compute Expected Time ($t_e$) and Variance ($\sigma^2$):** Calculate $t_e = \frac{t_o + 4t_m + t_p}{6}$ and $\sigma^2 = \left(\frac{t_p - t_o}{6}\right)^2$ for every activity.
4. **Construct the Network Diagram:** Draw nodes (events) and directional arrows showing logical dependencies from start event to finish event.
5. **Perform Forward & Backward Passes:** Using $t_e$ as activity durations, compute Earliest Expected Time ($T_E$), Latest Allowable Time ($T_L$), and Slack ($S = T_L - T_E$).
6. **Identify the Critical Path:** Trace the longest path (activities with zero slack) to find the **Expected Project Duration ($T_e$)**.
7. **Calculate Project Probability (if deadline $T_s$ is given):** Sum the variances of **critical path activities only**, take the square root for $\sigma_{cp}$, compute the $Z$-score, and find the probability from the Standard Normal Distribution table.

## 4. Probability of Project Completion

By the **Central Limit Theorem**, the total duration of the critical path is approximately **Normally Distributed** with:
* **Mean (Expected Project Duration, $T_e$):** Sum of $t_e$ of all activities on the critical path.
* **Project Variance ($\sigma_{cp}^2$):** Sum of variances ($\sigma^2$) of **critical path activities only**:
  $$\sigma_{cp}^2 = \sum_{i \in \text{Critical Path}} \sigma_i^2$$
* **Project Standard Deviation ($\sigma_{cp}$):**
  $$\sigma_{cp} = \sqrt{\sigma_{cp}^2}$$

### Standard Normal Variate ($Z$-Score)
To find the probability that the project finishes on or before a **Scheduled / Target Time ($T_s$)**:
$$Z = \frac{T_s - T_e}{\sigma_{cp}}$$
$$\text{Probability } P(T \le T_s) = \Phi(Z) \quad \text{(from Standard Normal Table)}$$

### Quick Reference: Standard Normal Distribution Values $\Phi(Z) = P(Z \le z)$
*(Useful to memorize key points in case a $Z$-table is not supplied or for quick verification)*

| $Z$ | $\Phi(Z)$ | $Z$ | $\Phi(Z)$ | $Z$ | $\Phi(Z)$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **$-2.0$** | $0.0228\;(2.28\%)$ | **$0.0$** | $0.5000\;(50.0\%)$ | **$+1.0$** | $0.8413\;(84.13\%)$ |
| **$-1.5$** | $0.0668\;(6.68\%)$ | **$+0.5$** | $0.6915\;(69.15\%)$ | **$+1.5$** | $0.9332\;(93.32\%)$ |
| **$-1.0$** | $0.1587\;(15.87\%)$ | **$+0.79$** | $0.7852\;(78.52\%)$ | **$+2.0$** | $0.9772\;(97.72\%)$ |
| **$-0.5$** | $0.3085\;(30.85\%)$ | **$+0.80$** | $0.7881\;(78.81\%)$ | **$+2.5$** | $0.9938\;(99.38\%)$ |

* **Key Rules:**
  * If $T_s = T_e \Rightarrow Z = 0 \Rightarrow P = 50\%$.
  * If $T_s > T_e \Rightarrow Z > 0 \Rightarrow P > 50\%$.
  * If $T_s < T_e \Rightarrow Z < 0 \Rightarrow P < 50\%$ (use $\Phi(-z) = 1 - \Phi(z)$).

## 5. Differences Between CPM and PERT

| Parameter | CPM (Critical Path Method) | PERT (Program Evaluation & Review Technique) |
| :--- | :--- | :--- |
| **1. Nature of Model** | **Deterministic** (single time estimate). | **Probabilistic** (three time estimates: $t_o, t_m, t_p$). |
| **2. Orientation** | **Activity-oriented** (focuses on tasks). | **Event-oriented** (focuses on milestone events). |
| **3. Suitability** | Repetitive, well-known projects (construction, plant maintenance). | Novel, non-repetitive, uncertain projects (R&D, defense, space). |
| **4. Focus** | Emphasizes **Time–Cost trade-off** (crashing). | Emphasizes **Time & Schedule Risk** (probability of completion). |
| **5. Time Estimate** | Single fixed duration ($D$) based on past data. | Three estimates combined via Beta distribution ($t_e = \frac{t_o + 4t_m + t_p}{6}$). |
| **6. Terminology** | Uses **Float** (Total Float, Free Float). | Uses **Slack** ($S = T_L - T_E$). |
| **7. Cost Optimization** | Directly integrates crashing and cost slopes. | Does not directly consider cost; assumes cost varies with time. |
| **8. Origin** | Developed by DuPont & Remington Rand (1957). | Developed by U.S. Navy (1958) for Polaris missile. |

#### Question 6 (5 Marks — Solved PERT Single-Activity Numerical)
**Source:** *Internal Assessment (Series Test-I), August 2026 (24HUT535 – Class: EL2K24), Part B – Q10(a) [BL: L2, CO2]*  
**Question:** An activity has the following time estimates:
* Optimistic time ($O$) = 3 days
* Most likely time ($M$) = 5 days
* Pessimistic time ($P$) = 9 days

Find:  
a) Expected duration of the activity  
b) Variance of the activity

**Answer:**

Given: $t_o = 3\text{ days}$, $\;t_m = 5\text{ days}$, $\;t_p = 9\text{ days}$.

**a) Expected Duration ($t_e$):**
$$t_e = \frac{t_o + 4t_m + t_p}{6} = \frac{3 + 4(5) + 9}{6} = \frac{3 + 20 + 9}{6} = \frac{32}{6} = \mathbf{5.33\text{ days}}$$
*(or $5\frac{1}{3}$ days)*

**b) Variance ($\sigma^2$):**
$$\sigma = \frac{t_p - t_o}{6} = \frac{9 - 3}{6} = \frac{6}{6} = 1\text{ day}$$
$$\sigma^2 = \left(\frac{t_p - t_o}{6}\right)^2 = (1)^2 = \mathbf{1\text{ day}^2}$$

### B. Self-Created Practice Question (Full-Length 8-Mark End-Sem Question)

#### Model Question 1 (8 Marks – Part B University Exam Style)
**Source:** *Self-Created (Syllabus Topic 2.1b – Comprehensive PERT & Probability Coverage)*  
**Question:** Explain the PERT technique and its three time estimates. How is the probability of completing a project by a target date calculated using PERT? Illustrate with a brief numerical example.

**Answer:**

**1. Overview of PERT (2 Marks):**  
**PERT (Program Evaluation and Review Technique)** is a probabilistic, event-oriented network planning technique used for projects with high duration uncertainty (such as R&D, IT innovation, or novel engineering systems). Because exact task durations cannot be predicted deterministically, PERT models each activity duration using a **Beta distribution** derived from three estimates:
* **Optimistic Time ($t_o$):** Minimum duration if all conditions are ideal.
* **Most Likely Time ($t_m$):** Most realistic duration under normal conditions.
* **Pessimistic Time ($t_p$):** Maximum duration if major non-catastrophic setbacks occur.

**2. Key PERT Formulas & Completion Probability Method (3 Marks):**  
For every activity:
* **Expected Time:** $t_e = \dfrac{t_o + 4t_m + t_p}{6}$
* **Variance:** $\sigma^2 = \left(\dfrac{t_p - t_o}{6}\right)^2$

Steps to compute probability of finishing by a target deadline $T_s$:
1. Construct the network using $t_e$ values and identify the **Critical Path** (expected project duration $T_e = \sum t_{e,\text{critical}}$).
2. Sum the variances of **only the critical path activities** to obtain project variance $\sigma_{cp}^2 = \sum \sigma_{i,\text{critical}}^2$, and take the square root to get project standard deviation $\sigma_{cp} = \sqrt{\sigma_{cp}^2}$.
3. By the Central Limit Theorem, project duration follows a Normal distribution. Compute the standard normal variate:
   $$Z = \frac{T_s - T_e}{\sigma_{cp}}$$
4. Look up $\Phi(Z)$ in the Standard Normal table to find the probability $P(T \le T_s)$.

**3. Illustrative Numerical Example (3 Marks):**  
Suppose a critical path has 2 sequential activities:
* Activity A: $t_o=4,\; t_m=6,\; t_p=8 \Rightarrow t_e = \frac{4+24+8}{6} = 6\text{ weeks},\quad \sigma_A^2 = \left(\frac{8-4}{6}\right)^2 = 0.44$
* Activity B: $t_o=5,\; t_m=8,\; t_p=17 \Rightarrow t_e = \frac{5+32+17}{6} = 9\text{ weeks},\quad \sigma_B^2 = \left(\frac{17-5}{6}\right)^2 = 4.00$

* Expected Project Duration: $T_e = 6 + 9 = 15\text{ weeks}$.
* Critical Path Variance: $\sigma_{cp}^2 = 0.44 + 4.00 = 4.44 \Rightarrow \sigma_{cp} = \sqrt{4.44} = 2.11\text{ weeks}$.
* Probability of completion within $T_s = 17.11\text{ weeks}$:
  $$Z = \frac{17.11 - 15}{2.11} = +1.00 \Rightarrow P(T \le 17.11) = \Phi(1.00) = \mathbf{84.13\%}$$
