# 3.3 Preparation of Gantt Chart

## 1. What is a Gantt Chart?
A **Gantt Chart** is a visual project management tool in the form of a horizontal bar chart that represents project schedules graphically over time. It allows project managers to view the start and finish dates of individual tasks, their durations, and how they relate to each other in a sequenced timeline.

## 2. Visual Components of a Gantt Chart in MS Project
The standard Gantt Chart view in MS Project is divided into two main sections:
*   **Left Side (Task Sheet Table):** A spreadsheet-like table listing project data including Task ID, Task Name, Duration, Start Date, Finish Date, Predecessors, and Resource Names.
*   **Right Side (Timeline/Bar Chart):** A horizontal time scale displaying graphical representations of the tasks.
    *   **Bars:** Horizontal blocks where the length of each bar reflects the planned duration of the task.
    *   **Milestones:** Represented as **diamonds**, marking significant events, checkpoints, or deliverables with zero duration.
    *   **Dependencies/Links:** Lines or arrows connecting task bars showing the sequence and logical relationships (e.g., an arrow pointing from the end of one bar to the start of the next).

*(Visual Aid)*: [Click here for a visual representation of an MS Project Gantt Chart](https://www.google.com/search?q=MS+Project+Gantt+Chart+Timeline+Tasks+Milestones+Dependencies&udm=2)

## 3. Task Scheduling Types: Manually Scheduled vs. Auto-Scheduled Tasks
Before preparing the Gantt Chart, MS Project requires you to choose how tasks are scheduled:
*   **Manually Scheduled Tasks:** Give project managers complete manual control over start dates, finish dates, and durations. Dates do not shift automatically when predecessors change. Represented by a **pin icon** in the Task Mode column. Used during initial, rough high-level planning.
*   **Auto-Scheduled Tasks:** Dates, durations, and dependencies are dynamically calculated by MS Project's scheduling engine based on calendar working times and task links. Changes in predecessors automatically ripple through the schedule. Represented by a **blue bar/calendar icon**. Used during detailed execution phases.

## 4. Step-by-Step Procedure for Preparing a Gantt Chart in MS Project
Constructing a Gantt chart is the core of project scheduling. The systematic process includes:
1.  **Define Project Start Date:** Go to the *Project Tab -> Project Information* and set the official project start date.
2.  **Set up Calendars:** Define the working days, shifts, and holidays using the Base Calendar.
3.  **Enter Project Activities:** Type all tasks and deliverables sequentially in the *Task Name* column of the Task Sheet.
4.  **Organize via WBS:** Use the Indent/Outdent tools to create Summary Tasks and Sub-tasks (as discussed in 3.2).
5.  **Estimate Durations:** Enter the estimated time to complete each sub-task in the *Duration* column (e.g., 5d for 5 days).
6.  **Establish Dependencies:** Link tasks by entering task ID numbers in the *Predecessors* column to determine the logical sequence (e.g., Task B cannot start until Task A finishes).
7.  **Auto-Scheduling:** Ensure tasks are set to *Auto-Scheduled* so the software automatically draws the Gantt bars and calculates the final project completion date.

## 5. Customizing the Gantt Chart
*   **Split Task Tool:** Allows a manager to interrupt work on a task, creating a gap in its schedule (e.g., due to weather delays) without altering the net work hours. Found on the *Task tab* -> *Split Task*. It divides the Gantt bar into two segments connected by a dotted line.
*   **Highlighting Critical Tasks:** Go to the *Gantt Chart Format tab* and check the *Critical Tasks* box. Critical tasks (zero total float) will turn **red**, while non-critical tasks remain **blue**.

### Short Questions (2 Marks)

**Q1. Define a Gantt chart.**
**Answer:** A Gantt chart is a visual project scheduling tool formatted as a horizontal bar chart. It graphically displays project tasks along a time scale, showing task durations, start and finish dates, and sequential dependencies.

**Q2. State the purpose of a Gantt chart in MS Project.**
**Answer:** The purpose of a Gantt chart in MS Project is to visually organize and communicate the project schedule. It helps managers easily understand task durations, track progress, identify task dependencies (links), and monitor significant milestones over time.

**Q3. Explain the usage of the split tool in a Gantt chart.**
**Answer:** The Split Task tool is used to interrupt work on a specific task (e.g., stopping work due to material shortages) and resume it later. It visually divides the task's Gantt bar into two or more segments connected by a dotted line, reflecting a non-working gap without changing the total work hours required.

**Q4. Discuss how a critical task is represented in the MS project Gantt chart.**
**Answer:** By default, once enabled via the "Gantt Chart Format" tab, MS Project visually differentiates critical tasks by coloring their horizontal bars **red** on the Gantt timeline, whereas non-critical tasks (tasks with float) are colored **blue**.

### Essay Questions (8 Marks)

**Q5. Compare Auto Scheduled tasks and Manually Scheduled tasks in MS Project.** *(Covers Essay Q1)*
**Answer:**
MS Project offers two modes of task scheduling that dictate how dates are calculated:

*   **Manually Scheduled Tasks:**
    *   *Control:* The user maintains total manual control over start dates, finish dates, and durations.
    *   *Impact of Dependencies:* If a predecessor task gets delayed, a manually scheduled successor task will *not* move automatically.
    *   *Data Requirement:* Allows incomplete entries (e.g., typing "TBD" for a start date).
    *   *Visual Icon:* Represented by a pushpin icon in the Task Mode column.
    *   *Use Case:* Best used during the initial drafting phase or high-level planning when exact dates and dependencies are still uncertain.

*   **Auto Scheduled Tasks:**
    *   *Control:* The MS Project scheduling engine automatically calculates dates and durations based on network logic, calendars, and resource constraints.
    *   *Impact of Dependencies:* If a predecessor is delayed, all linked auto-scheduled successor tasks automatically shift on the timeline to reflect the delay.
    *   *Data Requirement:* Requires valid, complete date and duration inputs.
    *   *Visual Icon:* Represented by a small blue bar/calendar icon in the Task Mode column.
    *   *Use Case:* Essential for the detailed execution phase to maintain a dynamic, real-time tracking schedule.

**Q6. Explain the step-by-step procedure for preparing a Gantt chart in MS Project, starting from entering project activities and ending with the development of the project schedule.** *(Covers Essay Q16, Q23, Q25, Q27)*
**Answer:**
Developing a comprehensive project schedule using a Gantt Chart in MS Project involves a systematic process:

1.  **Project Initialization:** Open MS Project and establish the base parameters. Go to *Project Information* to set the official Project Start Date. Next, configure the *Project Calendar* to define working days, hours, and organizational holidays.
2.  **Task Entry:** In the Gantt Chart view (Task Sheet on the left), list all the required project activities systematically in the *Task Name* column.
3.  **WBS Structuring:** Use the Indent (Right Arrow) and Outdent (Left Arrow) tools on the Task ribbon to group activities into Summary Tasks and sub-tasks, effectively creating the Work Breakdown Structure.
4.  **Duration Estimation:** For every lowest-level sub-task, input the estimated time required for completion in the *Duration* column (e.g., entering "3d" for 3 days, or "0d" to create a Milestone).
5.  **Establishing Dependencies (Task Links):** Determine the logical sequence of work. In the *Predecessors* column, enter the Task ID of the preceding task. For example, if Task 4 can only start after Task 3 finishes, enter "3" in Task 4's predecessor column. This creates a Finish-to-Start (FS) link, and MS Project will draw an arrow connecting the task bars.
6.  **Applying Auto-Scheduling:** Highlight all tasks and switch their Task Mode to *Auto-Scheduled*. The MS Project engine will immediately calculate the start and finish dates for all tasks and dynamically plot the horizontal bars on the right-side timeline.
7.  **Review and Finalize:** Review the visual timeline to ensure realistic scheduling. Apply the "Critical Tasks" format to highlight the critical path in red. Finally, save this completed schedule as the *Project Baseline* for future monitoring.

**Q7. Explain the importance of a Gantt chart (MS Project) in project planning and monitoring, and discuss how it helps a project manager understand task duration, sequence, dependencies, and progress.** *(Covers Essay Q15, Q24)*
**Answer:**
The Gantt chart is arguably the most critical visualization tool in project management. Its importance spans both the planning and monitoring phases of a project lifecycle.

*   **Importance in Project Planning:**
    *   *Visualizing Task Duration:* By representing tasks as horizontal bars against a calendar timeline, project managers can instantly visualize how long each activity is expected to take. Long bars immediately draw attention to time-intensive tasks.
    *   *Understanding Sequence and Dependencies:* The visual link lines (arrows) between bars clearly illustrate network logic. A manager can see exactly which tasks must be finished before others can begin, preventing impossible workflow scenarios.
    *   *Resource Planning:* Seeing tasks stacked vertically on the same dates alerts managers to periods of high simultaneous activity, helping them prevent resource bottlenecks before the project starts.

*   **Importance in Project Monitoring (Progress Tracking):**
    *   *Real-time Updates:* During execution, managers input actual start dates and "% Complete" data. MS Project updates the Gantt chart, drawing progress lines inside the task bars. 
    *   *Tracking against Baselines:* MS Project's "Tracking Gantt" view places a gray baseline bar directly beneath the actual colored task bar. This allows managers to visually compare planned vs. actual progress at a glance.
    *   *Managing Delays:* Because dependencies are linked, if a manager inputs a delay on a current task, the Gantt chart automatically shifts all future dependent tasks to the right. This immediately shows the manager the exact impact the delay has on the final project deadline.
