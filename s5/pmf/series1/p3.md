### **Q1. Define project scheduling.**
**Answer:**  
**Project scheduling** is the process of converting project activities into a structured time sequence. It involves establishing activity start and finish dates, task dependencies, activity durations, and resource assignments using techniques like Gantt charts, CPM, or PERT to ensure timely project execution.

---

### **Q2. What is a Gantt chart? State its key uses.**
**Answer:**  
A **Gantt chart** is a horizontal bar chart used as a visual scheduling tool in project management.  
* **Horizontal Axis:** Represents the project calendar time scale (days, weeks, or months).
* **Vertical Axis:** Lists the individual project activities/tasks.  
**Key Uses:** Tracks task progress against planned schedules, visualizes task durations, and identifies task overlaps and dependencies.

---

### **Q3. State any two advantages of a Gantt chart.**
**Answer:**  
1. **Simple and Visual:** Easy to construct, understand, and interpret by both technical teams and non-technical stakeholders.
2. **Progress Tracking:** Provides a clear visual baseline to compare actual progress against planned timelines, instantly highlighting schedule slippages.

---

### **Q4. Define Critical Path.**
**Answer:**  
The **Critical Path** is the longest continuous sequence of dependent activities in a project network diagram that determines the minimum total time required to complete the project. Activities on the critical path have **zero total float** (slack); any delay in these activities directly delays the project completion date.

---

### **Q5. What is Total Float? State its significance.**
**Answer:**  
**Total Float (or Total Slack)** is the maximum amount of time an activity can be delayed from its Early Start date without delaying the overall project completion date.  
$$\text{Total Float (TF)} = LST - EST \quad \text{or} \quad LFT - EFT$$  
* **Significance:** Non-critical activities have $TF > 0$, giving project managers schedule flexibility to reallocate resources to critical tasks.

---

### **Q6. Define PERT.**
**Answer:**  
**PERT (Program Evaluation and Review Technique)** is a probabilistic network management technique used for managing projects with uncertain activity durations (e.g., R&D, unique construction, or software development). It uses three time estimates (Optimistic, Most Likely, and Pessimistic) to calculate the expected completion duration of activities.

---

### **Q7. Define CPM.**
**Answer:**  
**CPM (Critical Path Method)** is a deterministic network management technique used for projects with predictable and well-defined activity durations (e.g., standard civil construction or manufacturing). It focuses on optimizing the trade-off between project duration and total direct cost (project crashing).

---

### **Q8. Explain the three time estimates used in PERT along with the formula for expected time ($t_e$).**
**Answer:**  
PERT uses three time estimates for each activity to model uncertainty:
1. **Optimistic Time ($a$ or $t_o$):** Minimum time required if execution goes perfectly.
2. **Most Likely Time ($m$ or $t_m$):** Best estimate of execution time under normal conditions.
3. **Pessimistic Time ($b$ or $t_p$):** Maximum time required if severe difficulties arise.

$$\text{Expected Time } (t_e) = \frac{t_o + 4t_m + t_p}{6}$$

---

### **Q9. What is resource leveling? Justify why it is important for project feasibility.**
**Answer:**  
**Resource Leveling** is a schedule optimization technique that adjusts activity start and finish dates within available floats to smooth out peak resource demands, keeping resource consumption below fixed maximum availability thresholds.  
* **Importance for Feasibility:** It prevents unrealistic resource over-allocations (e.g., requiring 15 workers when only 10 exist), ensuring that the schedule is practically achievable without causing worker burnout or equipment failure.

---

### **Q10. Explain the term resource scheduling.**
**Answer:**  
**Resource Scheduling** is the process of identifying, allocating, and assigning necessary project resources (human labor, equipment, materials, and finances) to specific project tasks over defined time periods, ensuring resources are deployed at the right time in required quantities.

---

### **Q11. What is project crashing?**
**Answer:**  
**Project Crashing** is a schedule compression technique used to shorten the overall project duration with the minimum incremental cost. It involves adding additional resources (e.g., extra labor, overtime work, or specialized equipment) to critical path activities that have the lowest crash cost per unit time.

---

### **Q12. Give four reasons why CPM is useful in project management.**
**Answer:**  
1. **Identifies Critical Tasks:** Highlights activities that directly control the overall project completion date.
2. **Enables Float Calculation:** Quantifies schedule flexibility for non-critical activities.
3. **Optimizes Project Cost and Time:** Facilitates time-cost trade-off analysis through project crashing.
4. **Improves Monitoring:** Provides a clear network framework to track progress against early and late schedule baselines.

---

### **Q13. Scenario Application: A software development team wants to display project activities along a timeline to track progress and deadlines. Which tool would you recommend and why?**
**Answer:**  
* **Recommendation:** **Gantt Chart**
* **Justification:** A Gantt chart visually maps software tasks (sprints, testing, deployment) on a clear linear timeline. It easily communicates start/finish dates, overlaps, and real-time progress updates to both developers and client stakeholders without complex mathematical calculations.
