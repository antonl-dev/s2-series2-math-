# Module 5.6: The Naïve Bayes Model

## 1. Introduction to the Naïve Bayes Classifier
The **Naïve Bayes Classifier** is a simple, fast, and highly effective **probabilistic supervised classification algorithm** based directly on **Bayes' Theorem** combined with a strong (**"naïve"**) assumption of **conditional independence** between every pair of features given the class label.

[Click here to see the diagram for Naive Bayes Classifier Conditional Independence Structure](https://www.google.com/search?udm=2&q=Naive+Bayes+Classifier+Bayesian+Network+Structure+Class+and+Features+diagram)

```text
                  +-------------------+
                  |    Class Label    |
                  |        (C_k)      |
                  +-------------------+
                   /    |       |    \
                  /     |       |     \
                 v      v       v      v
              ( x1 )  ( x2 )  (...)  ( xd )
         [Features are Conditionally Independent given C_k]
```

---

## 2. Why is it Called "Naïve"? (The Conditional Independence Assumption)
Suppose a data instance has $d$ features $\mathbf{X} = (x_1, x_2, \dots, x_d)$ and we want to compute the posterior probability $P(C_k \mid x_1, x_2, \dots, x_d)$ using Bayes' Rule:

$$
P(C_k \mid x_1, x_2, \dots, x_d) = \dfrac{P(x_1, x_2, \dots, x_d \mid C_k) \cdot P(C_k)}{P(x_1, x_2, \dots, x_d)}
$$

As seen in Module `5.5`, estimating the joint probability $P(x_1, x_2, \dots, x_d \mid C_k)$ directly requires an exponential number of parameters.

### The "Naïve" Assumption:
The Naïve Bayes model assumes that **given the class label $C_k$, the value of any feature $x_i$ is conditionally independent of the value of every other feature $x_j$ ($j \neq i$)**:

$$
P(x_1, x_2, \dots, x_d \mid C_k) = P(x_1 \mid C_k) \times P(x_2 \mid C_k) \times \dots \times P(x_d \mid C_k) = \prod_{i=1}^{d} P(x_i \mid C_k)
$$

* **Why "Naïve"?** Because in real life, features are rarely completely independent (e.g., in weather data, `Humidity` and `Sunny` are correlated; in emails, the words `"free"` and `"offer"` often appear together). Yet, despite this simplified assumption, Naïve Bayes performs remarkably well in practice!

---

## 3. Mathematical Formula & Step-by-Step Working of Naïve Bayes

### Naïve Bayes MAP Decision Rule:
Substituting the factored likelihood into the Maximum A Posteriori (MAP) rule:

$$
\text{Score}(C_k \mid \mathbf{X}) = P(\mathbf{X} \mid C_k) \cdot P(C_k) = P(C_k) \prod_{i=1}^{d} P(x_i \mid C_k)
$$

$$
\mathbf{\hat{y} = \arg\max_{C_k \in C} \; \left[ P(C_k) \prod_{i=1}^{d} P(x_i \mid C_k) \right]}
$$

And the normalized **Posterior Probability** of class $C_k$ is:

$$
P(C_k \mid \mathbf{X}) = \dfrac{P(C_k) \prod_{i=1}^{d} P(x_i \mid C_k)}{\sum_{j=1}^{K} \left[ P(C_j) \prod_{i=1}^{d} P(x_i \mid C_j) \right]}
$$

---

### Step-by-Step Procedure to Solve Any Naïve Bayes Table Problem in Exams:
1. **Step 1 (Compute Class Priors $P(C_k)$):**
   Count how many training rows belong to each class $C_k$ out of total rows $N$:

$$
P(C_k) = \dfrac{\text{Count}(C_k)}{N}
$$

2. **Step 2 (Compute Conditional Feature Likelihoods $P(x_i \mid C_k)$):**
   For each feature value $x_i$ in the test query, count how many times $x_i$ appears among the rows of class $C_k$:

$$
P(x_i \mid C_k) = \dfrac{\text{Count}(x_i \text{ and } C_k)}{\text{Count}(C_k)}
$$

3. **Step 3 (Compute Naïve Bayes Score for Each Class):**
   Multiply the prior and all feature likelihoods for each class:

$$
\text{Score}(C_k) = P(C_k) \times P(x_1 \mid C_k) \times P(x_2 \mid C_k) \times \dots \times P(x_d \mid C_k)
$$

4. **Step 4 (Compare & Predict Class):**
   Assign the test instance to the class $C_k$ with the **highest score** (and normalize by the sum of scores if posterior probability is requested).

---

## 4. The Zero-Probability Problem & Laplace (Add-One) Smoothing

### A. What is the Zero-Probability Problem?
Suppose a test sample contains a feature value $x_m$ that **never appeared in class $C_k$ in the small training set**, so $\text{Count}(x_m, C_k) = 0 \implies P(x_m \mid C_k) = 0$.
* When we compute the Naïve Bayes product:

$$
\text{Score}(C_k) = P(C_k) \times P(x_1 \mid C_k) \times \dots \times \mathbf{0} \times \dots \times P(x_d \mid C_k) = \mathbf{0}
$$

* **Result:** A single zero conditional probability **wipes out all the information** from all the other features and forces the entire posterior probability of class $C_k$ to **$0$**!

### B. Solution: Laplace (Add-One) Smoothing
To prevent zero probabilities, **Laplace Smoothing** adds a small pseudocount of **$1$** to every numerator and adds the number of possible feature outcomes **$V$** (or **$2$** for binary presence/absence) to the denominator:

$$
P_{\text{Laplace}}(x_i \mid C_k) = \dfrac{\text{Count}(x_i, C_k) + 1}{n_c + V}
$$

* Where $n_c = \text{Count}(C_k)$ is the number of training examples in class $C_k$, and $V$ is the number of possible distinct values of that attribute ($V = 2$ for binary features).

## 5. Solved University & Internal Exam Questions

### Question 1 [End Semester Exam - Nov 2025, Part B, Q20(b) (5 Marks)] & [Series Test-II, Part B, Q12(a) (4 Marks)]
> **Consider the training data in the following table where `Play` is a class attribute. In the table, the `Humidity` attribute has values `"L"` (for low) or `"H"` (for high), `Sunny` has values `"Y"` (for yes) or `"N"` (for no), `Wind` has values `"S"` (for strong) or `"W"` (for weak), and `Play` has values `"Yes"` or `"No"`.**
> 
> | Row | Humidity | Sunny | Wind | Play (Class) |
> | :---: | :---: | :---: | :---: | :---: |
> | 1 | L | N | S | **No** |
> | 2 | H | N | W | **Yes** |
> | 3 | H | Y | S | **Yes** |
> | 4 | H | N | W | **Yes** |
> | 5 | L | Y | S | **No** |
> 
> **What is the class label for the following day $(\text{Humidity} = \text{L}, \; \text{Sunny} = \text{N}, \; \text{Wind} = \text{W})$, according to naïve Bayesian classification?**

#### **Solution:**

**Given Test Instance to Classify:**

$$
\mathbf{X} = (\text{Humidity} = \text{L}, \; \text{Sunny} = \text{N}, \; \text{Wind} = \text{W})
$$

---

#### **Step 1: Compute Class Prior Probabilities $P(\text{Play} = \text{Yes})$ and $P(\text{Play} = \text{No})$**
Total number of training examples $N = 5$:
* Number of rows where $\text{Play} = \text{Yes}$: **$3$** (Rows 2, 3, 4)

$$
P(\text{Play} = \text{Yes}) = \dfrac{3}{5} = \mathbf{0.6}
$$

* Number of rows where $\text{Play} = \text{No}$: **$2$** (Rows 1, 5)

$$
P(\text{Play} = \text{No}) = \dfrac{2}{5} = \mathbf{0.4}
$$

---

#### **Step 2: Compute Conditional Probabilities $P(x_i \mid C_k)$ (Standard / Without Smoothing)**

**1. For Class $\text{Play} = \text{Yes}$ ($3$ rows: `[H, N, W]`, `[H, Y, S]`, `[H, N, W]`):**
* $\displaystyle P(\text{Humidity} = \text{L} \mid \text{Yes}) = \frac{0}{3} = \mathbf{0}$ *(since all 3 `Yes` rows have $\text{Humidity} = \text{H}$)*
* $\displaystyle P(\text{Sunny} = \text{N} \mid \text{Yes}) = \frac{2}{3} \approx \mathbf{0.667}$ *(Rows 2 and 4 have $\text{Sunny} = \text{N}$)*
* $\displaystyle P(\text{Wind} = \text{W} \mid \text{Yes}) = \frac{2}{3} \approx \mathbf{0.667}$ *(Rows 2 and 4 have $\text{Wind} = \text{W}$)*

**2. For Class $\text{Play} = \text{No}$ ($2$ rows: `[L, N, S]`, `[L, Y, S]`):**
* $\displaystyle P(\text{Humidity} = \text{L} \mid \text{No}) = \frac{2}{2} = \mathbf{1.0}$ *(both `No` rows have $\text{Humidity} = \text{L}$)*
* $\displaystyle P(\text{Sunny} = \text{N} \mid \text{No}) = \frac{1}{2} = \mathbf{0.5}$ *(Row 1 has $\text{Sunny} = \text{N}$)*
* $\displaystyle P(\text{Wind} = \text{W} \mid \text{No}) = \frac{0}{2} = \mathbf{0}$ *(both `No` rows have $\text{Wind} = \text{S}$)*

---

#### **Step 3: Compute Naïve Bayes Scores Without Smoothing**
* **For $\text{Play} = \text{Yes}$:**

$$
P(\mathbf{X} \mid \text{Yes}) P(\text{Yes}) = \dfrac{3}{5} \times \left(\dfrac{0}{3} \times \dfrac{2}{3} \times \dfrac{2}{3}\right) = \mathbf{0}
$$

* **For $\text{Play} = \text{No}$:**

$$
P(\mathbf{X} \mid \text{No}) P(\text{No}) = \dfrac{2}{5} \times \left(\dfrac{2}{2} \times \dfrac{1}{2} \times \dfrac{0}{2}\right) = \mathbf{0}
$$

*(**Important Observation:** Without smoothing, both classes have a zero-frequency feature—$P(\text{Humidity}=\text{L}\mid\text{Yes})=0$ and $P(\text{Wind}=\text{W}\mid\text{No})=0$—making both unsmoothed scores equal to $0$! Therefore, we apply **Laplace (Add-1) Smoothing** with $V = 2$ possible values per binary attribute to break the zero-probability deadlock!)*

---

#### **Step 4: Recompute Conditional Probabilities Using Laplace (Add-1) Smoothing**
Formula: $\displaystyle P(x_i \mid C_k) = \frac{\text{count} + 1}{n_c + 2}$ (since each attribute is binary, $V = 2$):

**1. For Class $\text{Play} = \text{Yes}$ ($n_{\text{Yes}} = 3$, denominator $= 3 + 2 = 5$):**
* $\displaystyle P(\text{Humidity} = \text{L} \mid \text{Yes}) = \frac{0 + 1}{3 + 2} = \mathbf{\frac{1}{5} = 0.2}$
* $\displaystyle P(\text{Sunny} = \text{N} \mid \text{Yes}) = \frac{2 + 1}{3 + 2} = \mathbf{\frac{3}{5} = 0.6}$
* $\displaystyle P(\text{Wind} = \text{W} \mid \text{Yes}) = \frac{2 + 1}{3 + 2} = \mathbf{\frac{3}{5} = 0.6}$

**Naïve Bayes Score for $\text{Play} = \text{Yes}$:**

$$
\text{Score}(\text{Yes}) = P(\text{Yes}) \times P(\text{L} \mid \text{Yes}) \times P(\text{N} \mid \text{Yes}) \times P(\text{W} \mid \text{Yes})
$$

$$
\text{Score}(\text{Yes}) = 0.6 \times 0.2 \times 0.6 \times 0.6 = \mathbf{0.0432} \quad \left(\text{or } \dfrac{3}{5} \times \dfrac{1}{5} \times \dfrac{3}{5} \times \dfrac{3}{5} = \dfrac{27}{625}\right)
$$

**2. For Class $\text{Play} = \text{No}$ ($n_{\text{No}} = 2$, denominator $= 2 + 2 = 4$):**
* $\displaystyle P(\text{Humidity} = \text{L} \mid \text{No}) = \frac{2 + 1}{2 + 2} = \mathbf{\frac{3}{4} = 0.75}$
* $\displaystyle P(\text{Sunny} = \text{N} \mid \text{No}) = \frac{1 + 1}{2 + 2} = \mathbf{\frac{2}{4} = 0.50}$
* $\displaystyle P(\text{Wind} = \text{W} \mid \text{No}) = \frac{0 + 1}{2 + 2} = \mathbf{\frac{1}{4} = 0.25}$

**Naïve Bayes Score for $\text{Play} = \text{No}$:**

$$
\text{Score}(\text{No}) = P(\text{No}) \times P(\text{L} \mid \text{No}) \times P(\text{N} \mid \text{No}) \times P(\text{W} \mid \text{No})
$$

$$
\text{Score}(\text{No}) = 0.4 \times 0.75 \times 0.50 \times 0.25 = \mathbf{0.0375} \quad \left(\text{or } \dfrac{2}{5} \times \dfrac{3}{4} \times \dfrac{2}{4} \times \dfrac{1}{4} = \dfrac{12}{320} = \dfrac{3}{80}\right)
$$

---

#### **Step 5: Final Comparison & Predicted Class Label**
* $\text{Score}(\text{Play} = \text{Yes}) = \mathbf{0.0432}$ (Posterior probability $\displaystyle = \frac{0.0432}{0.0432 + 0.0375} \approx \mathbf{53.53\%}$)
* $\text{Score}(\text{Play} = \text{No}) = \mathbf{0.0375}$ (Posterior probability $\displaystyle = \frac{0.0375}{0.0432 + 0.0375} \approx \mathbf{46.47\%}$)

Since $\text{Score}(\text{Play} = \text{Yes}) = 0.0432 > \text{Score}(\text{Play} = \text{No}) = 0.0375$:
✅ **Predicted Class Label:** **`Play = Yes`**

### Question 2 [Series Test-II, Part B, Q11(a) (4 Marks)]
> **A spam filter is trained on $10$ e-mails ($4$ Spam, $6$ Ham). The number of e-mails in each class containing a word is:**
> 
> | Word | Spam ($4$ e-mails) | Ham ($6$ e-mails) |
> | :--- | :---: | :---: |
> | `offer` | $3$ | $1$ |
> | `meeting` | $0$ | $4$ |
> 
> **A new e-mail contains both `"offer"` and `"meeting"`. Consider only these two words.**  
> **(i) Compute the Naive Bayes scores for both classes without smoothing and comment on the result.**  
> **(ii) Recompute using Laplace (add-one) smoothing, $P(w \mid c) = (\text{count} + 1)/(n_c + 2)$, where $n_c$ is the number of e-mails in class $c$, and find the predicted class with its posterior probability.**

#### **Solution:**

**Step 0: Class Prior Probabilities ($N = 10$ e-mails):**
* $\displaystyle P(\text{Spam}) = \frac{4}{10} = \mathbf{0.4}$
* $\displaystyle P(\text{Ham}) = \frac{6}{10} = \mathbf{0.6}$

---

#### **Part (i): Naïve Bayes Scores WITHOUT Smoothing & Comment**

**1. Conditional Probabilities Without Smoothing ($\displaystyle P(w \mid c) = \frac{\text{count}}{n_c}$):**
* **For `Spam` ($n_{\text{Spam}} = 4$):**
  * $\displaystyle P(\text{offer} \mid \text{Spam}) = \frac{3}{4} = 0.75$
  * $\displaystyle P(\text{meeting} \mid \text{Spam}) = \frac{0}{4} = \mathbf{0}$
* **For `Ham` ($n_{\text{Ham}} = 6$):**
  * $\displaystyle P(\text{offer} \mid \text{Ham}) = \frac{1}{6}$
  * $\displaystyle P(\text{meeting} \mid \text{Ham}) = \frac{4}{6} = \frac{2}{3}$

**2. Unsmoothed Naïve Bayes Scores:**
* **$\text{Score}(\text{Spam})$:**

$$
\text{Score}(\text{Spam}) = P(\text{Spam}) \times P(\text{offer} \mid \text{Spam}) \times P(\text{meeting} \mid \text{Spam}) = 0.4 \times 0.75 \times 0 = \mathbf{0}
$$

* **$\text{Score}(\text{Ham})$:**

$$
\text{Score}(\text{Ham}) = P(\text{Ham}) \times P(\text{offer} \mid \text{Ham}) \times P(\text{meeting} \mid \text{Ham}) = 0.6 \times \dfrac{1}{6} \times \dfrac{4}{6} = 0.1 \times \dfrac{2}{3} = \mathbf{\dfrac{1}{15} \approx 0.0667}
$$

**3. Comment on the Result:**
* Because the word `"meeting"` occurred $0$ times in the $4$ training Spam e-mails, $P(\text{meeting} \mid \text{Spam}) = 0$.
* When multiplied in the Naïve Bayes product, this single zero probability **completely wipes out** the strong Spam evidence from the word `"offer"` ($3/4 = 75\%$), forcing $\text{Score}(\text{Spam}) = 0$ and making $P(\text{Spam} \mid \mathbf{X}) = 0\%$. This illustrates the **Zero-Probability Problem** in unsmoothed Naïve Bayes.

---

#### **Part (ii): Recompute Using Laplace (Add-One) Smoothing & Find Posterior Probability**

Using the given Laplace formula $\displaystyle P(w \mid c) = \frac{\text{count} + 1}{n_c + 2}$:

**1. Smoothed Conditional Probabilities & Score for `Spam` ($n_{\text{Spam}} = 4, \; n_{\text{Spam}} + 2 = 6$):**
* $\displaystyle P(\text{offer} \mid \text{Spam}) = \frac{3 + 1}{4 + 2} = \frac{4}{6} = \frac{2}{3}$
* $\displaystyle P(\text{meeting} \mid \text{Spam}) = \frac{0 + 1}{4 + 2} = \frac{1}{6}$
* **Smoothed $\text{Score}(\text{Spam})$:**

$$
\text{Score}(\text{Spam}) = P(\text{Spam}) \times P(\text{offer} \mid \text{Spam}) \times P(\text{meeting} \mid \text{Spam})
$$

$$
\text{Score}(\text{Spam}) = \dfrac{4}{10} \times \dfrac{4}{6} \times \dfrac{1}{6} = \dfrac{16}{360} = \dfrac{2}{45} \approx \mathbf{0.0444}
$$

**2. Smoothed Conditional Probabilities & Score for `Ham` ($n_{\text{Ham}} = 6, \; n_{\text{Ham}} + 2 = 8$):**
* $\displaystyle P(\text{offer} \mid \text{Ham}) = \frac{1 + 1}{6 + 2} = \frac{2}{8} = \frac{1}{4} = 0.25$
* $\displaystyle P(\text{meeting} \mid \text{Ham}) = \frac{4 + 1}{6 + 2} = \frac{5}{8} = 0.625$
* **Smoothed $\text{Score}(\text{Ham})$:**

$$
\text{Score}(\text{Ham}) = P(\text{Ham}) \times P(\text{offer} \mid \text{Ham}) \times P(\text{meeting} \mid \text{Ham})
$$

$$
\text{Score}(\text{Ham}) = \dfrac{6}{10} \times \dfrac{2}{8} \times \dfrac{5}{8} = \dfrac{60}{640} = \dfrac{3}{32} = \mathbf{0.09375}
$$

**3. Predicted Class and Normalized Posterior Probability:**
* Since $\text{Score}(\text{Ham}) = 0.09375 > \text{Score}(\text{Spam}) = 0.0444$, the **predicted class is `Ham`**.
* **Total Evidence $P(\mathbf{X})$:**

$$
P(\mathbf{X}) = \text{Score}(\text{Ham}) + \text{Score}(\text{Spam}) = \dfrac{3}{32} + \dfrac{2}{45} = \dfrac{135 + 64}{1440} = \dfrac{199}{1440} \approx 0.13819
$$

* **Posterior Probability of Predicted Class (`Ham`):**

$$
P(\text{Ham} \mid \mathbf{X}) = \dfrac{\text{Score}(\text{Ham})}{\text{Score}(\text{Ham}) + \text{Score}(\text{Spam})} = \dfrac{3/32}{199/1440} = \dfrac{135}{199} \approx \mathbf{0.6784 \;\; (67.84\%)}
$$

  *(And $\displaystyle P(\text{Spam} \mid \mathbf{X}) = \frac{64}{199} \approx \mathbf{0.3216 \;\; (32.16\%)}$).*
