# Module 5.7: Classifier Performance Measures and ROC Curves

## 1. The Confusion Matrix
To evaluate the performance of a supervised classification model on test data, we compare the **Actual (Ground-Truth) Class Labels ($y_{\text{true}}$)** against the **Predicted Class Labels ($y_{\text{pred}}$)** using a table called a **Confusion Matrix**.

For a binary classification problem with classes **Positive ($1$)** and **Negative ($0$)**:

[Click here to see the diagram for Confusion Matrix TP FP FN TN Precision Recall Accuracy](https://www.google.com/search?udm=2&q=Confusion+Matrix+TP+FP+FN+TN+Precision+Recall+diagram)

### Four Outcomes in a Binary Confusion Matrix:
1. **True Positive ($\text{TP}$):** Actual class is **Positive ($1$)**, and the classifier correctly predicted **Positive ($1$)** *(Hit)*.
2. **True Negative ($\text{TN}$):** Actual class is **Negative ($0$)**, and the classifier correctly predicted **Negative ($0$)** *(Correct Rejection)*.
3. **False Positive ($\text{FP}$ — Type I Error / False Alarm):** Actual class is **Negative ($0$)**, but the classifier wrongly predicted **Positive ($1$)** *(e.g., a healthy patient wrongly told they have flu)*.
4. **False Negative ($\text{FN}$ — Type II Error / Miss):** Actual class is **Positive ($1$)**, but the classifier wrongly predicted **Negative ($0$)** *(e.g., a sick patient wrongly told they are healthy)*.

---

### Standard Layout vs. Python `scikit-learn` Layout:

#### A. Standard Textbook Layout (Positive First):
| | **Predicted Positive ($+$)** | **Predicted Negative ($-$)** | **Row Total** |
| :--- | :---: | :---: | :---: |
| **Actual Positive ($+$)** | **$\text{TP}$** | **$\text{FN}$** | $P = \text{TP} + \text{FN}$ *(Total Actual Positives)* |
| **Actual Negative ($-$)** | **$\text{FP}$** | **$\text{TN}$** | $N = \text{FP} + \text{TN}$ *(Total Actual Negatives)* |
| **Column Total** | $\text{TP} + \text{FP}$ *(Total Pred $+$)* | $\text{FN} + \text{TN}$ *(Total Pred $-$)* | $\text{Total } = \text{TP} + \text{TN} + \text{FP} + \text{FN}$ |

#### B. Python `sklearn.metrics.confusion_matrix(y_true, y_pred)` Layout ($0$ First, $1$ Second):
In `scikit-learn`, class labels are sorted in ascending order (`0` then `1`), so Row $0$/Col $0$ is Negative ($0$) and Row $1$/Col $1$ is Positive ($1$):
$$\text{sklearn\_cm} = \begin{bmatrix} \mathbf{TN} & \mathbf{FP} \\ \mathbf{FN} & \mathbf{TP} \end{bmatrix} \begin{array}{l} \leftarrow \text{Actual } 0 \text{ (Negative)} \\ \leftarrow \text{Actual } 1 \text{ (Positive)} \end{array}$$

## 2. Classifier Performance Metrics (Formulas & Interpretations)

### 1. Accuracy
The proportion of total predictions (both positive and negative) that the classifier got right:
$$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}$$
* **Error Rate (Misclassification Rate):** $\text{Error Rate} = 1 - \text{Accuracy} = \frac{\text{FP} + \text{FN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}$.
* **⚠️ Limitation of Accuracy (The Class Imbalance / Accuracy Paradox):**
  When one class is much larger than the other (e.g., $90\%$ Negative and $10\%$ Positive), a classifier can achieve high accuracy simply by predicting **Negative ($0$)** most of the time (resulting in a very large $\text{TN}$), even if its ability to detect actual Positive cases ($\text{Recall}$) is poor!

---

### 2. Precision (Positive Predictive Value — PPV)
$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$
* **Question it answers:** *"Out of all instances that the model **predicted as Positive** ($\text{TP} + \text{FP}$), what fraction are **actually Positive** ($\text{TP}$)?"*
* **Measures:** Exactness / reliability of positive predictions (penalizes **False Positives $\text{FP}$**).
* **When High Precision is Critical:** **Email Spam Filtering** (you don't want an important work email—a False Positive—to be sent to the Spam folder!).

---

### 3. Recall (Sensitivity / Hit Rate / True Positive Rate — $\text{TPR}$)
$$\text{Recall (TPR)} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$
* **Question it answers:** *"Out of all instances that are **actually Positive** in reality ($\text{TP} + \text{FN}$), what fraction did the model **successfully detect** ($\text{TP}$)?"*
* **Measures:** Completeness / sensitivity of positive detection (penalizes **False Negatives $\text{FN}$**).
* **When High Recall is Critical:** **Medical Disease Screening (Cancer / Flu detection)** (missing a sick patient—a False Negative—can be fatal!).

---

### 4. Specificity (True Negative Rate — $\text{TNR}$) and False Positive Rate ($\text{FPR}$)
* **Specificity ($\text{TNR}$):** Proportion of actual negatives correctly identified as negative:
  $$\text{Specificity (TNR)} = \frac{\text{TN}}{\text{TN} + \text{FP}}$$
* **False Positive Rate ($\text{FPR}$ / Fall-Out):** Proportion of actual negatives wrongly classified as positive:
  $$\text{FPR} = \frac{\text{FP}}{\text{FP} + \text{TN}} = 1 - \text{Specificity}$$

---

### 5. $F_1$-Score (Harmonic Mean of Precision and Recall)
Because there is a natural trade-off between Precision and Recall, the **$F_1$-Score** combines both into a single balanced metric by taking their **Harmonic Mean**:
$$F_1\text{-Score} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\,\text{TP}}{2\,\text{TP} + \text{FP} + \text{FN}}$$
* *Why Harmonic Mean instead of Arithmetic Mean?* Because the harmonic mean punishes extreme values: if either $\text{Precision} = 0$ or $\text{Recall} = 0$, then $F_1 = 0$ (whereas arithmetic mean would give $0.5$).

## 3. ROC Curves and Area Under the Curve (AUC)

### A. What is an ROC Curve?
Many classifiers (like Logistic Regression, Naïve Bayes, Neural Networks, and SVMs) output a continuous **probability or confidence score $s \in [0, 1]$**, and predict **Positive ($+$)** if $\text{Score} \ge \text{Threshold } \theta$.

A **Receiver Operating Characteristic (ROC) Curve** is a 2D graphical plot that illustrates the diagnostic ability of a binary classifier as its **classification threshold $\theta$ is varied across all possible values**:
* **Vertical Axis ($Y$-axis):** **True Positive Rate ($\text{TPR} = \text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$)**
* **Horizontal Axis ($X$-axis):** **False Positive Rate ($\text{FPR} = \frac{\text{FP}}{\text{FP} + \text{TN}}$)**

[Click here to see the diagram for ROC Curve TPR vs FPR and AUC Area Under Curve](https://www.google.com/search?udm=2&q=ROC+Curve+TPR+vs+FPR+AUC+Area+Under+Curve+diagram)

```text
  TPR (Recall)
  1.0 +------------------------------* (1,1) [Threshold = 0: Predict All +]
      |       Ideal (0,1)       *  /
  0.8 +      *               *   /
      |    *  <-- ROC Curve    /
  0.6 +   *                  /  <-- Diagonal Line (TPR = FPR)
      |  *    AUC = Area   /        Random Classifier (AUC = 0.5)
  0.4 + *     under curve/
      |*               /
  0.2 +              /
      |            /
  0.0 +----------+-------------------+--> FPR (1 - Specificity)
     0.0        0.5                 1.0
  (0,0) [Threshold > 1: Predict All -]
```

### B. Important Landmarks on the ROC Space
1. **Bottom-Left Corner $(0, 0)$:** Obtained when Threshold $\theta > \max(\text{score})$. The classifier predicts **every sample as Negative**, so $\text{TP} = 0, \text{FP} = 0 \implies (\text{FPR}, \text{TPR}) = (0, 0)$.
2. **Top-Right Corner $(1, 1)$:** Obtained when Threshold $\theta \le \min(\text{score})$. The classifier predicts **every sample as Positive**, so $\text{FN} = 0, \text{TN} = 0 \implies (\text{FPR}, \text{TPR}) = (1, 1)$.
3. **Top-Left Corner $(0, 1)$ — Perfect Classifier:** $\text{FPR} = 0$ ($0\%$ false alarms) and $\text{TPR} = 1$ ($100\%$ recall). The closer an ROC curve hugs the top-left corner $(0, 1)$, the better the classifier!
4. **Main Diagonal Line ($\text{TPR} = \text{FPR}$) — Random Guessing:** Represents a worthless classifier that flips a coin ($\text{AUC} = 0.5$).

---

### C. Area Under the ROC Curve (AUC-ROC)
* **Definition:** **AUC** is the total geometric area under the ROC curve inside the unit square $[0, 1] \times [0, 1]$.
  * **$\text{AUC} = 1.0$:** Perfect classifier (separates all positives above all negatives).
  * **$0.5 < \text{AUC} < 1.0$:** Useful classifier (better than random chance).
  * **$\text{AUC} = 0.5$:** Random guessing (no discriminative power).
  * **$\text{AUC} < 0.5$:** Worse than random (predictions are inverted).
* **Probabilistic Interpretation of AUC (Exam Favorite!):**
  **The AUC of a classifier is equal to the probability that the classifier will assign a higher score to a randomly chosen Positive instance than to a randomly chosen Negative instance:**
  $$\text{AUC} = P\big(\text{Score}(\mathbf{x}^+) > \text{Score}(\mathbf{x}^-)\big)$$
  Consequently, given $P$ positive samples and $N$ negative samples ($P \times N$ total pairs), AUC can also be computed by counting how many $(x^+, x^-)$ pairs have $\text{Score}(x^+) > \text{Score}(x^-)$ divided by $P \times N$, or by the **Trapezoidal / Rectangle Area Rule** under the ROC curve!

### Question 1 [End Semester Exam - Nov 2025, Part A, Q9 (2 Marks)]
> **State and explain precision and recall.**

#### **Solution:**
1. **Precision:**
   * **Definition:** Precision is the ratio of correctly predicted positive observations ($\text{TP}$) to the **total number of observations predicted as positive** ($\text{TP} + \text{FP}$):
     $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$
   * **Explanation:** It measures the **exactness or reliability** of positive predictions—i.e., when the model predicts a sample is positive, how often is it right? High precision means a low False Positive ($\text{FP}$) rate.
2. **Recall (Sensitivity / True Positive Rate):**
   * **Definition:** Recall is the ratio of correctly predicted positive observations ($\text{TP}$) to the **total number of actual positive observations** in the dataset ($\text{TP} + \text{FN}$):
     $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$
   * **Explanation:** It measures the **completeness or sensitivity** of the classifier—i.e., out of all actual positive cases present in the data, what fraction did the model successfully detect? High recall means a low False Negative ($\text{FN}$) rate.

### Question 2 [End Semester Exam - Nov 2025, Part B, Q20(a) (3 Marks)]
> **Suppose $10000$ patients get tested for flu; out of them, $9000$ are actually healthy and $1000$ are actually sick. For the sick people, a test was positive for $620$ and negative for $380$. For the healthy people, the same test was positive for $180$ and negative for $8820$. Construct a confusion matrix for the data and compute the precision and recall for the data.**

#### **Solution:**

**Step 1: Identify $\text{TP}, \text{FN}, \text{FP}, \text{TN}$**
Taking **"Sick (Flu)" as the Positive ($+$) class** and **"Healthy" as the Negative ($-$) class**:
* **Actual Positive (Sick) $= 1000$ patients:**
  * Sick patients who tested Positive $\implies \mathbf{\text{TP} = 620}$
  * Sick patients who tested Negative $\implies \mathbf{\text{FN} = 380}$
* **Actual Negative (Healthy) $= 9000$ patients:**
  * Healthy patients who tested Positive $\implies \mathbf{\text{FP} = 180}$
  * Healthy patients who tested Negative $\implies \mathbf{\text{TN} = 8820}$

**Step 2: Construct the Confusion Matrix**

| | **Predicted Positive (Test $+$)** | **Predicted Negative (Test $-$)** | **Total Actual** |
| :--- | :---: | :---: | :---: |
| **Actual Positive (Sick)** | **$\text{TP} = 620$** | **$\text{FN} = 380$** | $1000$ |
| **Actual Negative (Healthy)** | **$\text{FP} = 180$** | **$\text{TN} = 8820$** | $9000$ |
| **Total Predicted** | $800$ | $9200$ | **$10000$** |

**Step 3: Compute Precision and Recall**
1. **Precision:**
   $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} = \frac{620}{620 + 180} = \frac{620}{800} = \mathbf{0.775 \;\; (77.5\%)}$$
2. **Recall:**
   $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}} = \frac{620}{620 + 380} = \frac{620}{1000} = \mathbf{0.62 \;\; (62.0\%)}$$

### Question 3 [Series Test-II, Part A, Q6 (2 Marks)]
> **A classifier is evaluated on $200$ samples, of which $40$ are actually positive. Its precision is $0.8$ and its recall is $0.5$. Determine TP, FP, FN and TN, and compute the accuracy. Comment on why the accuracy looks better than the recall.**

#### **Solution:**

**Step 1: Determine $\text{TP}, \text{FN}, \text{FP}, \text{TN}$**
* Total samples $= 200$.
* Actual Positives ($\text{TP} + \text{FN}$) $= 40 \implies$ Actual Negatives ($\text{FP} + \text{TN}$) $= 200 - 40 = 160$.
* **From $\text{Recall} = 0.5$:**
  $$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}} = \frac{\text{TP}}{40} = 0.5 \implies \mathbf{\text{TP} = 20}$$
  $$\text{FN} = 40 - \text{TP} = 40 - 20 = \mathbf{\text{FN} = 20}$$
* **From $\text{Precision} = 0.8$:**
  $$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}} \implies 0.8 = \frac{20}{20 + \text{FP}} \implies 20 + \text{FP} = \frac{20}{0.8} = 25 \implies \mathbf{\text{FP} = 5}$$
* **From Actual Negatives ($\text{FP} + \text{TN} = 160$):**
  $$\text{TN} = 160 - \text{FP} = 160 - 5 = \mathbf{\text{TN} = 155}$$

**Step 2: Compute Accuracy**
$$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{Total}} = \frac{20 + 155}{200} = \frac{175}{200} = \mathbf{0.875 \;\; (87.5\%)}$$

**Step 3: Comment on Why Accuracy ($87.5\%$) Looks Much Better Than Recall ($50\%$)**
* The dataset is **class-imbalanced**: $80\%$ of the samples ($160$ out of $200$) belong to the **Negative** class, and only $20\%$ ($40$ samples) are Positive.
* Because the classifier correctly identifies almost all of the majority Negative class ($\text{TN} = 155$ out of $160$), the large $\text{TN}$ count dominates the numerator of Accuracy ($\frac{20 + 155}{200} = 87.5\%$), masking the fact that the classifier missed half of the actual Positive cases ($\text{Recall} = 50\%$).

#### **Part (ii): Compute the AUC and Interpret It as a Probability**

**Method 1: Geometric Area Under the Step-Function ROC Curve**
Looking at the horizontal $\text{FPR}$ intervals of width $\Delta \text{FPR} = 0.25$ from $\text{FPR} = 0$ to $\text{FPR} = 1$:
1. Interval $\text{FPR} \in [0.00, 0.25]$: Height $\text{TPR} = 0.50 \implies \text{Area}_1 = 0.25 \times 0.50 = 0.1250$
2. Interval $\text{FPR} \in [0.25, 0.50]$: Height $\text{TPR} = 0.75 \implies \text{Area}_2 = 0.25 \times 0.75 = 0.1875$
3. Interval $\text{FPR} \in [0.50, 0.75]$: Height $\text{TPR} = 1.00 \implies \text{Area}_3 = 0.25 \times 1.00 = 0.2500$
4. Interval $\text{FPR} \in [0.75, 1.00]$: Height $\text{TPR} = 1.00 \implies \text{Area}_4 = 0.25 \times 1.00 = 0.2500$

$$\text{AUC} = 0.1250 + 0.1875 + 0.2500 + 0.2500 = \mathbf{0.8125} \quad \left(\text{or } \frac{13}{16}\right)$$

**Method 2: Pairwise Concordance Verification ($P \times N = 4 \times 4 = 16$ pairs)**
* Positive sample scores $= \{0.95, 0.85, 0.70, 0.45\}$; Negative sample scores $= \{0.78, 0.55, 0.30, 0.10\}$.
* Count how many negative samples each positive sample outranks:
  * Score $0.95 (+)$ beats all $4$ negatives $\{0.78, 0.55, 0.30, 0.10\} \to 4$
  * Score $0.85 (+)$ beats all $4$ negatives $\{0.78, 0.55, 0.30, 0.10\} \to 4$
  * Score $0.70 (+)$ beats $3$ negatives $\{0.55, 0.30, 0.10\} \to 3$
  * Score $0.45 (+)$ beats $2$ negatives $\{0.30, 0.10\} \to 2$
* Total correctly ranked pairs $= 4 + 4 + 3 + 2 = 13$ out of $16$ pairs:
  $$\text{AUC} = \frac{13}{16} = \mathbf{0.8125}$$

**Probabilistic Interpretation of $\text{AUC} = 0.8125$:**
* If we randomly pick one actually positive sample ($+$) and one actually negative sample ($-$), there is an **$81.25\%$ probability ($0.8125$)** that the classifier assigns a **higher score to the positive sample than to the negative sample**.

#### **Part (ii): Effect of Swapping Arguments `precision_score(y_pred, y_true)`**

1. **What Value is Printed and Why:**
   * **Value Printed:** **`0.8`** (which is the **original Recall**!).
   * **Why:** When `y_pred` and `y_true` are swapped, `y_pred` is treated as the ground truth and `y_true` as the prediction. Under this swap, $\text{TP}$ ($1 \to 1$) and $\text{TN}$ ($0 \to 0$) stay unchanged, but **$\text{FP}$ ($0 \to 1$) and $\text{FN}$ ($1 \to 0$) get swapped** ($\text{FP}_{\text{swapped}} = \text{FN} = 1$, and $\text{FN}_{\text{swapped}} = \text{FP} = 2$)!
   * Therefore, `precision_score(y_pred, y_true)` computes:
     $$\frac{\text{TP}}{\text{TP} + \text{FP}_{\text{swapped}}} = \frac{\text{TP}}{\text{TP} + \text{FN}} = \text{Recall} = \frac{4}{4 + 1} = \mathbf{0.8}$$
2. **Metrics Unaffected by Swapping `y_true` and `y_pred` (Symmetric Metrics):**
   Any metric whose formula is symmetric with respect to $\text{FP}$ and $\text{FN}$ (e.g., contains only $\text{FP} + \text{FN}$ or $\text{FP} \times \text{FN}$) is completely unaffected by swapping `y_true` and `y_pred`:
   * **$F_1$-Score:** $F_1 = \frac{2\,\text{TP}}{2\,\text{TP} + \text{FP} + \text{FN}} = \frac{8}{11} \approx 0.7273$ (since $\text{FP} + \text{FN} = \text{FN} + \text{FP}$).
   * **Accuracy:** $\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}} = \frac{7}{10} = 0.7$.
