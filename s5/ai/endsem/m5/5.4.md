# Module 5.4: Kernel Functions and Non-Linear Support Vector Machines

## 1. Motivation: The Problem of Non-Linearly Separable Data
In Modules `5.2` and `5.3`, we studied Linear SVMs, which construct a straight line or flat hyperplane ($\mathbf{w}^T\mathbf{x} + b = 0$) to separate two classes.

However, in many real-world classification tasks, the data is **non-linearly separable** in its original input space—meaning **no straight line or flat hyperplane can separate Class $+1$ from Class $-1$**!

### Illustrative Example (1D and 2D Non-Linear Data):
* **In 1D:** Suppose Class $+1$ points lie near the origin ($x \in [-1, +1]$) and Class $-1$ points lie on both outer sides ($x < -2$ and $x > +2$). No single point (1D hyperplane) can separate them!
  * **Transformation:** If we map each 1D point $x$ to a **2D space** using $\Phi(x) = (x, \; x^2)$, the points now lie on a parabola $y = x^2$, and a simple horizontal straight line $x_2 = 1.5$ cleanly separates Class $+1$ from Class $-1$!
* **In 2D:** Suppose Class $+1$ points form an inner circle ($x_1^2 + x_2^2 < R^2$) and Class $-1$ points form a surrounding outer ring ($x_1^2 + x_2^2 > R^2$). No straight line in 2D can separate concentric circles, but mapping to **3D** via $\Phi(x_1, x_2) = (x_1, \; x_2, \; x_1^2 + x_2^2)$ lifts the outer ring higher along the $z$-axis, allowing a **flat 2D plane** to slice right between the two classes!

[Click here to see the diagram for Non-Linear SVM Kernel Trick Mapping 2D Concentric Circles to 3D Plane](https://www.google.com/search?udm=2&q=SVM+Kernel+Trick+2D+non+linear+to+3D+linearly+separable+hyperplane+diagram)

* **Cover's Theorem (1965):** *"A complex pattern-classification problem, cast in a high-dimensional space non-linearly, is more likely to be linearly separable than in a low-dimensional space."*

## 2. What is a Kernel Function & The "Kernel Trick"?

### A. The Computational Bottleneck of Explicit Feature Mapping $\Phi(\mathbf{x})$
Suppose we transform our input vectors $\mathbf{x} \in \mathbb{R}^d$ into a high-dimensional feature space $\mathcal{H}$ using a non-linear mapping $\Phi : \mathbb{R}^d \to \mathcal{H}$, and then solve the SVM Dual Problem in $\mathcal{H}$:

$$
\max_{\boldsymbol{\alpha}} \sum_{i=1}^{N} \alpha_i - \dfrac{1}{2}\sum_{i=1}^{N}\sum_{j=1}^{N} \alpha_i \alpha_j y_i y_j \left\langle \Phi(\mathbf{x}_i), \, \Phi(\mathbf{x}_j) \right\rangle
$$

* **Problem:** If $\mathbf{x}$ has $d = 1000$ features and we use degree-$5$ polynomial interactions, the transformed vector $\Phi(\mathbf{x})$ will have $\displaystyle \binom{1005}{5} \approx \mathbf{8.5 \times 10^{12}}$ dimensions! Explicitly computing and storing $\Phi(\mathbf{x})$ for every data point is computationally impossible (and for a Gaussian RBF mapping, $\mathcal{H}$ is **infinite-dimensional**!).

---

### B. Definition of a Kernel Function $K(\mathbf{x}_i, \mathbf{x}_j)$
Notice that neither the Dual Optimization Problem nor the SVM Decision Function ever needs the individual coordinates of $\Phi(\mathbf{x})$—they **only need the dot product (inner product) $\Phi(\mathbf{x}_i)^T \Phi(\mathbf{x}_j)$** between pairs of points!

A **Kernel Function**, denoted by **$K(\mathbf{x}_i, \mathbf{x}_j)$**, is a mathematical function that computes the **inner product of two vectors $\Phi(\mathbf{x}_i)$ and $\Phi(\mathbf{x}_j)$ in the high-dimensional feature space $\mathcal{H}$ directly in terms of the original low-dimensional input vectors $\mathbf{x}_i$ and $\mathbf{x}_j$**:

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \left\langle \Phi(\mathbf{x}_i), \, \Phi(\mathbf{x}_j) \right\rangle = \Phi(\mathbf{x}_i)^T \Phi(\mathbf{x}_j)
$$

---

### C. What is the "Kernel Trick"?
The **"Kernel Trick"** is the technique of replacing every inner product $\mathbf{x}_i^T \mathbf{x}_j$ in a linear algorithm (like SVM) with a non-linear Kernel Function $K(\mathbf{x}_i, \mathbf{x}_j) = \Phi(\mathbf{x}_i)^T \Phi(\mathbf{x}_j)$.
* **Why is it a "Trick"?** Because it allows SVM to learn a **linear Optimal Separating Hyperplane in a high-dimensional (or infinite-dimensional) space**—which corresponds to a powerful **non-linear decision boundary in the original input space**—**without ever explicitly computing the coordinates $\Phi(\mathbf{x})$** in that high-dimensional space!

#### **Non-Linear SVM Equations Using Kernel Functions:**
1. **Kernelized Dual Optimization Objective:**

$$
\max_{\boldsymbol{\alpha}} \quad \sum_{i=1}^{N} \alpha_i - \dfrac{1}{2}\sum_{i=1}^{N}\sum_{j=1}^{N} \alpha_i \alpha_j y_i y_j \, \mathbf{K(\mathbf{x}_i, \mathbf{x}_j)}
$$

2. **Kernelized SVM Decision Function (for a new test point $\mathbf{x}$):**

$$
f(\mathbf{x}) = \text{sign}\!\left( \sum_{i \in SV} \alpha_i y_i \, \mathbf{K(\mathbf{x}_i, \mathbf{x})} + b \right)
$$

## 3. Mathematical Demonstration of the Kernel Trick (Quadratic Example)
Let $\mathbf{x} = (x_1, x_2)^T$ and $\mathbf{z} = (z_1, z_2)^T$ be two 2D vectors, and consider the Kernel Function:

$$
K(\mathbf{x}, \mathbf{z}) = \left(\mathbf{x}^T \mathbf{z}\right)^2
$$

Let us expand $\left(\mathbf{x}^T \mathbf{z}\right)^2$ algebraically:

$$
K(\mathbf{x}, \mathbf{z}) = (x_1 z_1 + x_2 z_2)^2 = x_1^2 z_1^2 + 2 x_1 x_2 z_1 z_2 + x_2^2 z_2^2
$$

$$
K(\mathbf{x}, \mathbf{z}) = \begin{bmatrix} x_1^2 \\ \sqrt{2} x_1 x_2 \\ x_2^2 \end{bmatrix}^T \begin{bmatrix} z_1^2 \\ \sqrt{2} z_1 z_2 \\ z_2^2 \end{bmatrix} = \Phi(\mathbf{x})^T \Phi(\mathbf{z})
$$

where $\Phi(\mathbf{x}) = \left(x_1^2, \; \sqrt{2}x_1 x_2, \; x_2^2\right)^T \in \mathbb{R}^3$.
* **Efficiency Gain:** Instead of mapping both 2D vectors to 3D and taking a 3D dot product, we simply compute the 2D dot product $\mathbf{x}^T\mathbf{z}$ and square it! For $d$-dimensional vectors and degree $p$, explicit mapping takes $O(d^p)$ operations, whereas the Kernel $K(\mathbf{x}, \mathbf{z}) = (\mathbf{x}^T\mathbf{z})^p$ takes only **$O(d)$ operations**!

## 4. Standard Types of Kernel Functions in SVM (Crucial for Exams!)

[Click here to see the diagram for Decision Boundaries of Linear Polynomial and RBF Kernels in SVM](https://www.google.com/search?udm=2&q=SVM+Linear+vs+Polynomial+vs+RBF+Kernel+decision+boundaries+diagram)

### 1. Linear Kernel

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T \mathbf{x}_j + c
$$

* **Description:** Standard dot product in the original input space (no non-linear mapping).
* **When to Use:** When the data is already linearly separable or has a huge number of features compared to samples ($d \gg N$, such as **text classification / TF-IDF vectors**). Fast and least prone to overfitting.

---

### 2. Polynomial Kernel

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \left(\gamma \, \mathbf{x}_i^T \mathbf{x}_j + r\right)^d \quad \text{or} \quad \left(\mathbf{x}_i^T \mathbf{x}_j + 1\right)^d
$$

* **Parameters:** $d \in \{2, 3, \dots\}$ is the **polynomial degree**, $\gamma > 0$ is a scaling slope, and $r \ge 0$ is a constant offset (trades off influence of higher-order vs. lower-order terms).
* **Description:** Models curved polynomial decision boundaries and feature interactions up to degree $d$.
* **When to Use:** Image processing and problems where all training data is normalized.

---

### 3. Radial Basis Function (RBF) / Gaussian Kernel (Most Widely Used!)

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \exp\!\left(-\dfrac{\|\mathbf{x}_i - \mathbf{x}_j\|^2}{2\sigma^2}\right) = \exp\!\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right), \quad \text{where } \gamma = \dfrac{1}{2\sigma^2} > 0
$$

* **Description:**
  * Measures similarity based on the **squared Euclidean distance $\|\mathbf{x}_i - \mathbf{x}_j\|^2$** between points:
    * When $\mathbf{x}_i = \mathbf{x}_j$, distance is $0 \implies K(\mathbf{x}_i, \mathbf{x}_j) = e^0 = \mathbf{1}$ (maximum similarity).
    * As $\|\mathbf{x}_i - \mathbf{x}_j\| \to \infty$, $K(\mathbf{x}_i, \mathbf{x}_j) \to \mathbf{0}$ (acts like a localized Gaussian bump around each Support Vector).
  * By Taylor series expansion of $e^x$, the Gaussian RBF kernel implicitly maps inputs into an **infinite-dimensional feature space ($\mathcal{H} = \mathbb{R}^\infty$)**!
* **Effect of Hyperparameter $\gamma$:**
  * **Small $\gamma$ (Large $\sigma$):** Smooth, broad decision boundary (low variance, risk of underfitting).
  * **Large $\gamma$ (Small $\sigma$):** Tightly wrapped "island" boundaries around individual points (high variance, risk of **overfitting**).
* **When to Use:** Default general-purpose kernel when we have no prior knowledge about the data structure.

---

### 4. Sigmoid (Hyperbolic Tangent / Neural Network) Kernel

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \tanh\!\left(\gamma \, \mathbf{x}_i^T \mathbf{x}_j + r\right)
$$

* **Description:** Originated from Neural Networks; an SVM with a Sigmoid kernel is functionally equivalent to a two-layer Perceptron neural network.

## 5. Summary Table of SVM Kernel Functions

| Kernel Name | Mathematical Formula $K(\mathbf{x}_i, \mathbf{x}_j)$ | Hyperparameters | Feature Space Dimension | Typical Use Case |
| :--- | :---: | :---: | :---: | :--- |
| **1. Linear Kernel** | $\mathbf{x}_i^T \mathbf{x}_j$ | None | Original $d$ | Text classification, high-dimensional sparse data ($d \gg N$). |
| **2. Polynomial Kernel** | $(\gamma \, \mathbf{x}_i^T \mathbf{x}_j + r)^d$ | Degree $d$, $\gamma$, $r$ | $\displaystyle \binom{d_{\text{in}} + d}{d}$ (Finite) | Curved boundaries, explicit feature interaction problems. |
| **3. Gaussian RBF Kernel** | $\exp\!\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right)$ | $\displaystyle \gamma = \frac{1}{2\sigma^2} > 0$ | **Infinite ($\infty$)** | **Default choice** for complex non-linear boundaries (circles, spirals). |
| **4. Sigmoid Kernel** | $\tanh(\gamma \, \mathbf{x}_i^T \mathbf{x}_j + r)$ | $\gamma$, $r$ | Proxy for MLP | Neural network approximation. |

*(Note — **Mercer's Theorem:** A symmetric function $K(\mathbf{x}_i, \mathbf{x}_j)$ is a valid kernel function corresponding to an inner product in some feature space if and only if its $N \times N$ Gram Matrix $\mathbf{K}$ is **Positive Semi-Definite** for any set of points).*

## 6. Exam-Style Questions & Answers for Topic 5.4

### Question 1 (5 Marks)
> **What is the role of Kernel functions in Support Vector Machines? Explain the "Kernel Trick" and list any three commonly used kernel functions with their mathematical equations.**

#### **Solution:**

1. **Role of Kernel Functions in SVM:**
   * Standard linear SVMs can only construct a flat hyperplane ($\mathbf{w}^T\mathbf{x} + b = 0$) and fail when the classes are **non-linearly separable** in the original input space.
   * Kernel functions allow SVMs to classify non-linearly separable data by implicitly mapping the input vectors $\mathbf{x} \in \mathbb{R}^d$ into a **higher-dimensional feature space $\Phi(\mathbf{x}) \in \mathcal{H}$** where the classes become **linearly separable** by a flat hyperplane.
2. **The "Kernel Trick":**
   * Explicitly computing the high-dimensional coordinates $\Phi(\mathbf{x})$ for every data point is computationally expensive (or impossible if $\mathcal{H}$ is infinite-dimensional).
   * However, in the Dual SVM formulation, data vectors only appear inside inner products $\Phi(\mathbf{x}_i)^T \Phi(\mathbf{x}_j)$.
   * The **Kernel Trick** replaces this high-dimensional inner product with a **Kernel Function**:

$$
K(\mathbf{x}_i, \mathbf{x}_j) = \Phi(\mathbf{x}_i)^T \Phi(\mathbf{x}_j)
$$

     which computes the inner product directly using the original low-dimensional vectors $\mathbf{x}_i$ and $\mathbf{x}_j$, completely avoiding the explicit computation of $\Phi(\mathbf{x})$.
3. **Three Commonly Used Kernel Functions:**
   * **Linear Kernel:** $K(\mathbf{x}_i, \mathbf{x}_j) = \mathbf{x}_i^T \mathbf{x}_j$
   * **Polynomial Kernel (of degree $d$):** $K(\mathbf{x}_i, \mathbf{x}_j) = (\gamma \, \mathbf{x}_i^T \mathbf{x}_j + r)^d$
   * **Gaussian Radial Basis Function (RBF) Kernel:** $K(\mathbf{x}_i, \mathbf{x}_j) = \exp\!\left(-\gamma \|\mathbf{x}_i - \mathbf{x}_j\|^2\right)$, where $\displaystyle \gamma = \frac{1}{2\sigma^2} > 0$.
