# Module 5.5: Bayes' Rule in Machine Learning & Classification

## 1. Introduction: Bayes' Rule as a Classifier
In Module `1.1`, we studied Bayes' Theorem as a law of conditional probability. In **Module V (Supervised Learning)**, **Bayes' Rule** forms the mathematical foundation of **Statistical & Probabilistic Classification** (Bayesian Decision Theory).

Instead of finding a geometric hyperplane like SVM, a **Bayesian Classifier** treats the input features $\mathbf{X}$ and the target class label $C_k$ (or $Y$) as random variables and predicts the class label by computing the **posterior probability $P(C_k \mid \mathbf{X})$** that a given sample $\mathbf{X}$ belongs to each class $C_k$.

## 2. Mathematical Formulation of Bayes' Rule for Classification

Let:
* **$\mathbf{X} = (x_1, x_2, \dots, x_d)$** be the $d$-dimensional observed **feature vector** of a data sample.
* **$C = \{C_1, C_2, \dots, C_K\}$** be the set of $K$ mutually exclusive and exhaustive **target classes** (hypotheses).

By **Bayes' Rule**, the posterior probability that sample $\mathbf{X}$ belongs to class $C_k$ is:

$$P(C_k \mid \mathbf{X}) = \frac{P(\mathbf{X} \mid C_k) \cdot P(C_k)}{P(\mathbf{X})}$$

Where the denominator $P(\mathbf{X})$ is expanded using the **Law of Total Probability** across all $K$ classes:
$$P(\mathbf{X}) = \sum_{j=1}^{K} P(\mathbf{X} \mid C_j) \cdot P(C_j)$$

In words:
$$\text{Posterior Probability} = \frac{\text{Likelihood} \times \text{Class Prior}}{\text{Evidence (Marginal Likelihood)}}$$

---

### Meaning of Each Term in Supervised Classification:

| Term | Symbol | Meaning & How It Is Estimated from Training Data |
| :--- | :---: | :--- |
| **1. Class Prior Probability** | $P(C_k)$ | The baseline probability that any random sample belongs to class $C_k$ *before* observing its features $\mathbf{X}$.<br>• **Estimation:** $P(C_k) = \frac{\text{Number of training samples in class } C_k}{\text{Total number of training samples } N} = \frac{N_k}{N}$. |
| **2. Class-Conditional Likelihood** | $P(\mathbf{X} \mid C_k)$ | The probability (or probability density) of observing the specific feature values $\mathbf{X} = (x_1, \dots, x_d)$ *given* that the sample belongs to class $C_k$. |
| **3. Evidence (Marginal Probability)** | $P(\mathbf{X})$ | The total probability of observing feature vector $\mathbf{X}$ across all classes. It acts purely as a **normalizing constant** so that $\sum_{k=1}^{K} P(C_k \mid \mathbf{X}) = 1$. |
| **4. Posterior Probability** | $P(C_k \mid \mathbf{X})$ | The updated probability that the test sample belongs to class $C_k$ *after* observing its feature vector $\mathbf{X}$. |

---

## 3. Bayesian Decision Rules: MAP vs. Maximum Likelihood (ML)

Once a Bayesian model computes the probabilities for each class $C_k \in \{C_1, \dots, C_K\}$, how does it decide which class label $\hat{y}$ to assign to a test sample $\mathbf{X}$?

### A. Maximum A Posteriori (MAP) Decision Rule ($h_{\text{MAP}}$)
To minimize the probability of misclassification (**Bayes Optimal Decision Rule**), the classifier chooses the class $C_k$ that has the **highest Posterior Probability $P(C_k \mid \mathbf{X})$**:

$$\hat{y}_{\text{MAP}} = \arg\max_{C_k \in C} \; P(C_k \mid \mathbf{X}) = \arg\max_{C_k \in C} \; \frac{P(\mathbf{X} \mid C_k) \cdot P(C_k)}{P(\mathbf{X})}$$

* **Eliminating the Denominator $P(\mathbf{X})$:**
  Notice that for a given test sample $\mathbf{X}$, the denominator $P(\mathbf{X})$ does **not** depend on the class $C_k$—it is the exact same positive constant for every class! Therefore, we can drop $P(\mathbf{X})$ when comparing classes:
  $$\mathbf{\hat{y}_{\text{MAP}} = \arg\max_{C_k \in C} \; \Big[ P(\mathbf{X} \mid C_k) \cdot P(C_k) \Big]}$$
* *(Note: If the exam asks for the normalized **Posterior Probability** of the winning class $C^*$, we simply divide its unnormalized MAP score by the sum of scores of all classes: $P(C^* \mid \mathbf{X}) = \frac{P(\mathbf{X}\mid C^*)P(C^*)}{\sum_j P(\mathbf{X}\mid C_j)P(C_j)}$).*

---

### B. Maximum Likelihood (ML) Decision Rule ($h_{\text{ML}}$)
In the special case where **all classes are equally likely a priori** (Uniform Priors: $P(C_1) = P(C_2) = \dots = P(C_K) = \frac{1}{K}$), the prior term $P(C_k)$ is also constant across all classes and can be dropped. The MAP rule then simplifies to the **Maximum Likelihood (ML) Rule**:

$$\mathbf{\hat{y}_{\text{ML}} = \arg\max_{C_k \in C} \; P(\mathbf{X} \mid C_k)}$$

| Decision Rule | Formula | When to Use |
| :--- | :---: | :--- |
| **MAP Rule ($h_{\text{MAP}}$)** | $\arg\max_{C_k} \; P(\mathbf{X} \mid C_k) P(C_k)$ | **General case** (especially when classes are imbalanced, e.g., $90\%$ Healthy vs $10\%$ Sick, or $60\%$ Ham vs $40\%$ Spam). |
| **ML Rule ($h_{\text{ML}}$)** | $\arg\max_{C_k} \; P(\mathbf{X} \mid C_k)$ | Only when **all class priors $P(C_k)$ are equal** ($P(C_1) = P(C_2) = \dots$). |

## 4. Optimality of Bayes' Rule (Minimizing Classification Error)
For a binary classification problem with classes $C_1$ and $C_2$, if we classify sample $\mathbf{X}$ as $C_1$, the probability that we made an **error** is the probability that it actually belongs to $C_2$, i.e., $P(\text{error} \mid \mathbf{X}) = P(C_2 \mid \mathbf{X}) = 1 - P(C_1 \mid \mathbf{X})$.

Therefore, for any $\mathbf{X}$, the probability of classification error is minimized by choosing $C_1$ if $P(C_1 \mid \mathbf{X}) > P(C_2 \mid \mathbf{X})$, and $C_2$ otherwise:
$$P(\text{Error} \mid \mathbf{X}) = \min\big\{ P(C_1 \mid \mathbf{X}), \; P(C_2 \mid \mathbf{X}) \big\}$$
* **Bayes Optimal Classifier:** No other classifier using the same hypothesis space and prior knowledge can achieve a lower expected misclassification rate than the Bayes Optimal Classifier!

## 5. Practical Bottleneck of Full Bayes' Rule (Motivation for Naïve Bayes)
Why can't we always apply the exact Bayes' Rule directly when $\mathbf{X} = (x_1, x_2, \dots, x_d)$ has many features?
* To compute the **Joint Class-Conditional Likelihood $P(x_1, x_2, \dots, x_d \mid C_k)$** directly from training data without any simplifying assumptions, we must count how many times the **exact combination** $(x_1, x_2, \dots, x_d)$ appears in class $C_k$.
* **Exponential Parameter Explosion:** If there are $d = 30$ binary features and $K = 2$ classes, there are $2^{30} \approx \mathbf{1\text{ billion}}$ possible feature combinations per class! In any realistic dataset of a few thousand rows, almost every multi-feature combination will appear **$0$ times**, giving $P(\mathbf{X} \mid C_k) = 0$.
* **Solution (Module 5.6 — Naïve Bayes Model):** Assume that the features $x_1, x_2, \dots, x_d$ are **conditionally independent** given the class $C_k$, factoring the joint likelihood into a simple product of individual feature likelihoods:
  $$P(x_1, x_2, \dots, x_d \mid C_k) = \prod_{i=1}^{d} P(x_i \mid C_k)$$

## 6. Solved Exam Questions on Bayes' Rule

### Question 1 [Series Test-I, Part B, Q7(a) (5 Marks)]
> **A hospital uses an AI system to detect a disease.**
> * **Disease prevalence $= 2\%$**
> * **Test accuracy for diseased patients $= 95\%$**
> * **False positive rate $= 4\%$**
> 
> **A patient tests positive. Find the probability that the patient actually has the disease and explain why Bayes' theorem is important in medical AI.**

#### **Solution Summary:**
* **Classes (Hypotheses):** $C_1 = D$ (Disease, Prior $P(D) = 0.02$), $C_2 = \neg D$ (Healthy, Prior $P(\neg D) = 0.98$).
* **Feature / Evidence ($X = +$):** Positive AI diagnostic test.
* **Class-Conditional Likelihoods:** $P(+ \mid D) = 0.95$ and $P(+ \mid \neg D) = 0.04$.
* **Evidence $P(+)$:**
  $$P(+) = P(+ \mid D)P(D) + P(+ \mid \neg D)P(\neg D) = (0.95)(0.02) + (0.04)(0.98) = 0.019 + 0.0392 = 0.0582$$
* **Posterior Probability $P(D \mid +)$ by Bayes' Rule:**
  $$P(D \mid +) = \frac{P(+ \mid D)P(D)}{P(+)} = \frac{0.019}{0.0582} \approx \mathbf{0.3265 \;\; (32.65\%)}$$
* **MAP Decision:** Since $P(\neg D \mid +) = 1 - 0.3265 = 0.6735 > P(D \mid +)$, a patient with a single positive screening test is still more likely to be healthy ($67.35\%$) than diseased ($32.65\%$) because the prior prevalence ($2\%$) is very low. This demonstrates why Bayes' Rule is essential in Medical AI to combine prior prevalence with test sensitivity and avoid false-positive misdiagnoses.
