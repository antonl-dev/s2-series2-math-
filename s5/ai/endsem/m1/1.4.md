# Module 1.4: Distribution Function (Cumulative Distribution Function - CDF)

## 1. Definition of Distribution Function (CDF)
The **Distribution Function**—also called the **Cumulative Distribution Function (CDF)**—of a random variable $X$, denoted by $F(x)$ or $F_X(x)$, is defined as the probability that the random variable $X$ takes a value **less than or equal to** $x$:

$$F(x) = P(X \le x), \quad \text{for all } -\infty < x < \infty$$

* **Why is it called "Cumulative"?** Because as $x$ increases from $-\infty$ to $+\infty$, $F(x)$ **accumulates** (sums or integrates) all the probability up to and including the point $x$.
* **Universal Applicability:** Unlike PMF (which applies only to discrete variables) and PDF (which applies only to continuous variables), the **Distribution Function $F(x)$ is defined in the exact same way for both discrete and continuous random variables**.

---

## 2. Distribution Function for Discrete vs. Continuous Random Variables

### A. Discrete Random Variable CDF
If $X$ is a discrete random variable with Probability Mass Function (PMF) $P(X = x_i) = p(x_i)$, then its Cumulative Distribution Function is given by summing the probabilities of all outcomes $x_i$ that are less than or equal to $x$:

$$F(x) = P(X \le x) = \sum_{x_i \le x} P(X = x_i)$$

* **Graphical Shape:** The graph of $F(x)$ for a discrete random variable is a **step function (staircase function)**.
* It remains flat (constant) between possible values of $X$ and makes a sudden vertical jump of height $P(X = x_i)$ at each point $x_i$.

### B. Continuous Random Variable CDF
If $X$ is a continuous random variable with Probability Density Function (PDF) $f(x)$, then its Cumulative Distribution Function is the area under the PDF curve from $-\infty$ up to $x$:

$$F(x) = P(X \le x) = \int_{-\infty}^{x} f(t)\,dt$$

*(Note: We use a dummy integration variable $t$ inside the integral because $x$ is the upper limit of integration.)*

* **Graphical Shape:** The graph of $F(x)$ for a continuous random variable is a **continuous, smooth, non-decreasing S-shaped curve** (no sudden jumps) that starts at $0$ (as $x \to -\infty$) and approaches $1$ (as $x \to +\infty$).

## 3. Fundamental Properties of a Distribution Function $F(x)$
Every valid Cumulative Distribution Function $F(x)$ satisfies the following properties:

### 1. Bounded Between $0$ and $1$
Since $F(x) = P(X \le x)$ is an actual probability (unlike a PDF), its value is always between $0$ and $1$:
$$0 \le F(x) \le 1 \quad \text{for all } x \in (-\infty, \infty)$$

### 2. Boundary Limits at $-\infty$ and $+\infty$
$$F(-\infty) = \lim_{x \to -\infty} F(x) = 0 \quad (\text{Impossible Event})$$
$$F(+\infty) = \lim_{x \to +\infty} F(x) = 1 \quad (\text{Sure Event / Entire Sample Space})$$

### 3. Monotonically Non-Decreasing Function
If $a < b$, then:
$$F(a) \le F(b)$$
* **Proof:** The event $(X \le b)$ can be split into two mutually exclusive events: $(X \le a)$ and $(a < X \le b)$.
  $$P(X \le b) = P(X \le a) + P(a < X \le b)$$
  $$F(b) = F(a) + P(a < X \le b)$$
  Since probability is never negative ($P(a < X \le b) \ge 0$), it follows that $F(b) \ge F(a)$.
* *Exam Tip:* A CDF can never decrease (slope can never be negative) because cumulative probability can only be added, never subtracted, as $x$ moves to the right.

### 4. Right-Continuity
A distribution function is always continuous from the right:
$$\lim_{h \to 0^+} F(x + h) = F(x)$$

### 5. Computing Interval Probabilities Using $F(x)$
For any $a < b$:
* **Half-Open Interval Probability (Valid for BOTH Discrete and Continuous):**
  $$P(a < X \le b) = F(b) - F(a)$$
* **For Continuous Random Variables Only** (since $P(X = a) = P(X = b) = 0$):
  $$P(a \le X \le b) = P(a < X < b) = P(a < X \le b) = F(b) - F(a)$$
* **Complement Rule (Upper Tail Probability):**
  $$P(X > a) = 1 - P(X \le a) = 1 - F(a)$$

### 6. Relationship Between PDF $f(x)$ and CDF $F(x)$ (Continuous Case)
By the Fundamental Theorem of Calculus, the Probability Density Function $f(x)$ is the **first derivative** of the Cumulative Distribution Function $F(x)$ at all points where $F(x)$ is differentiable:
$$f(x) = \frac{d}{dx} F(x) = F'(x)$$
* **To go from PDF to CDF:** **Integrate** $\longrightarrow F(x) = \int_{-\infty}^{x} f(t)\,dt$
* **To go from CDF to PDF:** **Differentiate** $\longrightarrow f(x) = \frac{d}{dx}F(x)$

---

## 4. Comparison: PDF $f(x)$ vs. CDF $F(x)$

| Feature | Probability Density Function $f(x)$ | Cumulative Distribution Function $F(x)$ |
| :--- | :--- | :--- |
| **Definition** | Rate of probability density at point $x$: $f(x) = \frac{d}{dx}F(x)$ | Cumulative probability up to $x$: $F(x) = P(X \le x)$ |
| **Is it a Probability?** | **No**, it is probability *density* (probability per unit length). | **Yes**, $F(x)$ directly gives a probability. |
| **Range of Values** | $f(x) \ge 0$ (can be greater than $1$). | Always $0 \le F(x) \le 1$. |
| **Behavior with $x$** | Can increase or decrease (e.g., bell curve rises then falls). | **Always non-decreasing** ($F(a) \le F(b)$ for $a < b$). |
| **Limits at $\pm\infty$** | $\lim_{x \to -\infty} f(x) = 0$ and $\lim_{x \to +\infty} f(x) = 0$ | $F(-\infty) = 0$ and $F(+\infty) = 1$ |
| **Interval Probability $P(a \le X \le b)$** | Area under curve: $\int_{a}^{b} f(x)\,dx$ | Difference of values: $F(b) - F(a)$ |

### Problem 1: Discrete CDF [Based on Series Test-I, Part B, Q8(a)]
> **The probability distribution of a discrete random variable $X$ is given by:**
> 
> | $X$ | $0$ | $1$ | $2$ | $3$ |
> | :---: | :---: | :---: | :---: | :---: |
> | $P(X)$ | $0.2$ | $0.4$ | $0.3$ | $0.1$ |
> 
> **Find the Cumulative Distribution Function $F(x)$ of $X$, express it as a piecewise function, and find $P(1 \le X \le 2)$ and $P(X > 1)$.**

#### **Solution:**

**Step 1: Compute Cumulative Probabilities at Each Value of $X$**
* At $x = 0$: $F(0) = P(X \le 0) = P(X = 0) = 0.2$
* At $x = 1$: $F(1) = P(X \le 1) = P(X = 0) + P(X = 1) = 0.2 + 0.4 = 0.6$
* At $x = 2$: $F(2) = P(X \le 2) = F(1) + P(X = 2) = 0.6 + 0.3 = 0.9$
* At $x = 3$: $F(3) = P(X \le 3) = F(2) + P(X = 3) = 0.9 + 0.1 = 1.0$

| $x$ | $0$ | $1$ | $2$ | $3$ |
| :---: | :---: | :---: | :---: | :---: |
| **PMF $P(X=x)$** | $0.2$ | $0.4$ | $0.3$ | $0.1$ |
| **CDF $F(x) = P(X \le x)$** | $0.2$ | $0.6$ | $0.9$ | $1.0$ |

**Step 2: Write Piecewise Form of $F(x)$**
$$F(x) = \begin{cases} 0, & x < 0 \\ 0.2, & 0 \le x < 1 \\ 0.6, & 1 \le x < 2 \\ 0.9, & 2 \le x < 3 \\ 1.0, & x \ge 3 \end{cases}$$

**Step 3: Compute Requested Probabilities**
* $P(1 \le X \le 2) = P(X = 1) + P(X = 2) = F(2) - F(0) = 0.9 - 0.2 = 0.7$
* $P(X > 1) = 1 - P(X \le 1) = 1 - F(1) = 1 - 0.6 = 0.4$

### Problem 2: Continuous CDF from PDF [Based on Series Test-I, Part B, Q7(b)]
> **A continuous random variable $X$ has the PDF $f(x) = \frac{x}{8}$ for $0 \le x \le 4$, and $0$ otherwise. Find its Distribution Function $F(x)$ and use $F(x)$ to find $P(1 \le X \le 3)$.**

#### **Solution:**

**Step 1: Find $F(x) = \int_{-\infty}^{x} f(t)\,dt$ across all intervals**
1. **Case 1 ($x < 0$):**
   $$F(x) = \int_{-\infty}^{x} 0\,dt = 0$$
2. **Case 2 ($0 \le x \le 4$):**
   $$F(x) = \int_{-\infty}^{0} 0\,dt + \int_{0}^{x} \frac{t}{8}\,dt = \left[ \frac{t^2}{16} \right]_{0}^{x} = \frac{x^2}{16}$$
3. **Case 3 ($x > 4$):**
   $$F(x) = \int_{-\infty}^{0} 0\,dt + \int_{0}^{4} \frac{t}{8}\,dt + \int_{4}^{x} 0\,dt = \left[ \frac{t^2}{16} \right]_{0}^{4} = \frac{16}{16} = 1$$

**Step 2: Write Complete Piecewise CDF $F(x)$**
$$F(x) = \begin{cases} 0, & x < 0 \\ \frac{x^2}{16}, & 0 \le x \le 4 \\ 1, & x > 4 \end{cases}$$

**Step 3: Find $P(1 \le X \le 3)$ using $F(x)$**
$$P(1 \le X \le 3) = F(3) - F(1) = \frac{3^2}{16} - \frac{1^2}{16} = \frac{9 - 1}{16} = \frac{8}{16} = 0.5$$

### Problem 3: Piecewise Continuous CDF [Based on End Semester Exam - Nov 2025, Q11]
> **Find the Cumulative Distribution Function $F(x)$ for the PDF given in Nov 2025 End Semester Exam Q11:**
> $$f(x) = \begin{cases} \frac{x}{25}, & 0 \le x \le 5 \\ \frac{10 - x}{25}, & 5 \le x \le 10 \\ 0, & \text{otherwise} \end{cases}$$

#### **Solution:**

1. **For $x < 0$:**
   $$F(x) = 0$$
2. **For $0 \le x \le 5$:**
   $$F(x) = \int_{0}^{x} \frac{t}{25}\,dt = \left[ \frac{t^2}{50} \right]_{0}^{x} = \frac{x^2}{50}$$
   *(Note: At $x = 5$, $F(5) = \frac{25}{50} = 0.5$.)*
3. **For $5 \le x \le 10$:**
   We must include all accumulated probability from $0$ to $5$, plus the integral from $5$ to $x$:
   $$F(x) = \int_{0}^{5} \frac{t}{25}\,dt + \int_{5}^{x} \frac{10 - t}{25}\,dt = 0.5 + \frac{1}{25}\left[ 10t - \frac{t^2}{2} \right]_{5}^{x}$$
   $$F(x) = \frac{1}{2} + \frac{1}{25}\left( 10x - \frac{x^2}{2} - \left(50 - \frac{25}{2}\right) \right) = \frac{1}{2} + \frac{10x - \frac{x^2}{2} - 37.5}{25}$$
   $$F(x) = \frac{12.5 + 10x - 0.5x^2 - 37.5}{25} = \frac{10x - 0.5x^2 - 25}{25} = 1 - \frac{(10 - x)^2}{50}$$
4. **For $x > 10$:**
   $$F(x) = 1$$

**Complete Distribution Function $F(x)$:**
$$F(x) = \begin{cases} 0, & x < 0 \\ \frac{x^2}{50}, & 0 \le x \le 5 \\ 1 - \frac{(10 - x)^2}{50}, & 5 \le x \le 10 \\ 1, & x > 10 \end{cases}$$
