# Module 2.5: Agents and Environments

## 1. What is an Environment in AI?
In Artificial Intelligence, an **Environment** (or **Task Environment**) is the external world, surroundings, or problem space in which an intelligent agent exists, operates, perceives states, and performs actions.

* **Agent–Environment Interaction Loop:**
  1. At any time step $t$, the **Environment** is in some state $s_t$ and presents a **percept** to the agent through the agent's **sensors**.
  2. The **Agent** processes the percept (and its internal state/goals) and selects an **action** $a_t$, which it executes through its **actuators**.
  3. The action modifies the **Environment**, causing it to transition to a new state $s_{t+1}$ (and potentially generating a performance reward), and the cycle repeats.
* **Nature of Environments:** An environment can be a **physical real-world environment** (e.g., city roads for a self-driving car, a room with dust for a vacuum robot) or a **virtual/simulated software environment** (e.g., an $8 \times 8$ digital chessboard, the Internet, or a financial trading platform).

## 2. Properties / Categories of Task Environments (Russell & Norvig Classification)
The complexity of designing an intelligent agent depends heavily on the nature of its environment. In AI, task environments are categorized along **seven fundamental dimensions** (especially the first six):

### 1. Fully Observable vs. Partially Observable

#### a) Fully Observable Environment
* An environment is **Fully Observable** if the agent's sensors give it access to the **complete state** of the environment at each point in time, including all aspects that are relevant to the choice of action.
* **Advantage:** The agent does **not** need to maintain an internal state (memory) to keep track of the world.
* **Examples:** Standard **Chess** or **Checkers** (both players can see the entire board and all pieces at all times); **Crossword puzzle**; **8-Puzzle**.

#### b) Partially Observable Environment
* An environment is **Partially Observable** if the sensors cannot detect all relevant aspects of the environment at once.
* **Why Partial Observability Occurs:**
  * Noisy or inaccurate sensors.
  * Parts of the state are hidden from the sensors (e.g., occluded obstacles, opponent's hidden cards).
  * Limited sensor range (e.g., a vacuum robot with only a local dirt sensor that cannot see whether *other* rooms have dirt).
* **Examples:** **Poker / Card games** (cannot see opponent's cards); **Automated Taxi Driving** (cannot see around corners or what other drivers are thinking); **Local-sensor Vacuum Cleaner**.
* *(Note: If the agent has no sensors at all, the environment is called **Unobservable**).*

---

### 2. Deterministic vs. Stochastic (Non-Deterministic)

#### a) Deterministic Environment
* An environment is **Deterministic** if the **next state** of the environment is **completely determined** by the **current state** and the **action executed by the agent** (and in multi-agent games, the actions of other agents). There is no randomness in state transitions.
* **Examples:** **Chess** (moving a Knight to a square deterministically places it there; there is no dice roll); **8-Puzzle**; **Crossword puzzle**; **Image classification**.
* *(Note in Textbooks: If the environment is deterministic except for the actions of other agents—like Chess—some textbooks also call it **Strategic**).*

#### b) Stochastic Environment
* An environment is **Stochastic** if the next state is **not** completely determined by the current state and action because there is inherent **randomness or uncertainty** in how the world evolves (outcomes can only be described using probabilities).
* **Examples:** **Backgammon / Ludo** (involves rolling dice); **Self-Driving Taxi** (traffic behavior, tire blowouts, and weather are unpredictable); **Medical Diagnosis** (a treatment does not guarantee a $100\%$ deterministic cure).

---

### 3. Episodic vs. Sequential

#### a) Episodic Environment
* In an **Episodic** environment, the agent's experience is divided into atomic, independent **"episodes"**. In each episode, the agent receives a percept and performs a single action.
* Crucially, **the next episode does NOT depend on the actions taken in previous episodes**. The agent does not need to think ahead!
* **Examples:** **Defective Part-Picking Robot on an Assembly Line** (classifying whether bottle #1 is defective has no effect on whether bottle #2 is defective); **Spam Email Filter**; **Medical Image Classification** (X-ray #1 vs. X-ray #2).

#### b) Sequential Environment
* In a **Sequential** environment, the **current decision affects all future decisions and states**. Short-term actions have long-term consequences, so the agent must plan ahead.
* **Examples:** **Chess** (sacrificing a piece on move 5 affects the entire rest of the game); **Taxi Driving** (taking a wrong highway exit changes the entire remaining route); **Vacuum Cleaner moving across rooms**.

---

### 4. Static vs. Dynamic (and Semidynamic)

#### a) Static Environment
* An environment is **Static** if the environment **does not change while the agent is deliberating** (thinking about what action to take next).
* Static environments are easy to deal with because the agent does not need to keep looking at the world while deciding on an action, nor does it need to worry about the passage of time.
* **Examples:** **Crossword puzzle**; **Chess without a clock**; **8-Puzzle**.

#### b) Dynamic Environment
* An environment is **Dynamic** if the environment **can change while the agent is deliberating**. If the agent takes too long to think, the world moves on (equivalent to choosing to do nothing!).
* **Examples:** **Automated Taxi Driving** (other cars and pedestrians keep moving while the AI computes its next steering angle); **Real-time Robotics / Drone Flight**; **Stock Market Trading**.

#### c) Semidynamic Environment
* An environment is **Semidynamic** if the **environment itself does not change** with the passage of time, **but the agent's performance score does**!
* **Example:** **Chess played with a tournament game clock** (the board pieces don't move on their own while you think, but your clock ticks down and you lose on time if you think too long).

---

### 5. Discrete vs. Continuous

This distinction applies to **four aspects**: the **state** of the environment, the way **time** is handled, and the **percepts** and **actions** of the agent:
* **Discrete Environment:** Has a finite (or countably infinite) number of distinct states, discrete time steps (turns), and a finite set of percepts and actions.
  * *Examples:* **Chess** (finite $8 \times 8$ grid, turn-based time, discrete legal moves); **8-Puzzle**; **Grid-world Vacuum Cleaner**.
* **Continuous Environment:** Involves continuous physical variables changing smoothly over continuous real-valued time.
  * *Examples:* **Taxi Driving / Drone Control** (speed, steering angles, position, and time vary continuously over real numbers).

---

### 6. Single-Agent vs. Multi-Agent

#### a) Single-Agent Environment
* Only **one agent** is operating in the environment by itself (any other objects follow fixed physical laws rather than trying to maximize their own performance measure).
* **Examples:** **Solving a Crossword puzzle**; **8-Puzzle**; **Vacuum Cleaner in an empty house**.

#### b) Multi-Agent Environment
* **Two or more agents** operate in the environment and their actions affect each other's performance measures.
* **Two Sub-types of Multi-Agent Environments:**
  1. **Competitive Multi-Agent Environment:** Maximizing one agent's performance minimizes the other's (zero-sum game). *Example:* **Chess**, **Poker**.
  2. **Cooperative (or Partially Cooperative) Multi-Agent Environment:** Agents work together (or share rules) to maximize a common goal, such as avoiding collisions. *Example:* **Fleet of Warehouse Robots**, **Taxi Driving** (all drivers want to avoid crashing into each other).

---

### 7. Known vs. Unknown (Bonus Property)
* Refers not to the environment itself, but to the **agent's state of knowledge** about the "laws of physics" (transition model and payoff function) of the environment:
  * **Known Environment:** The outcomes (or probabilities of outcomes) for all actions are given to the agent beforehand (e.g., knowing the rules of Chess or Solitaire).
  * **Unknown Environment:** The agent does not know how its actions work and must **explore and learn** how the environment behaves (e.g., playing a brand-new video game without reading the manual; Reinforcement Learning).

## 4. Solved University & Internal Exam Questions

### Question 1 [End Semester Exam - Nov 2025, Part A, Q4 (2 Marks)]
> **What is an environment in AI?**

#### **Solution:**
In Artificial Intelligence, an **Environment** (or task environment) is the surrounding external world—either physical or virtual—in which an intelligent agent exists and operates. 
* The environment provides **percepts** (inputs/observations) to the agent via its **sensors**, and the agent modifies or interacts with the environment by executing **actions** via its **actuators**.
* *Examples:* Roads, traffic, and pedestrians form the environment for a self-driving car; an $8 \times 8$ chessboard and opponent form the environment for a Chess AI.

### Question 2 [End Semester Exam - Nov 2025, Part B, Q14(a) (4 Marks)]
> **Describe any four categories of environments in which intelligent agents can function.**

#### **Solution:**
Any four of the following standard categories of task environments can be written for full marks:

1. **Fully Observable vs. Partially Observable Environments:**
   * **Fully Observable:** The agent's sensors capture the complete, exact state of the environment at every moment (e.g., *Chess*, *8-Puzzle*).
   * **Partially Observable:** The agent can only perceive a portion of the environment due to sensor limitations, noise, or hidden information (e.g., *Poker*, *Self-Driving Car*).
2. **Deterministic vs. Stochastic Environments:**
   * **Deterministic:** The next state of the environment is completely and predictably determined by the current state and the agent's action (e.g., *Crossword Puzzle*, *Chess*).
   * **Stochastic:** The next state involves randomness and uncertainty, so outcomes are probabilistic rather than guaranteed (e.g., *Backgammon with dice*, *Taxi Driving*).
3. **Episodic vs. Sequential Environments:**
   * **Episodic:** The agent's experience is divided into independent atomic episodes where the current action does not affect future episodes (e.g., *Defective Part Inspection on a conveyor belt*, *Spam Filtering*).
   * **Sequential:** Current actions influence all future states and decisions, requiring long-term planning (e.g., *Chess*, *Route Navigation*).
4. **Static vs. Dynamic Environments:**
   * **Static:** The environment remains unchanged while the agent is thinking/deliberating (e.g., *Crossword Puzzle*, *Chess without a clock*).
   * **Dynamic:** The environment continuously changes while the agent is deliberating (e.g., *Autonomous Driving*, *Drone Flight*).
5. **Discrete vs. Continuous Environments:**
   * **Discrete:** Has a finite number of distinct states, time steps, percepts, and actions (e.g., *Chess*).
   * **Continuous:** States, time, and actions vary smoothly over continuous real values (e.g., *Self-Driving Car steering and speed*).
6. **Single-Agent vs. Multi-Agent Environments:**
   * **Single-Agent:** Only one agent operates in the environment (e.g., *Crossword Puzzle*).
   * **Multi-Agent:** Multiple agents interact either competitively (e.g., *Chess*) or cooperatively (e.g., *Multi-robot warehouse*).

> **Classify the environment for - Chess AI using:**

#### **Solution:**

| Dimension | Classification for Chess AI | Justification |
| :--- | :--- | :--- |
| **1. Observability** | **Fully Observable** | Both the AI and the opponent can see the entire $8 \times 8$ board and the exact positions of all pieces at all times. |
| **2. Determinism** | **Deterministic** *(Strategic)* | There are no dice or random chance elements; moving a piece to a square deterministically results in the exact new board state (uncertainty comes only from the opponent's choice, i.e., *strategic*). |
| **3. Episodic / Sequential** | **Sequential** | Every move made now alters the board state and directly affects all future moves, tactics, and the final game outcome. |
| **4. Static / Dynamic** | **Static** *(or **Semidynamic** with a clock)* | **Static** if played without a clock (the board does not change while the AI thinks); **Semidynamic** if played with a tournament timer (board stays still, but the time-based score changes). |

| **6. Single / Multi-agent** | **Multi-Agent** *(Competitive)* | Two agents (White and Black) interact competitively in a zero-sum game where one agent's win is the other's loss. |
