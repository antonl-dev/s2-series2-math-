# Module 4.3: Concept of Artificial Neuron

## 1. Mathematical Model of an Artificial Neuron (Perceptron)
An **Artificial Neuron** (also called a **Node**, **Unit**, or **Perceptron**) is the fundamental computational building block of an Artificial Neural Network. It receives multiple numerical inputs, computes their weighted sum plus a bias, and passes the result through an **Activation Function** to produce a single scalar output.

[Click here to see the diagram for Mathematical Model of an Artificial Neuron Inputs Weights Bias Activation](https://www.google.com/search?udm=2&q=Mathematical+Model+of+Artificial+Neuron+Weights+Bias+Summation+Activation+Function+diagram)

```text
    Inputs        Weights
   (x0 = 1) ---- [ b = w0 ] ---+
                               |
     x1 -------- [   w1   ] ---+---> ( SUM: z = Sum(wi*xi) + b ) ---> [ Activation phi(z) ] ---> Output y
                               |
     x2 -------- [   w2   ] ---+
     ...            ...        |
     xn -------- [   wn   ] ---+
```

---

### Step-by-Step Mathematical Formulation
Consider an artificial neuron receiving $n$ input signals $x_1, x_2, \dots, x_n$:

#### 1. Inputs ($\mathbf{x}$)
The input features fed into the neuron, represented as a column vector:

$$
\mathbf{x} = [x_1, x_2, \dots, x_n]^T
$$

#### 2. Synaptic Weights ($\mathbf{w}$)
Each input $x_i$ is multiplied by an adjustable real-valued parameter $w_i$ called its **synaptic weight**:

$$
\mathbf{w} = [w_1, w_2, \dots, w_n]^T
$$

* **Role of Weights:** Weights control the **strength and sign of influence** of each input feature on the neuron's output:
  * **$w_i > 0$ (Excitatory Weight):** Increases the net input when $x_i > 0$.
  * **$w_i < 0$ (Inhibitory Weight):** Suppresses/decreases the net input when $x_i > 0$.
  * **$w_i = 0$:** Input $x_i$ has no effect on the neuron.

#### 3. Bias ($b$ or $w_0$)
An external constant parameter $b$ (often modeled as an extra weight $w_0 = b$ connected to a fixed dummy input $x_0 = +1$) is added to the weighted sum.
* **Role of Bias (Why is Bias Needed?):**
  * Without a bias term, the linear equation $\displaystyle \sum w_i x_i = 0$ is forced to pass strictly through the **origin $(0, 0, \dots, 0)$**.
  * The **bias $b$ shifts the activation function horizontally (left or right)** and allows the neuron's decision boundary hyperplane ($\mathbf{w}^T\mathbf{x} + b = 0$) to be shifted away from the origin to fit the data properly.

[Click here to see the diagram for Effect of Weight and Bias on Neuron Activation Function](https://www.google.com/search?udm=2&q=Effect+of+Weight+and+Bias+on+Activation+Function+Sigmoid+shift)

#### 4. Net Input / Linear Combiner ($z$ or $v$ or $net$)
The **Summation Junction ($\displaystyle \sum$)** computes the net pre-activation input $z$ as the dot product of weights and inputs plus the bias:

$$
z = \sum_{i=1}^{n} w_i x_i + b = w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b
$$

#### 5. Activation Function / Transfer Function ($\phi(\cdot)$ or $f(\cdot)$)
The net input $z \in (-\infty, \infty)$ is passed through a non-linear function $\phi(z)$ to produce the neuron's final output (activation) $y$ (or $a$):

$$
y = \phi(z) = \phi\left(\sum_{i=1}^{n} w_i x_i + b\right)
$$

---

## 2. Why Are Non-Linear Activation Functions Necessary?
Suppose a multi-layer neural network had **no non-linear activation functions** (or used only a linear identity function $\phi(z) = z$).
* Then Layer 1 computes $\mathbf{h}_1 = W_1 \mathbf{x} + \mathbf{b}_1$, and Layer 2 computes $\mathbf{y} = W_2 \mathbf{h}_1 + \mathbf{b}_2 = W_2(W_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2 = (W_2 W_1)\mathbf{x} + (W_2 \mathbf{b}_1 + \mathbf{b}_2) = W_{\text{eff}} \mathbf{x} + \mathbf{b}_{\text{eff}}$.
* Because a linear function of a linear function is still just a **single linear function**, a 100-layer linear neural network would have the exact same representational power as a **single-layer linear regression model**!
* **Non-linear activation functions** (like Sigmoid, Tanh, and ReLU) break this linearity, enabling neural networks to learn complex, curved decision boundaries and approximate any continuous function.

## 3. Types of Activation Functions (Crucial for Exams!)

[Click here to see the diagram for Common Activation Functions Sigmoid Tanh ReLU Leaky ReLU Plots](https://www.google.com/search?udm=2&q=Activation+Functions+in+Neural+Networks+Sigmoid+Tanh+ReLU+plots)

### 1. Threshold (Heaviside Step) Activation Function
Used in the original McCulloch-Pitts Neuron and Rosenblatt's Perceptron for binary classification:

$$
\phi(z) = \begin{cases} 1, & \text{if } z \ge 0 \\ 0, & \text{if } z < 0 \end{cases}
$$

* **Limitation:** Its derivative is $0$ everywhere (and undefined at $z = 0$), so it **cannot be used with Gradient Descent / Backpropagation**!

---

### 2. Sigmoid (Logistic) Activation Function
Maps any real number $z \in (-\infty, \infty)$ into a smooth S-shaped curve bounded strictly between **$0$ and $1$**:

$$
\sigma(z) = \dfrac{1}{1 + e^{-z}}
$$

* **Range:** $(0, 1)$ — makes it ideal for the **output layer of binary classification**, where the output is interpreted as a probability $P(y = 1 \mid \mathbf{x})$.
* **Derivative (Used in Backpropagation):**

$$
\sigma'(z) = \dfrac{d}{dz}\sigma(z) = \sigma(z)\big(1 - \sigma(z)\big)
$$

* **Maximum Value of Derivative:** At $z = 0$, $\sigma(0) = 0.5$, so:

$$
\sigma'_{\max}(0) = 0.5 \times (1 - 0.5) = \mathbf{0.25}
$$

* **Three Major Drawbacks of Sigmoid in Hidden Layers:**
  1. **Vanishing Gradient Problem (Saturation):** When $|z|$ is large ($z \gg 0$ or $z \ll 0$), $\sigma(z)$ saturates near $1$ or $0$, causing the derivative $\sigma'(z) \to 0$. Even in the best case ($z = 0$), the gradient is at most **$0.25$**. Multiplying numbers $\le 0.25$ across many hidden layers during backpropagation causes gradients in early layers to shrink exponentially to zero!
  2. **Not Zero-Centered:** Outputs are always positive ($\sigma(z) > 0$), causing "zig-zagging" weight updates during gradient descent.
  3. **Computationally Expensive:** Computing the exponential $e^{-z}$ is slower than simple comparisons.

---

### 3. Hyperbolic Tangent ($\tanh$) Activation Function
Maps any real number $z \in (-\infty, \infty)$ into a smooth S-shaped curve bounded between **$-1$ and $+1$**:

$$
\tanh(z) = \dfrac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1
$$

* **Range:** $(-1, +1)$ — **Zero-centered** ($\tanh(0) = 0$), which makes optimization faster than Sigmoid.
* **Derivative:** $\tanh'(z) = 1 - \tanh^2(z) \in (0, 1]$.
* **Drawback:** Still saturates for large positive or negative inputs ($z \to \pm\infty \implies \tanh'(z) \to 0$), so it still suffers from the **vanishing gradient problem** in deep networks.

---

### 4. Rectified Linear Unit (ReLU) — The Modern Default for Hidden Layers
Outputs the input $z$ directly if it is positive; otherwise, it outputs **$0$**:

$$
\text{ReLU}(z) = \max(0, z) = \begin{cases} z, & \text{if } z > 0 \\ 0, & \text{if } z \le 0 \end{cases}
$$

* **Range:** $[0, \infty)$
* **Derivative of ReLU:**

$$
\text{ReLU}'(z) = \begin{cases} \mathbf{1}, & \text{if } z > 0 \\ \mathbf{0}, & \text{if } z < 0 \end{cases}
$$

* **Why ReLU is Preferred Over Sigmoid in Deep Networks (4 Key Reasons):**
  1. **Solves the Vanishing Gradient Problem (for $z > 0$):** For all positive inputs ($z > 0$), ReLU does **not** saturate and its derivative is a constant **$\text{ReLU}'(z) = 1$** (unlike Sigmoid's $\le 0.25$). During backpropagation, multiplying by $1$ allows error gradients to flow backward through dozens of deep layers without shrinking to zero!
  2. **Extreme Computational Efficiency:** Requires only a simple threshold comparison (`if z > 0`) and no expensive exponential ($e^{-z}$) or division operations, speeding up training by $5\times\text{ to }6\times$.
  3. **Sparse Activation (Biological Plausibility):** Because all negative pre-activations ($z \le 0$) become exact $0$, only a subset of neurons fire at any given time, creating a sparse, lightweight representation that reduces overfitting.
  4. **Faster Convergence:** Empirically converges much faster than Sigmoid/Tanh in Stochastic Gradient Descent.
* **Limitation of ReLU ("Dying ReLU" Problem) & Fix:**
  * If a neuron's weights get updated such that $z < 0$ for all training inputs, its output is $0$ and its gradient is $0$ forever (the neuron "dies").
  * **Fix — Leaky ReLU:** Gives a small positive slope $\alpha$ (e.g., $\alpha = 0.01$) for negative inputs: $\text{LeakyReLU}(z) = \max(\alpha z, z)$.

---

### 5. Softmax Activation Function (For Multi-Class Output Layer)
Converts a vector of $K$ raw scores (logits $z_1, \dots, z_K$) in the output layer into a valid **probability distribution** over $K$ classes:

$$
\text{Softmax}(z_i) = \dfrac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}, \quad \text{where } \sum_{i=1}^{K} \text{Softmax}(z_i) = 1
$$

## 4. Summary Comparison Table of Activation Functions

| Activation Function | Formula $\phi(z)$ | Derivative $\phi'(z)$ | Output Range | Vanishing Gradient? | Typical Usage |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Step Function** | $1$ if $z \ge 0$ else $0$ | $0$ ($z \neq 0$) | $\{0, 1\}$ | Cannot do Backprop | Basic Single Perceptron |
| **Sigmoid** | $\displaystyle \frac{1}{1 + e^{-z}}$ | $\sigma(z)(1 - \sigma(z)) \le 0.25$ | $(0, 1)$ | **Yes (Severe)** | **Binary Classification Output Layer** |
| **Tanh** | $\displaystyle \frac{e^z - e^{-z}}{e^z + e^{-z}}$ | $1 - \tanh^2(z) \le 1$ | $(-1, 1)$ | **Yes** (at tails) | RNNs / Shallow Hidden Layers |
| **ReLU** | $\max(0, z)$ | **$1$ (for $z > 0$)**, $0$ (for $z < 0$) | $[0, \infty)$ | **No (for $z > 0$)** | **Default for Deep Hidden Layers** |
| **Leaky ReLU** | $\max(0.01z, z)$ | $1$ ($z > 0$), $0.01$ ($z < 0$) | $(-\infty, \infty)$ | **No** | Deep Hidden Layers (prevents Dying ReLU) |
| **Softmax** | $\displaystyle \frac{e^{z_i}}{\sum_j e^{z_j}}$ | $\text{S}_i(\delta_{ij} - \text{S}_j)$ | $(0, 1)$, sum $=1$ | No (with Cross-Entropy) | **Multi-Class Classification Output Layer** |

## 5. Solved University & Internal Exam Questions

### Question 1 [End Semester Exam - Nov 2025, Part A, Q8 (2 Marks)]
> **Why is ReLU often preferred over Sigmoid in deep feed forward networks?**

#### **Solution:**
ReLU ($\text{ReLU}(z) = \max(0, z)$) is preferred over Sigmoid ($\displaystyle \sigma(z) = \frac{1}{1+e^{-z}}$) in the hidden layers of deep feed-forward networks for two main reasons:
1. **Prevents the Vanishing Gradient Problem:** The derivative of Sigmoid has a maximum value of only **$0.25$** and approaches $0$ for large $|z|$ (saturation), causing gradients to vanish to zero when multiplied across deep layers during backpropagation. In contrast, **ReLU has a constant derivative of $1$ for all positive inputs ($z > 0$)**, allowing gradients to flow backward unimpeded through deep networks.
2. **Computational Efficiency & Sparsity:** ReLU only requires a simple comparison ($\max(0, z)$) rather than expensive exponential calculations ($e^{-z}$), and it sets negative activations to exact zero, creating sparse representations and much faster training convergence.

---

### Question 2 [End Semester Exam - Nov 2025, Part B, Q18(b) (3 Marks)]
> **(b) How does ReLU activation help in solving this [vanishing gradient] issue? (3 Marks)**  
> *(Note: Full Q18(a) & (b) is also covered in Module 4.5).*

#### **Solution:**
1. **Non-Saturating Positive Region:** Unlike Sigmoid and Tanh—which squash all real inputs into a narrow bounded interval $(0, 1)$ or $(-1, 1)$ and flatten out (saturate) for large positive values—the **ReLU function $\text{ReLU}(z) = \max(0, z)$ is unbounded and linear for all $z > 0$**, so it never saturates in the positive regime.
2. **Unit Derivative ($\phi'(z) = 1$) Preserves Gradient Magnitude in Backpropagation:**
   * The piecewise derivative of ReLU is:

$$
\text{ReLU}'(z) = \begin{cases} 1, & \text{if } z > 0 \\ 0, & \text{if } z < 0 \end{cases}
$$

   * During the backward pass of backpropagation, the error gradient with respect to an early hidden layer involves the product of activation derivatives across $L$ layers: $\displaystyle \prod_{l=1}^{L} \phi'(z^{(l)})$.
   * With Sigmoid ($\sigma'(z) \le 0.25$), $(0.25)^L \to 0$ exponentially fast as $L$ grows. With ReLU, for all active neurons ($z > 0$), $\displaystyle \prod_{l=1}^{L} 1 = \mathbf{1}$, so the error signal is passed backward **without attenuation**, allowing even the earliest layers of very deep networks to update their weights effectively.
