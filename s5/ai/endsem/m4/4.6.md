# Module 4.6: The Backpropagation Algorithm

## 1. What is the Backpropagation Algorithm?
The **Backpropagation Algorithm** (short for **"Backward Propagation of Errors"**, popularized by David Rumelhart, Geoffrey Hinton, and Ronald Williams in 1986) is the standard supervised learning algorithm used to train **Multi-Layer Feed-Forward Neural Networks (MLPs / Deep Neural Networks)**.

* **Why Was Backpropagation Needed?**
  * In a single-layer perceptron, it is easy to update weights because we know the exact target output $y$ for the output neuron.
  * However, in a **Multi-Layer Network**, we do **not** know the "true target values" for the internal **Hidden Layer** neurons (**The Credit Assignment Problem**).
* **How Backpropagation Solves This:**
  * Backpropagation uses the **Chain Rule of Differential Calculus** to compute the partial derivative (gradient) $\frac{\partial E}{\partial w}$ of the output loss function $E$ with respect to **every weight and bias in every layer**—starting from the **Output Layer** and propagating the error signal **backward** layer-by-layer to the **Hidden Layers**.
  * Once the gradients are computed, **Gradient Descent** updates the weights in the direction that minimizes the total error $E$.

## 2. Network Notation & Reference Diagram
Consider a standard 3-layer Feed-Forward Neural Network with:
* **Input Layer** indexed by **$i$** (inputs $x_i$)
* **Hidden Layer** indexed by **$j$** (net input $z_j$, hidden output $h_j$, weights $w_{ji}$ from input $i$ to hidden $j$)
* **Output Layer** indexed by **$k$** (net input $z_k$, predicted output $\hat{y}_k$, target $y_k$, weights $w_{kj}$ from hidden $j$ to output $k$)

```text
  FORWARD PASS (Signals flow Left ---> Right):
  x_i ----(w_ji)----> [ z_j -> h_j = phi(z_j) ] ----(w_kj)----> [ z_k -> y^_k = phi(z_k) ] ---> Error E

  BACKWARD PASS (Error Gradients flow Right ---> Left):
  dw_ji <--(delta_j)-- [ delta_j = phi'(z_j)*Sum(delta_k*w_kj) ] <--(delta_k)-- [ delta_k = (y_k - y^_k)*phi'(z_k) ]
```

## 3. Complete Mathematical Derivation of Backpropagation (Chain Rule)

Let the loss function for a training example $(\mathbf{x}, \mathbf{y})$ be the **Sum of Squared Errors (MSE)**:
$$E = \frac{1}{2} \sum_{k} \left(y_k - \hat{y}_k\right)^2$$
*(The factor $\frac{1}{2}$ is included so that it cancels nicely with the exponent $2$ when differentiating!)*

### Case A: Gradient for Output Layer Weights ($w_{kj}$)
A weight $w_{kj}$ (connecting hidden unit $j$ to output unit $k$) affects the total error $E$ only through the net input $z_k$ and output activation $\hat{y}_k$:
$$w_{kj} \longrightarrow z_k = \sum_{j} w_{kj} h_j + b_k \longrightarrow \hat{y}_k = \phi(z_k) \longrightarrow E = \frac{1}{2}\sum_{k}(y_k - \hat{y}_k)^2$$

By the **Chain Rule of Calculus**:
$$\frac{\partial E}{\partial w_{kj}} = \frac{\partial E}{\partial \hat{y}_k} \cdot \frac{\partial \hat{y}_k}{\partial z_k} \cdot \frac{\partial z_k}{\partial w_{kj}}$$

Let us evaluate each of the three partial derivatives:
1. $\frac{\partial E}{\partial \hat{y}_k} = \frac{\partial}{\partial \hat{y}_k} \left[ \frac{1}{2}(y_k - \hat{y}_k)^2 \right] = -(y_k - \hat{y}_k) = (\hat{y}_k - y_k)$
2. $\frac{\partial \hat{y}_k}{\partial z_k} = \phi'(z_k)$ *(If $\phi$ is Sigmoid, $\phi'(z_k) = \hat{y}_k(1 - \hat{y}_k)$)*
3. $\frac{\partial z_k}{\partial w_{kj}} = \frac{\partial}{\partial w_{kj}}\left(\sum_j w_{kj} h_j + b_k\right) = h_j$

Multiplying all three terms together:
$$\frac{\partial E}{\partial w_{kj}} = -(y_k - \hat{y}_k) \cdot \phi'(z_k) \cdot h_j = -\delta_k \cdot h_j$$

Where **$\delta_k$ is the Output Layer Local Error Signal (Delta)**:
$$\delta_k = -\frac{\partial E}{\partial z_k} = (y_k - \hat{y}_k) \cdot \phi'(z_k)$$
*(For Sigmoid output: $\; \mathbf{\delta_k = (y_k - \hat{y}_k) \, \hat{y}_k (1 - \hat{y}_k)}$)*

---

### Case B: Gradient for Hidden Layer Weights ($w_{ji}$)
A weight $w_{ji}$ (connecting input $i$ to hidden unit $j$) affects $z_j$, which affects $h_j$, which in turn affects **all output units $k$** connected to hidden unit $j$:
$$w_{ji} \longrightarrow z_j \longrightarrow h_j \longrightarrow \{z_k \text{ for all } k\} \longrightarrow E$$

By the **Multivariable Chain Rule**:
$$\frac{\partial E}{\partial w_{ji}} = \left(\sum_{k} \frac{\partial E}{\partial z_k} \cdot \frac{\partial z_k}{\partial h_j}\right) \cdot \frac{\partial h_j}{\partial z_j} \cdot \frac{\partial z_k}{\partial w_{ji}}$$

Evaluating each term:
1. $\frac{\partial E}{\partial z_k} = -\delta_k$ (already computed in the output layer!)
2. $\frac{\partial z_k}{\partial h_j} = \frac{\partial}{\partial h_j}\left(\sum_j w_{kj} h_j + b_k\right) = w_{kj}$
3. $\frac{\partial h_j}{\partial z_j} = \phi'(z_j)$ *(If $\phi$ is Sigmoid, $\phi'(z_j) = h_j(1 - h_j)$)*
4. $\frac{\partial z_j}{\partial w_{ji}} = x_i$

Combining these gives the **Hidden Layer Local Error Signal ($\delta_j$)**:
$$\delta_j = -\frac{\partial E}{\partial z_j} = \phi'(z_j) \sum_{k} \delta_k \cdot w_{kj}$$
*(For Sigmoid hidden layer: $\; \mathbf{\delta_j = h_j (1 - h_j) \sum_{k} \delta_k \, w_{kj}}$)*

And the gradient with respect to hidden weight $w_{ji}$ is:
$$\frac{\partial E}{\partial w_{ji}} = -\delta_j \cdot x_i$$

## 4. Solved University Exam Question (Complete 8-Mark Answer!)

### Question 1 [End Semester Exam - Nov 2025, Part B, Q17 (8 Marks)]
> **Explain the backpropagation algorithm with steps.**

#### **Solution:**

#### **1. Introduction:**
**Backpropagation (Backward Propagation of Errors)** is a supervised learning algorithm used to train Multi-Layer Feed-Forward Neural Networks (MLPs). It minimizes the error (loss) between the network's predicted output ($\hat{y}$) and the actual target output ($y$) by:
1. Propagating inputs **forward** to compute predictions and loss.
2. Propagating error derivatives **backward** from the output layer to the hidden layers using the **Chain Rule of Calculus**.
3. Updating all weights and biases using **Gradient Descent**.

---

#### **2. Step-by-Step Backpropagation Algorithm:**

Consider a neural network with Input units $x_i$, Hidden units $h_j$ (weights $w_{ji}$, bias $b_j$), Output units $\hat{y}_k$ (weights $w_{kj}$, bias $b_k$), activation function $\phi(z)$ (e.g., Sigmoid $\sigma(z) = \frac{1}{1+e^{-z}}$), and learning rate $\eta \in (0, 1)$.

##### **Step 1: Weight and Bias Initialization**
* Initialize all network weights ($w_{ji}, w_{kj}$) to small random numbers (e.g., using Xavier or He initialization) to break symmetry, and initialize biases ($b_j, b_k$) to $0$ or small random values.

##### **Step 2: Forward Propagation (Forward Pass)**
For a training sample $(\mathbf{x}, \mathbf{y})$, feed the input vector $\mathbf{x} = [x_1, \dots, x_n]$ forward through the network:
1. **At the Hidden Layer ($j$):**
   Compute the net weighted input $z_j$ and activation output $h_j$ for each hidden neuron $j$:
   $$z_j = \sum_{i} w_{ji} x_i + b_j$$
   $$h_j = \phi(z_j) = \frac{1}{1 + e^{-z_j}}$$
2. **At the Output Layer ($k$):**
   Compute the net weighted input $z_k$ and predicted output $\hat{y}_k$ for each output neuron $k$:
   $$z_k = \sum_{j} w_{kj} h_j + b_k$$
   $$\hat{y}_k = \phi(z_k) = \frac{1}{1 + e^{-z_k}}$$

##### **Step 3: Error (Loss) Calculation**
Compare the predicted output $\hat{y}_k$ with the desired target label $y_k$ using the Mean Squared Error (MSE) loss function:
$$E = \frac{1}{2} \sum_{k} \left(y_k - \hat{y}_k\right)^2$$

##### **Step 4: Backward Propagation of Error (Backward Pass)**
Compute the local error gradients ($\delta$) moving backward from the output layer to the hidden layer using the Chain Rule:
1. **Output Layer Error Term ($\delta_k$):**
   For each output unit $k$, compute its error term $\delta_k = -\frac{\partial E}{\partial z_k}$:
   $$\delta_k = (y_k - \hat{y}_k) \cdot \phi'(z_k)$$
   *(For Sigmoid activation, since $\phi'(z_k) = \hat{y}_k(1 - \hat{y}_k)$):*
   $$\mathbf{\delta_k = (y_k - \hat{y}_k) \, \hat{y}_k (1 - \hat{y}_k)}$$
2. **Hidden Layer Error Term ($\delta_j$):**
   Propagate the output errors $\delta_k$ backward through the connecting weights $w_{kj}$ to each hidden unit $j$:
   $$\delta_j = \phi'(z_j) \sum_{k} \left(\delta_k \cdot w_{kj}\right)$$
   *(For Sigmoid activation, since $\phi'(z_j) = h_j(1 - h_j)$):*
   $$\mathbf{\delta_j = h_j (1 - h_j) \sum_{k} \left(\delta_k \cdot w_{kj}\right)}$$

##### **Step 5: Weight and Bias Update (Gradient Descent)**
Update all weights and biases in the direction opposite to the error gradient ($w^{\text{new}} = w^{\text{old}} - \eta \frac{\partial E}{\partial w}$):
1. **Update Hidden-to-Output Weights ($w_{kj}$) and Biases ($b_k$):**
   $$\Delta w_{kj} = -\eta \frac{\partial E}{\partial w_{kj}} = \eta \cdot \delta_k \cdot h_j \implies \mathbf{w_{kj}^{\text{new}} = w_{kj}^{\text{old}} + \eta \, \delta_k \, h_j}$$
   $$\mathbf{b_k}^{\text{new}} = b_k^{\text{old}} + \eta \, \delta_k$$
2. **Update Input-to-Hidden Weights ($w_{ji}$) and Biases ($b_j$):**
   $$\Delta w_{ji} = -\eta \frac{\partial E}{\partial w_{ji}} = \eta \cdot \delta_j \cdot x_i \implies \mathbf{w_{ji}^{\text{new}} = w_{ji}^{\text{old}} + \eta \, \delta_j \, x_i}$$
   $$\mathbf{b_j}^{\text{new}} = b_j^{\text{old}} + \eta \, \delta_j$$

##### **Step 6: Stopping / Convergence Criterion**
* Repeat **Steps 2 to 5** for all training samples across multiple **epochs** until the total network error $E$ falls below an acceptable threshold ($E < \epsilon$) or the maximum number of training epochs is reached.

---

#### **3. Pseudocode Summary of Backpropagation:**
```text
function BACKPROPAGATION(training_examples, eta, n_in, n_hidden, n_out):
    Initialize all weights w and biases b to small random values
    repeat until stopping criterion is met:
        for each (x, y) in training_examples do:
            /* 1. Forward Pass */
            For each hidden unit j: compute h_j = phi(Sum_i(w_ji * x_i) + b_j)
            For each output unit k: compute y^_k = phi(Sum_j(w_kj * h_j) + b_k)

            /* 2. Backward Pass */
            For each output unit k:
                delta_k <- (y_k - y^_k) * phi'(z_k)
            For each hidden unit j:
                delta_j <- phi'(z_j) * Sum_k(w_kj * delta_k)

            /* 3. Weight Update */
            For each weight w_kj: w_kj <- w_kj + eta * delta_k * h_j
            For each weight w_ji: w_ji <- w_ji + eta * delta_j * x_i
```

## 5. Bonus: Mini Numerical Example of 1 Backpropagation Step
*(Helpful if a numerical question is asked or to illustrate Q17!)*

Consider a simple 1-input ($x = 1$), 1-hidden ($h$), 1-output ($\hat{y}$) network with Sigmoid activations, target $y = 1$, learning rate $\eta = 1.0$, initial weights $w_1 = 0.5$ (input $\to$ hidden), $w_2 = 1.0$ (hidden $\to$ output), and zero biases:
1. **Forward Pass:**
   * $z_h = w_1 x = 0.5 \times 1 = 0.5 \implies h = \sigma(0.5) \approx \mathbf{0.622}$
   * $z_y = w_2 h = 1.0 \times 0.622 = 0.622 \implies \hat{y} = \sigma(0.622) \approx \mathbf{0.651}$
2. **Error:** $E = \frac{1}{2}(1 - 0.651)^2 = \mathbf{0.0609}$
3. **Backward Pass:**
   * Output delta: $\delta_y = (y - \hat{y})\hat{y}(1 - \hat{y}) = (1 - 0.651)(0.651)(0.349) \approx \mathbf{0.0793}$
   * Hidden delta: $\delta_h = h(1 - h)(\delta_y w_2) = (0.622)(0.378)(0.0793 \times 1.0) \approx \mathbf{0.0186}$
4. **Weight Updates ($\eta = 1.0$):**
   * $w_2^{\text{new}} = w_2 + \eta \delta_y h = 1.0 + (1.0)(0.0793)(0.622) = \mathbf{1.0493}$
   * $w_1^{\text{new}} = w_1 + \eta \delta_h x = 0.5 + (1.0)(0.0186)(1) = \mathbf{0.5186}$
