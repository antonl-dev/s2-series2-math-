## PART A: Attribute Closure ($X^+$) and How to Compute It

Every single problem in Module 4 (finding Candidate Keys, checking FD Equivalence, finding Minimal Cover, and checking 2NF/3NF/BCNF) relies on **one simple superpower**: computing the **Attribute Closure ($X^+$)**!

### 1. What is Attribute Closure ($X^+$)?
* **Definition:** Given a set of Functional Dependencies $F$ on a relation $R$, the **Closure of a set of attributes $X$ under $F$**, denoted by **$X^+$** (or $\{X\}^+$), is the **set of all attributes that are functionally determined by $X$** using $F$.
* **In plain English:** *"If I start by knowing the attributes in $X$, what is the complete list of attributes I can unlock by chaining the arrows in $F$?"*

---

### 2. The 3-Step Recipe to Compute $X^+$ (Takes 15 Seconds!)

Suppose we want to find $\{X\}^+$ given a set of FDs $F$:

1. **Step 1 (Start with $X$ itself):**
   Write down the starting attributes inside $X^+$ (because by Reflexivity, $X$ always determines itself!):
   $$X^+ = \{X\}$$
2. **Step 2 (Scan the FDs and Grow the Set):**
   Look through each FD $U \rightarrow V$ in $F$:
   * Ask: **"Are ALL the attributes on the Left-Hand Side ($U$) already inside my current $X^+$ box?"**
   * If **YES** $\rightarrow$ Add the Right-Hand Side attribute(s) **$V$** into your $X^+$ box!
3. **Step 3 (Repeat until it stops growing):**
   Keep scanning $F$ until no more new attributes can be added to $X^+$. That final set is **$X^+$**!

---

### 3. Worked Example of Computing Attribute Closure ($X^+$)

Suppose a relation $R(A, B, C, D, E)$ has the following set of FDs $F$:
$$F = \{\; A \rightarrow B, \;\; BC \rightarrow D, \;\; D \rightarrow E \;\}$$

#### Example 1: Find $\{A\}^+$
* **Start:** $\{A\}^+ = \{A\}$
* **Scan $F$:**
  * Look at $A \rightarrow B$: Is $A$ inside $\{A\}$? **Yes!** Add $B$ $\implies \{A, B\}$.
  * Look at $BC \rightarrow D$: Are **both** $B$ and $C$ inside $\{A, B\}$? **No!** ($B$ is inside, $C$ is missing! So we **cannot** use $BC \rightarrow D$).
  * Look at $D \rightarrow E$: Is $D$ inside $\{A, B\}$? **No!**
* **Final Result:** $\{A\}^+ = \mathbf{\{A, B\}}$.

#### Example 2: Find $\{A, C\}^+$
* **Start:** $\{AC\}^+ = \{A, C\}$
* **Scan $F$:**
  * Using $A \rightarrow B$ (since $A \in \{A, C\}$): Add $B$ $\implies \{A, B, C\}$.
  * Using $BC \rightarrow D$ (now **both** $B$ and $C$ are inside $\{A, B, C\}$!): Add $D$ $\implies \{A, B, C, D\}$.
  * Using $D \rightarrow E$ (now $D$ is inside $\{A, B, C, D\}$!): Add $E$ $\implies \{A, B, C, D, E\}$.
* **Final Result:** $\{AC\}^+ = \mathbf{\{A, B, C, D, E\}}$ *(All attributes of $R$!)*.

---

### 4. Three Major Uses of Attribute Closure ($X^+$)

1. **Testing Whether a Functional Dependency $X \rightarrow Y$ Holds:**
   * Simply compute $X^+$. If $Y$ is inside $X^+$ ($Y \subseteq X^+$), then **$X \rightarrow Y$ holds**! Otherwise, it does not hold.
   * *(In our example above, does $AC \rightarrow E$ hold? Since $E \in \{AC\}^+$, **YES**, $AC \rightarrow E$ holds!)*

2. **Finding Superkeys and Candidate Keys of a Relation $R$:**
   * **Superkey Rule:** If $X^+$ contains **ALL attributes of the relation $R$**, then $X$ is a **Superkey**!
   * **Candidate Key Rule:** If $X$ is a Superkey AND no proper subset of $X$ is a Superkey, then $X$ is a **Candidate Key**!
   * *(In our example above, $\{AC\}^+ = \{A, B, C, D, E\}$, while $\{A\}^+ = \{A, B\}$ and $\{C\}^+ = \{C\}$. Therefore, **`AC` is the Candidate Key** of $R$!)*
   > **Quick Trick to Find Candidate Keys Fast:**
   > Any attribute that **NEVER appears on the Right-Hand Side (RHS)** of any FD can **never** be derived from anything else—so it **MUST be part of EVERY Candidate Key**! *(Above, $A$ and $C$ never appear on any RHS, so start by testing $\{AC\}^+$ immediately!)*

## PART B: Equivalence of Two Sets of Functional Dependencies ($R \equiv S$)

> ⭐ **DIRECT EXAM QUESTION:** Asked in **Oct 2025 Internal Test Q4(b) (4 Marks)**:
> *"Given two sets R and S of functional dependency for a relation:*
> *$R = \{A \rightarrow B, \; AB \rightarrow C, \; D \rightarrow AC, \; D \rightarrow E\}$*
> *$S = \{A \rightarrow BC, \; D \rightarrow AE\}$*
> *Check whether the given two functional dependencies are equivalent or not."*

### 1. When Are Two Sets of Functional Dependencies $R$ and $S$ Equivalent?

* **Definition:** Two sets of functional dependencies $R$ and $S$ are said to be **Equivalent** (denoted **$R \equiv S$**) if and only if **both** of the following conditions hold:
  1. **$R$ covers $S$ ($S \subseteq R^+$):** Every FD in $S$ can be inferred/derived using the FDs of $R$.
  2. **$S$ covers $R$ ($R \subseteq S^+$):** Every FD in $R$ can be inferred/derived using the FDs of $S$.
* *(If even **one** FD in $S$ cannot be derived from $R$, or vice versa, then $R$ and $S$ are **NOT equivalent**!)*

📸 **[Click here to view Equivalence of Functional Dependencies Solved Examples on Google Images](https://www.google.com/search?q=equivalence+of+two+sets+of+functional+dependencies+in+dbms+example&udm=2)**

---

### 2. Mechanical 2-Part Algorithm to Check if $R \equiv S$ (Works Every Time!)

```text
+-------------------------------------------------------------------+
|  PART 1: Does R cover S? (Check each FD X -> Y in S using R)      |
|  - For each X -> Y in S:                                          |
|    Compute {X}^+ using ONLY the FDs in R.                         |
|    Is Y inside {X}^+_R?                                           |
|    -> If YES for all FDs in S, then R covers S!                   |
+---------------------------------+---------------------------------+
                                  |
                                  v
+-------------------------------------------------------------------+
|  PART 2: Does S cover R? (Check each FD U -> V in R using S)      |
|  - For each U -> V in R:                                          |
|    Compute {U}^+ using ONLY the FDs in S.                         |
|    Is V inside {U}^+_S?                                           |
|    -> If YES for all FDs in R, then S covers R!                   |
+---------------------------------+---------------------------------+
                                  |
                                  v
   [ If BOTH Part 1 and Part 2 are YES ===> R and S are EQUIVALENT! ]
```

## PART C: Minimal Cover (Canonical Cover / Irreducible Set of FDs)

> ⭐ **DIRECT EXAM QUESTION:** Asked in **Nov 2025 End-Sem Exam Q8(a) (5 Marks)**:
> *"Given a relation $R(A, B, D)$. Find the minimal cover of the set of functional dependencies given; $F = \{B \rightarrow A, \; A \rightarrow D, \; AB \rightarrow D\}$ (5 marks)"*

### 1. What is a Minimal Cover ($F_m$)?
Sometimes a designer writes down a messy set of Functional Dependencies $F$ that has **extra/redundant attributes** or **redundant FDs** that are already implied by other FDs.
* **Definition:** A **Minimal Cover** (also called a **Canonical Cover** or **Irreducible Set**) of a set of functional dependencies $F$ is a simplified, minimal set of FDs **$F_m$** that is **equivalent to $F$ ($F_m \equiv F$)** and contains **zero redundancy**.

### 2. The 3 Strict Conditions of a Minimal Cover (And the 3-Step Algorithm!)

Every Minimal Cover $F_m$ must satisfy **three conditions**, and our **3-Step Algorithm** enforces them one by one in this exact order:

📸 **[Click here to view Minimal Cover (Canonical Cover) 3-Step Algorithm Chart on Google Images](https://www.google.com/search?q=minimal+cover+or+canonical+cover+in+dbms+steps+example&udm=2)**

---

#### Step 1: Make the Right-Hand Side (RHS) a Single Attribute!
* **Rule:** Every FD in the Minimal Cover must have **only ONE single attribute** on its Right-Hand Side ($X \rightarrow A$).
* **What to do:** Whenever you see an FD with multiple attributes on the RHS (like $X \rightarrow YZ$), split it using the **Decomposition Rule**:
  $$X \rightarrow YZ \quad\Longrightarrow\quad X \rightarrow Y \;\;\text{ and }\;\; X \rightarrow Z$$
  *(⚠️ Never split the Left-Hand Side! Only split the Right-Hand Side!)*

---

#### Step 2: Remove Extraneous (Redundant) Attributes from the Left-Hand Side (LHS)!
* **Rule:** No FD $X \rightarrow A$ should have any extra/unnecessary attribute hiding inside its Left-Hand Side $X$.
* **What to do:** Look **ONLY** at FDs that have **2 or more attributes on their LHS** (for example, $AB \rightarrow D$).
  * **To test if $A$ is extraneous (redundant) in $AB \rightarrow D$:**
    Compute $\{B\}^+$ using the current FDs. If $D \in \{B\}^+$ (or $A \in \{B\}^+$), it means **$B$ alone already determines $D$** without needing $A$! So $A$ is redundant—cross out $A$ and simplify $AB \rightarrow D$ to **$B \rightarrow D$**.
  * **To test if $B$ is extraneous (redundant) in $AB \rightarrow D$:**
    Compute $\{A\}^+$ using the current FDs. If $D \in \{A\}^+$ (or $B \in \{A\}^+$), it means **$A$ alone already determines $D$** without needing $B$! So $B$ is redundant—cross out $B$ and simplify $AB \rightarrow D$ to **$A \rightarrow D$**.

---

#### Step 3: Remove Redundant Functional Dependencies!
* **Rule:** No FD in $F_m$ can be derived from the other FDs in $F_m$.
* **What to do:** Check each remaining FD $X \rightarrow Y$ one by one:
  1. **Temporarily hide (cover up with your finger)** the FD $X \rightarrow Y$.
  2. Compute the closure **$\{X\}^+$ using ONLY the remaining FDs** ($F - \{X \rightarrow Y\}$).
  3. Ask: **"Did $Y$ STILL appear inside $\{X\}^+$ even when $X \rightarrow Y$ was hidden?"**
     * If **YES** $\rightarrow$ Then $X \rightarrow Y$ is **100% Redundant** (the other FDs already give $X \rightarrow Y$ transitively)! **Delete $X \rightarrow Y$ permanently!**
     * If **NO** $\rightarrow$ Then $X \rightarrow Y$ is **Essential**! **Keep $X \rightarrow Y$!**

## PART D: Past Year Questions (PYQs) from Your Papers – Full Answers

### PYQ 1: Oct 2025 Internal Test – Question IV(b) [4 Marks]

> **Question IV(b) [4 Marks]:**
> *"Given two sets $R$ and $S$ of functional dependency for a relation:*
> *$R = \{A \rightarrow B, \;\; AB \rightarrow C, \;\; D \rightarrow AC, \;\; D \rightarrow E\}$*
> *$S = \{A \rightarrow BC, \;\; D \rightarrow AE\}$*
> *Check whether the given two functional dependencies are equivalent or not."*

---

#### ✅ Model Exam Answer (Write this verbatim for 4 / 4 Marks):

Two sets of functional dependencies $R$ and $S$ are **equivalent ($R \equiv S$)** if and only if **$R$ covers $S$** (every FD in $S$ can be inferred from $R$) **AND** **$S$ covers $R$** (every FD in $R$ can be inferred from $S$).

---

#### Step 1: Check whether $R$ covers $S$ (Evaluate each FD of $S$ using $R$)
Here, $R = \{A \rightarrow B, \;\; AB \rightarrow C, \;\; D \rightarrow AC, \;\; D \rightarrow E\}$.
We must verify whether both FDs of $S$ ($A \rightarrow BC$ and $D \rightarrow AE$) hold under $R$:

1. **Testing $A \rightarrow BC \in S$ using $R$:**
   Compute the attribute closure $\{A\}^+_R$ using the FDs in $R$:
   * Start with $\{A\}^+_R = \{A\}$
   * Using $A \rightarrow B \in R$: $\{A\}^+_R = \{A, B\}$
   * Using $AB \rightarrow C \in R$: $\{A\}^+_R = \{A, B, C\}$
   * Since $\{B, C\} \subseteq \{A\}^+_R$, the FD **$A \rightarrow BC$ holds under $R$**. ✅

2. **Testing $D \rightarrow AE \in S$ using $R$:**
   Compute the attribute closure $\{D\}^+_R$ using the FDs in $R$:
   * Start with $\{D\}^+_R = \{D\}$
   * Using $D \rightarrow AC \in R$: $\{D\}^+_R = \{A, C, D\}$
   * Using $D \rightarrow E \in R$: $\{D\}^+_R = \{A, C, D, E\}$
   * Using $A \rightarrow B \in R$: $\{D\}^+_R = \{A, B, C, D, E\}$
   * Since $\{A, E\} \subseteq \{D\}^+_R$, the FD **$D \rightarrow AE$ holds under $R$**. ✅

$\therefore$ **Since all FDs of $S$ are satisfied under $R$, $R$ covers $S$ ($S \subseteq R^+$).**

---

#### Step 2: Check whether $S$ covers $R$ (Evaluate each FD of $R$ using $S$)
Here, $S = \{A \rightarrow BC, \;\; D \rightarrow AE\}$.
We must verify whether all four FDs of $R$ ($A \rightarrow B$, $AB \rightarrow C$, $D \rightarrow AC$, and $D \rightarrow E$) hold under $S$:

1. **Testing $A \rightarrow B \in R$ using $S$:**
   * Compute $\{A\}^+_S$ using $S$:
   * Start with $\{A\} \xrightarrow{A \rightarrow BC} \{A, B, C\}$.
   * Since $B \in \{A\}^+_S$, **$A \rightarrow B$ holds under $S$**. ✅

2. **Testing $AB \rightarrow C \in R$ using $S$:**
   * Compute $\{AB\}^+_S$ using $S$:
   * Start with $\{A, B\} \xrightarrow{A \rightarrow BC} \{A, B, C\}$.
   * Since $C \in \{AB\}^+_S$, **$AB \rightarrow C$ holds under $S$**. ✅

3. **Testing $D \rightarrow AC \in R$ and $D \rightarrow E \in R$ using $S$:**
   * Compute $\{D\}^+_S$ using $S$:
   * Start with $\{D\} \xrightarrow{D \rightarrow AE} \{A, D, E\} \xrightarrow{A \rightarrow BC} \{A, B, C, D, E\}$.
   * Since $\{A, C\} \subseteq \{D\}^+_S$, **$D \rightarrow AC$ holds under $S$**. ✅
   * Since $E \in \{D\}^+_S$, **$D \rightarrow E$ holds under $S$**. ✅

$\therefore$ **Since all FDs of $R$ are satisfied under $S$, $S$ covers $R$ ($R \subseteq S^+$).**

---

#### Final Conclusion:
Since **$R$ covers $S$** AND **$S$ covers $R$**, the given two sets of functional dependencies **$R$ and $S$ are EQUIVALENT ($R \equiv S$)**.

### PYQ 2: Nov 2025 End-Sem Exam – Question 8(a) [5 Marks]

> **Question 8(a) [5 Marks]:**
> *"Given a relation $R(A, B, D)$. Find the minimal cover of the set of functional dependencies given; $F = \{B \rightarrow A, \;\; A \rightarrow D, \;\; AB \rightarrow D\}$ (5 marks)"*

---

#### ✅ Model Exam Answer (Write this verbatim for 5 / 5 Marks):

Given Relation $R(A, B, D)$ and Functional Dependency set:
$$F = \{\; B \rightarrow A, \;\; A \rightarrow D, \;\; AB \rightarrow D \;\}$$

To find the **Minimal Cover ($F_m$)** of $F$, we apply the standard 3-step algorithm:

---

#### Step 1: Express all FDs with a Single Attribute on the Right-Hand Side (RHS)
We check the RHS of every FD in $F$. Since each FD already has only one single attribute on its RHS, no decomposition is needed:
1. $B \rightarrow A$
2. $A \rightarrow D$
3. $AB \rightarrow D$

---

#### Step 2: Remove Extraneous (Redundant) Attributes from the Left-Hand Side (LHS)
Only the third FD, **$AB \rightarrow D$**, has more than one attribute on its LHS. We check whether $A$ or $B$ is extraneous in $AB \rightarrow D$:

* **Checking if $B$ is extraneous in $AB \rightarrow D$:**
  Compute the closure of the remaining LHS attribute $\{A\}^+$ using $F$:
  $$\{A\}^+ = \{A, D\} \quad (\text{since } A \rightarrow D \in F)$$
  Since $D \in \{A\}^+$, attribute $A$ alone is sufficient to determine $D$. Therefore, **$B$ is an extraneous (redundant) attribute** in $AB \rightarrow D$!
* *(Alternatively, checking if $A$ is extraneous in $AB \rightarrow D$: $\{B\}^+ = \{B, A, D\}$ using $B \rightarrow A$ and $A \rightarrow D$. Since $A \in \{B\}^+$, $A$ is also extraneous!)*
* Removing the extraneous attribute $B$ from $AB \rightarrow D$ reduces it to **$A \rightarrow D$**, which is already present in our set.
* Removing the duplicate FD leaves:
  $$F_1 = \{\; B \rightarrow A, \;\; A \rightarrow D \;\}$$

---

#### Step 3: Remove Redundant Functional Dependencies
Now we test each remaining FD in $F_1 = \{B \rightarrow A, \;\; A \rightarrow D\}$ to see if any FD can be derived from the others:

1. **Test if $B \rightarrow A$ is redundant:**
   * Temporarily remove $B \rightarrow A$. The remaining set is $\{A \rightarrow D\}$.
   * Compute $\{B\}^+$ using $\{A \rightarrow D\}$:
     $$\{B\}^+ = \{B\}$$
   * Since $A \notin \{B\}^+$, **$B \rightarrow A$ is NOT redundant** (it is essential and must be kept).

2. **Test if $A \rightarrow D$ is redundant:**
   * Temporarily remove $A \rightarrow D$. The remaining set is $\{B \rightarrow A\}$.
   * Compute $\{A\}^+$ using $\{B \rightarrow A\}$:
     $$\{A\}^+ = \{A\}$$
   * Since $D \notin \{A\}^+$, **$A \rightarrow D$ is NOT redundant** (it is essential and must be kept).

*(Note: Even if $AB \rightarrow D$ had been kept until Step 3, temporarily removing $AB \rightarrow D$ and computing $\{AB\}^+$ under $\{B \rightarrow A, \; A \rightarrow D\}$ gives $\{AB\}^+ = \{A, B, D\}$, which contains $D$, proving $AB \rightarrow D$ is redundant!)*

---

#### Final Answer (Minimal Cover $F_m$):
$$\boxed{F_m = \{\; B \rightarrow A, \;\; A \rightarrow D \;\}}$$

### ⭐ Bonus Worked Example: A Bigger Minimal Cover Problem (Where All 3 Steps Do Work!)

Suppose in Nov 2026 they give a 5-FD Minimal Cover problem:
> **Find the minimal cover of:** $F = \{\; A \rightarrow BC, \;\; B \rightarrow C, \;\; A \rightarrow B, \;\; AB \rightarrow C \;\}$

1. **Step 1 (Split RHS of $A \rightarrow BC$ into single attributes):**
   * $A \rightarrow B$
   * $A \rightarrow C$
   * $B \rightarrow C$
   * $A \rightarrow B$ *(duplicate, write once)*
   * $AB \rightarrow C$
   * Current list: $\{A \rightarrow B, \;\; A \rightarrow C, \;\; B \rightarrow C, \;\; AB \rightarrow C\}$.

2. **Step 2 (Remove extraneous LHS attribute from $AB \rightarrow C$):**
   * Check if $B$ is extraneous in $AB \rightarrow C$: Compute $\{A\}^+ = \{A, B, C\}$. Since $B \in \{A\}^+$ (and $C \in \{A\}^+$), **$B$ is extraneous**!
   * Replace $AB \rightarrow C$ with $A \rightarrow C$ (which is already in our list!).
   * Current list: $\{A \rightarrow B, \;\; A \rightarrow C, \;\; B \rightarrow C\}$.

3. **Step 3 (Remove redundant FDs):**
   * **Test $A \rightarrow B$** (using $\{A \rightarrow C, \; B \rightarrow C\}$): $\{A\}^+ = \{A, C\}$ (does not contain $B$) $\rightarrow$ **Keep $A \rightarrow B$**.
   * **Test $A \rightarrow C$** (using $\{A \rightarrow B, \; B \rightarrow C\}$):
     $$\{A\}^+ = \{A\} \xrightarrow{A \rightarrow B} \{A, B\} \xrightarrow{B \rightarrow C} \{A, B, C\}$$
     Look! **$C$ IS inside $\{A\}^+$** even without $A \rightarrow C$! So **$A \rightarrow C$ is REDUNDANT**—delete it!
   * **Test $B \rightarrow C$** (using $\{A \rightarrow B\}$): $\{B\}^+ = \{B\}$ (does not contain $C$) $\rightarrow$ **Keep $B \rightarrow C$**.

4. **Final Minimal Cover:**
   $$F_m = \{\; A \rightarrow B, \;\; B \rightarrow C \;\}$$

### Quick 30-Second Recap of 4.2
* **Attribute Closure ($X^+$):** Start with $\{X\}$ and keep adding the RHS of any FD whose LHS is already inside your set.
* **Candidate Key Test:** If $X^+$ contains **all attributes of the table** (and no subset of $X$ does), $X$ is a **Candidate Key**.
* **FD Equivalence ($R \equiv S$):**
  1. Check if every FD in $S$ holds using closures under $R$.
  2. Check if every FD in $R$ holds using closures under $S$.
  3. If both are YES $\rightarrow$ **$R$ and $S$ are Equivalent!**
* **Minimal Cover ($F_m$) 3-Step Recipe:**
  1. **Step 1:** Split RHS so every FD has **1 attribute on RHS**.
  2. **Step 2:** Remove redundant attributes from multi-attribute **LHS**.
  3. **Step 3:** Hide each FD one by one; if its RHS is still in $\{LHS\}^+$ using the other FDs, **delete that redundant FD**.
